# BlindAssist Community Code of Conduct

## Our commitment

We are committed to a respectful, accessible and evidence-minded community for people of every background, identity, ability and level of experience. Accessibility work should include disabled people without treating anyone as a test subject or source of private data.

## Expected behavior

- Use welcoming, plain and accessible language.
- Critique ideas, evidence and code rather than people.
- Respect privacy, consent, licenses and stated evidence boundaries.
- Accept uncertainty and negative results without pressuring contributors to overclaim.
- Give attribution and make room for less experienced contributors.
- Stop or redirect discussion when it exposes sensitive personal or security information.

## Unacceptable behavior

- Harassment, threats, discriminatory language or unwanted sexual attention.
- Publishing another person's private information or imagery without explicit authorization.
- Deliberately misrepresenting research evidence, user outcomes, accessibility needs or safety claims.
- Sustained disruption, intimidation, impersonation or retaliation against a reporter.

## Scope and enforcement

This code applies in repository issues, pull requests, discussions, reviews and project-related public spaces. Maintainers may edit or remove content, lock conversations, reject contributions, or temporarily or permanently restrict participation when behavior is unsafe or incompatible with this code.

Report conduct concerns to the repository maintainer through the contact path on the [maintainer's GitHub profile](https://github.com/violetljj). If a concern includes a security vulnerability or sensitive private data, use the private process in [SECURITY.md](SECURITY.md) and do not post those details publicly.

Reports will be handled as privately as the available channel permits. Conflicts of interest should be disclosed so another suitable reviewer can be involved when available. Enforcement decisions will consider context, impact, prior behavior and participant safety.
