## 维护规则

- 每个独立任务只占一行；详情只能写入该任务自己的 `<TASK-ID>.md`。
- 仅在创建、交接、状态变化或完成时更新索引；普通里程碑只更新任务交接文件。
- 完成且已把持久决策写入项目文档后，从活跃索引移除该行；不要把它的下一步混入新任务。
- “一句话下一步”不得要求人工采集、标注、审核、仲裁或验收；证据缺口应路由到自动 Agent/模型替代、隔离/拒收或局部分支 fail closed。
- 不记录令牌、个人信息、大段日志或跨任务讨论。
