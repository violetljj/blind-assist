## 维护规则

- 每个独立任务只占一行；详情只能写入该任务自己的 `<TASK-ID>.md`。
- 创建、暂停、恢复、阻塞或完成任务时，同步更新状态、时间和下一步。
- 已完成任务可保留一行并标记 `已完成`；不要把它的下一步混入新任务。
- 不记录令牌、个人信息、大段日志或跨任务讨论。
