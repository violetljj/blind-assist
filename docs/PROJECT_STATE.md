# Project state

Updated: 2026-08-31

BlindAssist is a runnable Android showcase research prototype. The default
policy is effect-first: demonstrate a genuine, visible effect in a controlled
setup, state the evidence source and metric honestly, and keep only checks that
protect interpretation or change the next decision.

This page is the compact committed authority surface. Uncommitted local work is
work in progress and does not change the project state.

1. Read this page for routing and the project-wide boundary.

## Claim boundary

- BlindAssist is not validated navigation or a certified safety product.
- Synthetic, replay, curated Development, registered-source, live-device, and
  natural-distribution evidence are reported separately.
- `UNKNOWN` and `NOT_EVALUABLE` are neither negative evidence nor known-safe.
- `referent != affordance != waypoint != arrival != handoff`.
- A build or JVM test is not a live-camera or user result.
- Protected blind/final claims follow
  [formal research governance](formal/RESEARCH_GOVERNANCE.md).
