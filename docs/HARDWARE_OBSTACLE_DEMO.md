## A+LOCAL 实验模式

用户要求将研究组合移到实物手机。新增开关默认开启，可随时关闭并回到原基础 ToF。
冻结 A 阈值 0.4071309640537889、LOCAL 阈值 0.7959699076137833，LOCAL 为 200 棵
HGB 树、961 维公开输入特征，仅中央 BODY/HEAD 查询 1/4 参与 A OR LOCAL；不包含失败的
额外救援门控，不改模型或阈值。模型在手机 CPU 离线运行，纯标量/树操作不依赖 GPU。

**这是名义几何适配实验，不是标定后的实机升级效果证明。** RGB 640×480 中央裁成
640×360，再用 2×2 面积平均到 320×180；名义相机水平视场 100°、ToF 45°、同轴无平移，
粗朝向沿用原安装记录。径向读数按区域中心射线换算轴向，不能精确代表区域内实际反射位置。
研究 ToF 是假设的单回波模拟器，实物状态/材质/畸变/安装偏差没有因此被消除。
真实原始区域、读数和显示画面保留，界面显示未标定，不画伪配准框。

LOCAL 需要有效 RGB 和 8×8 ToF；两路时龄上界差大于 250 ms 时暂停 LOCAL，此规则不是
曝光同步证明。缺少画面时保留 A；ToF 失效时停止判决。推理结束和主线程恢复时再次检查
750 ms 新鲜度，拒绝过期贡献。LOCAL 单独触发保留 UNKNOWN，不输出虚构距离。
同一 ToF 样本不重复推理，旧缓存受相机时龄限制；无后台积压。USB 中转缺少双路时龄，
仅 A，不声称支持 USB LOCAL。模型加载或输入格式失败明确显示回退基础 ToF。

留证继续保存当时判决和包含算法来源的状态，回放不重新推理、不发声。

## 留证与回放

1. 连接后，前台在内存循环保留最近最多 20 秒 / 256 帧。点 **保存刚才 20 秒** 保存已有记录；连接刚启动时会短于 20 秒。新 ToF 序号、判决变化与流状态变化不会被普通显示采样限速忽略。
2. 默认只记录测距、有效性、时龄、原判决及提示请求。展开 **记录 / 回放**，可开启 **附带画面抽帧**：异步最多 2 Hz、320×240 JPEG，非连续录像，不表示曝光同步。关闭会清除未保存的画面；已保存记录不变。
3. 在记录列表点 **回放**，可拖动时间轴或播放/暂停。回放保留当时判决，不重新运行新算法，不播语音/震动；离开页面暂停，页面重建后仍保持暂停回放。点 **返回实时** 才恢复连接。
4. 记录保存在 App 私有不备份目录，最多 50 条 / 50 MB，不自动上传或淘汰。**导出**写入用户选择的文档位置，JSON 包含可选 Base64 JPEG；**删除**需要确认，仅删除选中的本地记录。

保存的时钟为 Android 单调时间；保存日期另用墙钟。语音入队不证明已听到，震动请求不证明实际触感；记录不是障碍真值。记录帧与图像抽帧可能不同步，回放会注明无画面或 2 Hz 抽帧。

## 安装朝向粗检查

展开 **安装朝向检查**，固定设备和背景，依次采集背景、画面中央、左侧、右侧。
目标需比背景近至少 20 cm，上下尽量居中；每步 2 秒、至少 5 个不同的新 ToF 帧，要求双路实时完整输入。
断流会终止当前步骤，会话或实时/回放模式改变时清空检查。结果只是与用户声明摆放位置的粗一致性，未完成像素、视场或距离标定，不自动调整方向或几何参数。

## 分路降级

Wi-Fi 两路新鲜度独立检查，原 750 ms 上限不变：

- 两路有效：实时画面与 ToF 判决。
- 相机不可用、ToF 有效：清除旧画面，明确显示并提示 **仅测距模式**；基础 ToF 判决继续。
- ToF 不可用、相机有效：只显示新鲜画面，判决为 UNKNOWN，停止障碍提醒并提示测距中断。
- 两路不可用：不显示旧画面，不保留旧判决。有效测距流不代表每个区域有效，无效区域仍被原规则拒绝。

## 事件式反馈

- 首次有效障碍触发立即提醒；持续触发每 12 秒提醒一次。距离相对上次提醒缩短至少 300 mm、间隔至少 1 秒时追加“前方测距变近”。这只是读数变化，不表示追踪到同一物体或估计碰撞时间。
- 非触发持续至少 1 秒后重新允许首次提醒；短暂抖动不反复启动事件。非触发与 UNKNOWN 都不会播报安全或可通行。
- 曾经有效的实时输入中断时只提醒一次；恢复时播报恢复，若同时触发则合并障碍提示。初次未连接不循环播报失联。
- 语音和震动独立控制，设置随 App 保存；回放两者均关闭，离开页面停止连接与反馈。当前不提供锁屏持续运行模式。
- 离线页面有直接重连按钮；发现、时钟、新鲜度和几何规则仍使用既有协议。

## 手机热点直连

相机与 XIAO 8×8 ToF 各自加入手机的 2.4 GHz 热点，App 直接接收 MJPEG 与
64 区测距。电脑仅用于首次刷写、配网与开发；运行不需要电脑中转或 ADB reverse。
两块板仍需 USB 电源（可使用移动电源），不要求 USB 数据连接。

1. 手机开启与已配网凭据一致的热点，频段包含 2.4 GHz。
2. 给两块硬件供电。首次配网通过 `host/provision_wifi.py` 读取忽略目录中的
   SSID/password JSON，经物理 USB 写入硬件 NVS；凭据不进入仓库。
3. 打开 App 进入原首页，点击 **开始辅助** 后进入 **前视感知**，自动发现两个设备；**结束辅助**回到首页。
4. 若未找到，打开 **设备连接 → 自动发现**，或填入两块板的局域网 IP 后连接。
   **网络设置**可进入手机无线设置。局域网路由器也可使用相同协议。
5. 展示页以相机、最近触发读数和有效区数量为主体；展开 **感知数据** 显示原始热图，
   可查看数据时龄。未完成相机—ToF 空间标定，不显示伪造的目标框或像素映射。

相机使用最新帧替换及 UDP 单调时钟映射；ToF 独立以固定 10 Hz 采样，新样本通过
UDP3335 主动推送。手机每秒续订，租约五秒，到期自动停止发送；HTTP 保留诊断用途。
两路时龄上界均包含各自的时钟误差界；这些不是屏幕发光或语音输出延迟，ToF 时间戳
是读出完成，未包含此前感测和 I²C 时间。两路独立采样，不声称曝光同步。
无线任一路超过 750 ms 或时间/数据无效时，该路单独失效；相机握手失效清除画面，ToF 失效清除判决，详见分路降级。
设备重启会重建相机时钟与序号状态；前后台切换停止连接及语音。

ESP32 演示传输是可信局域网内的明文 HTTP/UDP，未提供设备身份认证或 TLS。
Android 为动态热点地址允许明文网络；无线展示端点仅接受 RFC1918 数字 IPv4，
HTTP 80/流 81，不接受任意域名、凭据 URL 或跳转。应仅连接用户自己的演示硬件。
USB 中转作为可选兼容入口保留；需要刷回对应 USB 固件，不会与无线固件同时采集。

## 展示方法

选用基础 **ToF 完整区域支持与前方走廊相交**，不选 A*、学习增强或
校准分数筛选。来源是 `ba_camera_corridor.py::tof_readout`，无需模型权重、
RGB 语义类别或 CNH。原始 nominal-45° 模拟基线在已消费 96 帧中为
30 TP / 19 FP / 6 FN、5/6 事件；后续校准版本为 30/15/6，因此这里明确
选择较基础、有误报代价的版本。详见 [原始结果](../research/active/dtr-r0/nearfield/TOF_FOV45_20260920.md)。

硬件适配保留完整区域角范围，以径向测距区间换算轴向范围，再判定是否与
X±0.30 m、Y[-0.20,0.90] m、Z[0.30,3.00] m 相交。45°方形视场、
`0.13 + 0.06 × range` 距离半径和当前装配粗朝向都是展示工程假设，
没有完成实物标定；上面的仿真成绩不属于此硬件版本。它不规划绕行路线。

仅 status=5、有目标、quality=KNOWN 且距离>3 mm 的区域可贡献提示；
某一区无效不会覆盖其他独立有效区域。1–3 mm 是已有异常的排除规则，
不是实物精度保证。缺失、畸形网格、停止采集、断连、过期均为 UNKNOWN；
未提示也不代表可通行。极近处和视场外不在此走廊定义的覆盖承诺内。
