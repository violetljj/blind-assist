## 维护规则

- 当前行为变化：更新对应 `current` 文档。
- 发布事实：写入根目录 `CHANGELOG.md`。
- 详细执行和验证：写入根目录 `DEVELOPMENT_LOG.md`。
- 一次性研究或审计：使用带日期文件，并明确标记为 snapshot。
- 新增文档时同步更新本索引，避免只依赖文件名发现内容。
