# BlindAssist 前沿论文精读与升级报告：项目概览

## 基本信息

- 报告类型：中文工程研究与技术提升报告
- 学科领域：移动端计算机视觉、视频语义分割、助盲导航、人机交互与安全评测
- 暂定题目：从轻量分割到事件级安全感知：BlindAssist 前沿论文精读与跨越式升级路线
- 用户确认：2026-07-13 明确要求下载上一轮推荐论文、精读、详细分析并形成建设性提升报告
- 输出格式：Markdown
- 当前阶段：S1 Evidence

## 研究背景

BlindAssist 已完成 SANPO 来源、split、跨后端、量化和连续场景晋级门的工程化建设，但轻量分割候选仍出现显著的模型初始化方差、step/curb 场景弱、boundary 与 unknown 不稳定等问题。研究任务不以追逐单次 mIoU 为目标，而是寻找能同时改善最差 seed、最差 session、事件级召回、误提醒和端侧预算的机制。

## 研究目的

1. 从已核验的一手论文中提炼可迁移机制，而非做论文摘要堆叠。
2. 区分可立即实验、需要先补证据、仅适合作为长期路线的工作。
3. 给出与现有训练协议、数据门、INT8 门和设备事件门兼容的升级方案。
4. 形成可预注册、可证伪、可回退的实验路线和优先级。

## 研究方法

- 下载并校验论文全文，记录官方来源、会议/期刊、文件哈希和页数。
- 按边界结构、跨域与噪声、不确定性、时序建模、助盲任务与人因五个主题精读。
- 每篇形成问题、机制、证据、局限、迁移点、最小实验和失败条件七类笔记。
- 建立 evidence-claim map，再综合为技术路线与实验矩阵。
- 对报告执行规范符合性审查、证据覆盖审查和引用/文件验证。

## 输出结构

1. 执行摘要与当前瓶颈
2. 文献证据地图
3. 五条技术路线的综合分析
4. 推荐架构与训练/校准/时序链路
5. 分阶段实验计划与晋级门
6. 风险、反例与停止条件
7. 结论及参考文献
