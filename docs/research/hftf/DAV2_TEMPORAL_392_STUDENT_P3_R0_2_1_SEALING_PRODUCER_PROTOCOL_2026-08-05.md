# P3 R0.2.1 sealing producer protocol

The private-target, key-generation, authenticated sealing and aggregate-coverage producers are frozen before any locked Bonn depth target is derived.

Truth uses the existing project clearance operator with the official Bonn intrinsics and registered depth divided by 5000 metres. The three lateral bands, second-percentile clearance and 1.5 m occupied boundary are fixed. Unavailable ground or band clearance becomes `UNKNOWN_GROUND`; the public sensor-evidence field is `independent_metric_sensor_valid`, never the legacy `tof_valid` alias.

The sealed bundle is an accurately named deterministic encrypt-then-HMAC local envelope. The coverage producer may disclose only aggregate clip, parent and transition counts. If any frozen gate is insufficient, the route stops as not evaluable and the cohort cannot be replaced.

No target has yet been read under this protocol. No model, optimizer or training runtime is involved.
