# Codex 精简长任务交接模板

> 仅在任务跨窗口，或同时具备两项以上状态风险时使用：多阶段、多代码/文档区域、昂贵验证、设备/外部操作、共享 worktree 干扰、等待用户决定。每个独立任务使用一份 `artifacts.local/work/codex-handoffs/<TASK-ID>.md`，并在同目录 `INDEX.md` 登记。`TASK-ID` 为全大写的 `DOMAIN-OUTCOME-ROUND`，例如 `SANPO-PUBLIC-SILVER-R7`。正常交接应少于 20 个非空行；链接证据，不复制大段输出。

## 续作规则

续作前先阅读此文件，并核验声明的 worktree / 分支、执行 `git status --short` 与“已验证”中声明的必要检查。只允许操作“允许修改的路径”；旧记录只提供线索，未经核验不得当作当前事实。若现场与交接不一致，停止实施，先记录差异。

目标、阻塞和下一步不得创建人工采集、人工标注、人工审核、人工仲裁或人工验收任务。缺证据时必须写成合法自动替代、模型/Agent 补采、隔离/拒收或局部分支 fail closed；只有真实授权、凭据或用户选择等不可伪造的外部权限，才可写为等待用户决定。
