### 先扣除数值和解码问题

两密集模型使用CE＋前景Dice训练，并按验证mIoU选模，没有直接优化最终指点质量。分割评价聚合全部像素，指点取某类分数的单个空间最大值；改善区域大部分像素而保留一个错误尖峰，就可能出现mIoU升、点命中降。DINO原生输出28×28，Seg为多尺度112×112，细节瓶颈是可检验解释之一，但预训练、参数与损失交互尚未被控制，不能仅凭网格大小下结构因果结论。

[此前完整点差诊断](DINO_POINT_GAP_ANALYSIS.md)已复现IIT全部原坐标、命中和混淆矩阵。相同稳定log-odds读点时，Seg3,351、DINO3,330，原始净差−73缩至−21；其RGB组区间跨零。DINO最大连通域内部点3,384/3,821，超过其原峰值105次，Seg同规则却净损失170次。数值／固定几何改善不是模型结构创新，也不能选择性只给某模型用更好的规则。

自然图来源小区域中，固定三个候选的GT oracle只有209/392（53.32%），远低于总体91.81%；纯排序旧三点受限。该来源原始命中Seg172/392、DINO186/392，与captured小区域1,199/1,243、1,100/1,243明显不同。应检验真实局部证据与新点生成，不能只拟合采集图片上的中心／大连通域先验。

**UMD本轮仍使用原固定softmax峰值，没有运行上述稳定／内部点对照。** 因而其9.56个百分点差距不是已经证明可由新结构恢复的收益。后续任何结构比较必须先给两方同样的稳定、温度与内部点强对照。

## 值得做的结构研究：优先级与对照

### 优先：真实细节、新候选、最终点质量联合学习

建议把“粗语义热图→选最高峰”改成一个可学习定位系统：全局语义分支保留类别／上下文，stride4/8图像特征或小范围原图细节分支提供实际边缘、薄柄和局部部位信息；预测新的区域／坐标候选，再由视觉证据及预测形状共同估计最终点的命中与内部质量。不能只把28×28相同token插值放大后称获得高分辨率证据。

监督可从已有IIT人工mask自动生成：语义区域、内部距离／边界余量、候选命中及错部位／背景困难负点，无需逐点人工标注。细长合法区域不能因腐蚀标签全部消失。推理只读图像、查询和模型输出，不读GT。该机制同时覆盖无好候选与有好区域却指错位置，比单独重排三个旧点更符合当前错误结构。

**最弱假设：**真实细节与联合目标在同等资源下能解决现有错误，而非普通高分辨率解码、训练目标、增强、标注偏差已能解释全部收益。DINO／Seg直接横比不能回答这个问题。

后续最小有辨识力的模型组应固定同一骨干、预训练和可训练层：

| 对照／消融 | 要排除的解释 |
| --- | --- |
| 原头＋相同稳定峰值、温度、最大连通域内部点 | 浮点与固定解码就能改善 |
| 普通高分辨率FPN／卷积头，真实低层特征；PointRend式粗到细强对照 | 只是更高分辨率／通用细化有效 |
| 同参数普通辅助头；给基线相同点质量监督与选模规则 | 只是参数更多、新损失或换了checkpoint |
| 仅局部细节／仅点质量／二者联合 | 新候选与质量选择分别贡献什么，是否有交互 |
| 相同预算的尺度、背景、颜色增强及源平衡 | 跨源提升仅由普通数据配方造成 |

共同记录mIoU、点命中、自然图小区域、逐类、按来源组区间，以及前景外溢／其他类错误。尤其要防止“涂更大面积换点命中”。预先固定验证选模指标，不能一个按mIoU、另一个事后按点选最好。当前IIT/UMD都已被用于设计，不能再称未见确认集；后续需预先隔离新来源或对象／场景组，完整保留现有结果。

### 次优先：跨源前景和类别证据的结构约束

跨源背景外溢、grasp／cut细节和display通道干扰提示，可以检验局部功能形状与全局物体语义的分解，或共享前景质量与类别证据的一致性。先做查询对背景分数、普通增强／类平衡／损失及相同解码控制，确认后再加模块。不能把UMD上未穷尽标注的类直接当所有训练负例，不能用屏蔽未共享通道获得的结果替换原协议。

这可与上一结构共享表示，暂不堆第三个独立创新点。若简单配方已经消除差距，应如实保留简单方案。

### 条件保留：动作条件的部位绑定

PLSP显示同图动作切换值得研究，但当前最突出的刀具动作缺少不同空间训练目标。先在确有独立训练区分信号的动作对上检验同等训练数据和等预算模型，再决定是否需要显式动作—局部部位交互；对训练目标模糊的组合保留不确定性。现阶段不建议把纯PLSP动作融合改头当主创新，也不建议把语义blade／handle配对包装成真实操控角色。

存在性／拒答可作为未来独立问题；本轮没有完整自然缺席监督和相应分母，不能据正类置信度直接宣称可靠拒答。
