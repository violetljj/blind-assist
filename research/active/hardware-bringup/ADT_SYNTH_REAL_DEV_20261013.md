# ADT 真实与合成画面逐帧配对：合成画面能否替代真实画面研究误报

2026-10-13，执行者 Claude。数据为 Aria Digital Twin Dataset, Meta Reality Labs Research。规则在运行前写入 `adt-eval-20261013/PLAN_SYNREAL.md`。clean_seq131 和 meal_seq131 两段（968 帧），时间戳、GT 深度和姿态完全相同，只把 RGB 换成 ADT 自带的同帧合成渲染。DAV2-S 原版，2/3 确认。

| | 真实 v3 / v6 | 合成 v3 / v6 |
|---|---|---|
| 理想尺度：误报率（负例 417） | 4.56% / 2.40% | 4.32% / 2.64% |
| 理想尺度：检出率 z ≤1.5 m（正例 1143） | 91.0% / 90.6% | 93.1% / 92.7% |
| 模拟 ToF 锚定链：误报率 | 6.00% / 3.36% | 6.00% / 4.08% |
| 模拟 ToF 锚定链：检出率 z ≤1.5 m | 69.4% / 68.2% | 80.1% / 79.6% |

**判定**：合成画面在理想尺度下的误报率约为真实的 0.95 和 1.1 倍（规则要求 ≥0.7），检出率相差 2.1 个百分点（规则要求 ≤5）。所以**对于 DAV2 形状误差和误报这个问题，合成画面可以作为替代**，ASE 可以用于这类读出或误报研究。

**保留**：在锚定链上，合成画面的检出率高出约 11 个百分点。合成画面的视差与 GT 更一致，模拟 ToF 拟合更容易成功。所以凡是涉及锚定或尺度的结论，用合成数据会偏乐观，必须在真实数据上检验。样本只有两段、一套公寓，负例 417 个，结论只适用于“能否当研究替代”这一用途。
