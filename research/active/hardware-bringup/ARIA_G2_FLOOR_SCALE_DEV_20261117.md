# 眼镜视角户外：用 VIO 重力加已知眼高做地面锚定，能否顶替 ToF 定尺度（Aria 第二代试点）

2026-11-17，EXPLORE。接 [SANPO 户外初筛](SANPO_SCALE_WITHOUT_TOF_DEV_20261117.md) 和 [SANPO 位姿核对](SANPO_POSE_GRAVITY_CHECK_DEV_20261117.md)。
SANPO 中地面锚定只在“真值重力”下接近形状上限，而 SANPO 的位姿不能当重力用。
本问改用一份有可用重力的眼镜数据，检验**真实 VIO 重力**下的户外地面锚定。

## 数据（Aria Gen 2 Pilot Dataset v1.0，CC BY-NC 4.0）

- walk_0、walk_1：同一次约 5 分钟的户外步行，两名佩戴者，各 8983 帧左右（30 FPS），轨迹约 214 m，平均速度约 0.7 m/s。
- 用户 2026-11-17 在网页提交访问表单并同意许可。只下载了 `depth`、`mps_slam_trajectories`、`mps_slam_calibration` 三项，
  共 6 个文件，全部通过大小和 SHA1 校验（收据：`artifacts.local/downloads/aria-gen2-pilot-20261117/RECEIPT.json`，不存签名链接）。
- 深度参考：官方用 FoundationStereo 在前向两枚 CV 相机上算出的立体深度。512×512 矫正针孔，焦距约 309 px，视场约 79°，单位 mm，沿射线距离。
  它是**伪真值**。
- 模型输入：与深度同一像素网格的矫正**灰度图**（复制成 3 通道），无需跨相机配准。最终产品是彩色相机，这一点有差别。
- 重力：`T_world_camera` 所在的世界坐标与重力对齐（轨迹中重力为 (0, 0, −9.81)），由每帧位姿得到相机坐标中的“下”方向。
  这是 MPS 离线精修的 VIO，比眼镜上实时算出的重力略准。

## 方法（运行前写定）

**抽帧**：每 15 帧取 1 帧（2 Hz），两段约 1200 帧。以每 30 秒为一块（每段 10 块，共 20 块）作为汇总单位。
两段是同一路线，块之间不独立，所以只作描述性汇总。

**参考地面与眼高**（评估端，不用语义，只用几何）：
- 每帧用参考深度点，以 RANSAC 拟合地面平面，要求法向与 VIO 重力的夹角 ≤ 15°，取相机下方内点最多的平面；内点至少 2000 个才算拟合成功。
- 每段取逐帧相机离地高度的中位数作为“已知眼高”。
- 非地面像素：参考点离拟合地面的高度 > 0.15 m。

| 臂 | 尺度来源 |
| --- | --- |
| A | DAV2-S + 模拟 ToF：与相机共轴的 45° 8×8 区，区距离取参考深度；仿射拟合，失败时用稳健拟合，再失败沿用上一帧 |
| B_ref | DAV2-S + 地面锚定，重力取参考地面法向（完美重力参照） |
| **B_vio** | DAV2-S + 地面锚定，重力取 VIO 位姿，眼高取每段中位 |
| B_vio ± 眼高误差 | 同 B_vio，眼高分别加 −10、−5、+5、+10 cm（描述） |
| C / D | DAV2-Metric-Hypersim-Small / UniDepth-V2-S 原始公制输出（描述，灰度输入） |
| O | DAV2-S 逐帧用参考深度做仿射（形状上限） |

地面锚定沿用项目原规则：取射线落在前方 0.8–6 m 地面的像素，以 RANSAC 拟合视差 = a·(1/z) + b。

**指标**：
- 近场非地面（主）：参考距离 0.5–3 m，非地面，每帧至少 200 像素；
- 近场（辅）：参考距离 0.5–3 m；
- 走廊障碍（辅）：左右 ±0.30 m、前方 0.30–2.0 m、离地 0.15–1.9 m，每帧至少 200 像素。

每帧取 AbsRel 中位与 δ1，先在块内取中位，再在块间取中位。同时报告锚定成功率，以及 VIO 重力与参考地面法向的夹角。

### 判据

- **成立**：主区上 B_vio 的 AbsRel ≤ 1.25 × A，且 B_vio 锚定成功率 ≥ 90% → 户外眼镜视角下，“VIO 重力 + 已知眼高”可以给单目深度定尺度，不依赖 ToF。
- **不成立**：B_vio 的 AbsRel > 2 × A，或成功率 < 70%。
- 其余为不确定。眼高误差各组、C、D 和走廊区只做描述。

## 结果

规则和脚本先提交（39a1fc06）。之后有三次运行，判定规则都没有改：

1. **第 1 次中断**：每帧的矫正内参略有不同（焦距逐帧差 0.06–0.13 px），被断言拦住；同时改为两遍读取，避免内存过大（c92851c5）。
2. **第 2 次作废**：我按文档把深度 PNG 当作“沿射线距离”换算，而实际存的是**光轴深度**。
   - 现象：眼高只有 1.04 m，VIO 重力与参考地面夹角约 12°，参考地面锚定成功率仅 62%。
   - 核对：两种理解各拟合一次地面。
     - 按光轴深度：平面内点比例 0.78，与 VIO 重力夹角 1.5°，眼高约 1.5 m；
     - 按射线距离：分别为 0.24、约 15°、约 1.0 m。
   - 这次的判定结果为“成立”，现**作废**。输出保留为 `result_DEFECT_range_interpretation.json`。
3. **第 3 次为有效结果**：按光轴深度读取（60cc1657）。

**数据核对（有效运行）**：
- 1201 帧、21 个 30 秒块；参考地面全部拟合成功。
- 眼高 1.563 m（walk_0）、1.499 m（walk_1）。
- VIO 重力与参考地面法向夹角：中位 1.56°，95 分位 3.28°。

| --- | ---: | ---: | ---: | ---: | ---: |

- **主判据：不确定。** B_vio / A = 1.94（> 1.25 且 ≤ 2），成功率 97%。
- **走廊障碍上地面锚定明显失败**（0.56，δ1 约 0.01），而同一锚定在地面上很准（0.04）。
  完美重力的 B_ref 同样失败，所以问题不在 VIO 重力，而在“用地面拟合的仿射尺度外推到近处障碍物”这一步。
  形状上限 O 在走廊上为 0.083，说明 DAV2-S 的相对形状本身是够的。
- 不做任何锚定的 UniDepth-V2-S，在灰度输入上是最好的“无 ToF”选项（走廊 0.208，δ1 0.58），但仍明显不如模拟 ToF。
- 眼高调低时误差反而下降，与“地面拟合的仿射对近处物体有系统偏差”一致，没有单独检验。

## 含义

- [SANPO 初筛](SANPO_SCALE_WITHOUT_TOF_DEV_20261117.md) 的乐观结果（地面锚定在非地面上接近形状上限）**在这份更大的眼镜数据上没有复现**。
  SANPO 只有 31 帧非地面、CREStereo 伪真值、真值重力；这里是约 920 帧、FoundationStereo 伪真值、真实 VIO 重力。
- 对方向 A：户外“地面 + IMU + 已知眼高”**不能作为近处障碍物的可靠尺度来源**。ToF（哪怕只是共轴 45°）仍然是更好的尺度锚，室内外都是。
  不用 ToF 时，公制小模型 UniDepth-V2-S 是目前最接近的退路。
- 限制：
  - 只有一条路线、两名佩戴者，块之间不独立；
  - 参考深度是立体伪真值；
  - 模型输入是灰度而不是彩色；
  - 模拟 ToF 理想、无噪声、共轴；
  - VIO 是 MPS 离线精修版本。
