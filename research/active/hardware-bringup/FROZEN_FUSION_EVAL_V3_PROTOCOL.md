# 冻结检验 v3：稳健 ToF 锚定 + 2/3 帧确认

2026-10-13 提交，早于新头戴检验数据的录制。执行脚本 [frozen_fusion_eval_v3.py](host/frozen_fusion_eval_v3.py)。开发依据见 [v3 开发报告](FUSION_V3_DEV_20261013.md)。v1/v2 及其协议、脚本、判据不变，同一批新数据三版都跑、都报告。

## 与 v2 的唯一差别

v3 = v2 + 稳健锚定替换。每个就绪帧照 v1 用 ToF 区距离拟合 DAV2-S 视差仿射（`fit_affine`）。若该拟合未通过固定质量合同（`fusion_anchor_candidates_dev_20261013.QUALITY`：≥6 区、逆深度相对跨度 ≥10%、中位相对误差 ≤10%、≥60% 区误差 ≤20%），就用穷举两点共识重拟合（`robust_affine`）；只有新拟合在全部有效区上通过同一合同才替换。其余链路（地面锚定 → 沿用上一帧）、模型、标定、HEAD/BODY 盒子、150 像素门槛、姿态门控、ToF 强档、2/3 帧确认、标签规则与判据全部与 v1/v2 相同。上述文件的 sha256 写入结果。

## 判据（与 v1 相同，逐段、以就绪帧为分母）

- `quiet`：任一 query 融合报警帧占比 ≤10%。
- `side`：融合报警帧占比 ≤30%。
- `ahead`：最后 15 个就绪帧中融合报警占比 ≥50%。
- `head`：最后 15 帧 HEAD 融合报警占比 ≥50%。

**总体主张**：所有 `ahead` 段都通过且所有 `quiet` 段都通过。缺类或零就绪帧写“无法完整评价”。新数据评价后不改标签、参数或判据；三版结果并列报告，不因结果挑版本。
