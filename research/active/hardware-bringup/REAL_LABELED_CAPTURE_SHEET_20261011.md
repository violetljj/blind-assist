# 宿舍最简 CNH 录制操作单

**一次完成：10段，每段30秒，录制共5分钟，连摆放约20分钟。不需要等到晚上。**

**材料：**椅子、纸箱、胶带、拖把杆或扫把柄、一本书、手机。无需卷尺、三脚架。

**先固定：**椅子上放纸箱，ToF尽量水平向前，用胶带固定，松手后不晃。启动只问一次大约离地高度（cm，可估）。先关闭占用COM5的演示/串口监视器。

**按提示操作：**摆好→回车→自动测距→回车→倒计时3秒→录30秒。杆的距离读不准时，按提示在杆的位置放书→回车测距→拿走书。结束回车继续，`r`重录；准备时`s`跳过。照片可选，在准备提示中填文件名即可，不拍也能录。

| 段 | 怎么摆 |
|---|---|
| 1 近无回波 | 阳台上让测距头视线越过栏杆朝外，不隔玻璃、避开衣物；人和支架留在栏杆内。只录一次。 |
| 2 墙近 | 正对左白墙，约0.6m；脚本显示实际测距。 |
| 3 墙远 | 正对同一左墙，退到约1.5m。 |
| 4 空通道（明） | 门口端过道中线朝窗帘，清空中线附近地面杂物，保持白天明亮设置。 |
| 4b 空通道（暗） | **支架位置不动**，拉上遮光帘、关灯，再录30秒。与4配对。 |
| 5 竖杆近 | 恢复第4段的窗帘/灯光设置；杆落地固定在过道中线，距ToF约1m，不能手持。 |
| 6 竖杆远 | 同一竖杆移到约2m。 |
| 7 外侧杆 | 杆回到约1m，横向挪一大步（约0.5m）。 |
| 8 头部横杆 | 杆横绑床梯，伸进过道，约额头高度，距ToF约1–1.5m。 |
| 9 重启空通道 | 恢复第4段位置、摆放及明亮设置；按提示拔插重启，再录一次。 |

**三条注意：**①录制时人离开传感器前方与两侧；②带轮物体别动；③换条件尽量只挪整套支架，4/4b之间支架不能挪。

**启动采集台（仓库终端）：**

```powershell
& .\artifacts.local\hardware-bringup\venv\Scripts\python.exe .\research\active\hardware-bringup\host\real_labeled_capture_web.py
```

打开本机页面`http://127.0.0.1:8791`，点“开始/续录”才连接设备；页面显示当前提示，点继续等同回车。中断后再点续录；指定重录填`4b`（其他段换成其编号）。终端版本仍可运行`host/real_labeled_capture.py`，加`--resume`或`--resume --redo 4b`。输出在本机`artifacts.local/work/real-labeled-capture-<date>/`，失败及旧重录段都保留。

4/4b用于比较实际CNH ambient与噪声；脚本记录实测差异，开关灯后不一定产生足够的ToF ambient变化。拉帘也可能改变尽头回波，后处理需排除相关回波bin。距离为固件弱参考、高度为估计，边界不清的query标UNKNOWN。[标注说明](REAL_LABELED_ANNOTATION_PLAN_20261011.md) · [回放核验](REAL_LABELED_CAPTURE_REPLAY_TEST_20261011.md)。
