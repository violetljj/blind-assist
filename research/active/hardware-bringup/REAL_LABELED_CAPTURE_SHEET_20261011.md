# 宿舍最简 CNH 录制操作单

**材料：**椅子、纸箱、胶带、拖把杆或扫把柄、一本书、手机。无需卷尺、三脚架。

**固定设备：**椅子上放纸箱，ToF尽量水平向前，用胶带固定；手松开后不晃。启动时只填一次大约离地高度（cm，可估），不填其他测量表。先关闭占用COM5的演示/串口监视器。

**怎么录：**每段按提示摆好→回车；脚本自动读中央距离，必要时提示“在杆的位置放一本书→回车读数→拿走书”；再回车，3秒倒计时后静止录30秒。结束按回车继续，输入`r`重录；准备阶段输入`s`跳过。照片可选：拍一张后在准备提示中输入文件名，直接回车也能继续。

| 段 | 白天按这个顺序摆放 |
|---|---|
| 1 近无回波 | 阳台上，让测距头视线越过栏杆朝外，不隔玻璃，避开衣物；人和支架留在栏杆内侧。 |
| 2 墙近 | 正对左白墙，约0.6m；自动测距会显示实际读数。 |
| 3 墙远 | 仍正对同一左墙，退到约1.5m。 |
| 4 空通道 | 门口端过道中线朝窗帘，清空中线附近地面杂物。 |
| 5 竖杆近 | 拖把/扫把杆落地固定在过道中线，距ToF约1m，不能手持。 |
| 6 竖杆远 | 同一竖杆移到约2m。 |
| 7 外侧杆 | 杆回到约1m，横向挪一大步（约0.5m）。 |
| 8 头部横杆 | 杆横绑床梯，伸进过道，约额头高度，距ToF约1–1.5m。 |
| 9 重启空通道 | 恢复第4段；按脚本提示拔插重启，再录空通道。 |
| 10 夜间近无回波 | 夜间关灯、拉帘，重复第1段；阳台测距头仍不能隔玻璃。 |
| 11 夜间空通道 | 保持关灯、拉帘，重复第4段。 |

**三条注意：**①录制时人离开测距头前方与两侧；②带轮物体别动；③换条件尽量只挪整套支架，不改变板子的安装。无需为了满足名义尺寸反复调摆放。

**启动命令（在仓库终端）：**

```powershell
& .\artifacts.local\hardware-bringup\venv\Scripts\python.exe .\research\active\hardware-bringup\host\real_labeled_capture.py
```

白天完成后退出；夜间同命令加`--night`。中断后加`--resume`，夜间中断则加`--night --resume`。跨天夜间仍续接最近的宿舍版录制目录；需要指定某次时加`--output artifacts.local/work/real-labeled-capture-YYYYMMDD`。

共11×30秒=**5.5分钟有效录制**，另加摆放、自检与倒计时。原字节、帧、主机时间和元数据只保存在本机`artifacts.local/work/real-labeled-capture-<date>/`，失败段与旧重录段保留。距离是固件弱参考，高度/姿态是估计；“空/有目标/外侧”是条件预期，边界不清楚的query以后标UNKNOWN，不当精确真值。[标注说明](REAL_LABELED_ANNOTATION_PLAN_20261011.md) · [回放核验](REAL_LABELED_CAPTURE_REPLAY_TEST_20261011.md)。
