# 方向 A 实验 1：用 ToF 只校正一个尺度系数的公制小模型，是否优于 ToF 仿射锚定的相对深度

2026-11-17，EXPLORE。方向 A（用户 11-17 同意）：宽视场 RGB 负责“看”，ToF 负责定尺度，UniDepth-V2-S 作为 ToF 失效时的退路。
评估用 [评估协议 v1](evalkit/EVALKIT.md)，数据为 Aria 第二代试点 walk_0/1（1201 帧）和本地 SANPO（50 帧，只有负样本，只看误报）。

## 想法

- 现做法 `tof_dav2s`：用 ToF 的 64 个区对 DAV2-S 相对视差拟合仿射（两个参数），再推到整幅图。
- 新做法 `tof_unidepth`：UniDepth-V2-S 本身输出米，误差主要是整体尺度偏差（SANPO 约 30%）。
  只用 ToF 估**一个缩放系数** s，取各有效区“ToF 距离 / UniDepth 距离”的中位数，有效区少于 5 个时沿用本段上一帧的 s。
  预期在 ToF 视场以外更稳，因为公制模型本身保持了透视。

## 方法（运行前写定）

| 臂 | 内容 |
| --- | --- |
| tof_dav2s | 现做法（理想 ToF：共轴 45° 8×8，区距离取参考深度，0.3–4 m） |
| **tof_unidepth** | UniDepth-V2-S × s（理想 ToF） |
| tof_dav2s_out / tof_unidepth_out | 户外受限 ToF：只保留 ≤ 2.85 m 的区（L8CX 规格中强环境光下的量程），每区乘 (1 + N(0, 3%)) 噪声，种子由帧号固定 |
| unidepth_s | 不校正（退路参照） |
| oracle_dav2s | 形状上限 |

附加分析：近场非地面像素按是否在 ToF 视场内（相机坐标水平、垂直角都在 ±22° 以内）分开计算 AbsRel。

## 判据（Aria，理想 ToF，tof_unidepth 对 tof_dav2s）

主指标：走廊低矮带与躯干带 AbsRel 的平均（各自取块中位后平均）。

- **采用 tof_unidepth 作为方向 A 的尺度核心**：主指标降低 ≥ 15%，且两带严格负误报帧比例各自升高不超过 0.03，两带检出各自降低不超过 0.02。
- **保留 tof_dav2s**：主指标升高 ≥ 15%，或误报、检出任一项超出上面的容差。
- 其余为不确定。

户外受限 ToF、视场内外、SANPO 误报、头部带都只做描述。
