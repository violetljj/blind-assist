# 短时地面记忆：设备能否判断"盲杖会先碰到"（2026-10-15，EXPLORE）

承接 [盲杖可达性重标](ADT_CANE_REACH_DEV_20261015.md)：ADT 行走场景中约九成 v6 报警针对盲杖会先碰到的东西。本轮检验一个因果（只看过去）的估计器能否据此压掉冗余报警。

## 规则（运行前写入脚本）

- 头戴相机平视时看不到脚前地面，但行走时 1–3 秒前看过。估计器只融合**过去 3 秒**（含当前帧）的地面带点（离地 0.05–0.30 m），3 cm 体素，走廊 ±0.30 m、前方 0 至"身体距离 + 0.15 m"，≥3 体素判为"盲杖会先碰到"，压掉该帧 v6 报警。带宽、余量、体素阈值与真值标注完全相同。
- A 臂（gt）：记忆和身体距离都用 GT 深度——因果记忆的可见性上限。
- B 臂（chain）：用设备自己的锚定 DAV2 深度（v6 同链：ToF 拟合 → 稳健替换 → 地面锚定 → 沿用；模拟 ToF；`adt_chain_depth_dump_dev_20261015.py` 导出，步长 2）。
- 两臂位姿均用 GT（真实设备需惯导/视觉里程计，未检验）；真值标签与分层同前（行走；行走且 0.8 m 内无动态物体）。

## 判读

1. **因果记忆在原理上足够**：只看过去 3 秒的 GT 深度，就能压掉约八成"盲杖会先碰到"的报警，几乎不损失盲杖漏检物（35→34/38）。
2. **换成设备深度后效果大体保留**：冗余同样压掉约八成，报警总量降约四分之三；代价是盲杖漏检物检出 35→31/38（行走全集 105→86/116，后者含手持物污染）。被误压的原因可能是 DAV2 把物体下部或墙脚估成了地面带内的支撑，本轮未逐例拆解。
3. 设备深度还顺带压掉部分负例误报（33→19），机制未拆分，不作结论。

## 边界

ADT 一套公寓、家务为主；盲杖漏检物只有 38 个近距帧，来自少数物体；ToF 为乐观模拟；位姿为 GT；3 秒窗口与其它参数一次设定，无敏感性分析；不代表真实佩戴效果。
