# ADT 上的四个新方向：更强深度模型、世界一致性、联合锚定、ToF 朝向

2026-10-13 至 10-14，EXPLORE，执行者 Claude。数据为 Aria Digital Twin Dataset, Meta Reality Labs Research（非商用研究许可，帧和派生物不分发）。每个方向的判定规则都在运行前写入 `artifacts.local/work/adt-eval-20261013/PLAN_BACKBONE_MOTION.md`、`PLAN_JOINT_ANCHOR.md`、`PLAN_TOF_TILT.md`。ADT 13 段 5825 帧（约 5 Hz），口径不变：query 帧、2/3 确认；误报率 = 报警 / GT 盒内 0 像素的 query 帧；检出率 = 报警 / GT 盒内 ≥150 像素且中位深度 ≤1.5 m 的 query 帧。

## 结论先说

**最大的杠杆不是深度模型，而是 ToF 的朝向。** 现在的 ToF 光轴基本水平（ADT 模拟中位在水平线下 3.5°，自录数据下 5°），±22° 的视场只盖住警戒盒内 17% 的障碍像素；DAV2-S 误报像素团有 92% 落在 ToF 视场之外。把 ToF 再往下转 25–30°，用真值模拟的系统检出率从 85.1% 升到约 93%，加上“ToF 视场内没有回波就否决 RGB 像素团”后误报率还比现在低（6.7% → 6.1%）。RGB 改用下倾后的 ToF 锚定，效果更明显：DAV2-S 的 RGB 支路检出 80.6% → 88.3%，误报 5.93% → 5.69%；检出 ≥80% 时的最低误报 5.3% → 3.1%，接近理想尺度（3.25%）；系统检出 93.7%、误报 6.6%（现在 85.1%、6.7%），按预先规则通过。这是一个只改安装角、不加硬件的改动，需要重新标定相机–ToF 外参，再录一批验证。

**换更强的深度模型帮助有限**：同样的读出和锚定，DAV2-L（公制 Hypersim）、MoGe-2-L、UniDepth-V2-L 在检出 ≥80% 时的最低误报为 4.6%、4.3%、4.0%（DAV2-S 5.3%），低 13–25%，不到预先要求的“误报减半”，也不如 DAV2-S 配下倾 ToF（3.1%）。把 DAV2-S 换成大 14 倍的模型，收益不如把 ToF 转个角度。

## 1. 更强的深度模型：有改善，不是突破

脚本把每帧每个盒内像素团（≥10 px）存成 [像素数、中位深度、质心]，读出规则全部离线回放；DAV2-S 的 v3/v6 读出与原 ADT 评测逐帧一致（样例段 100/100）。“链路”= 与 v6 相同的 ToF 锚定链（公制模型用 1/深度当视差）；“原始”= 公制模型自带尺度、不锚定；“扫描”= 在像素门槛（50–900）× 像素团深度上限（1.2–2.0 m）上扫，取检出达标时的最低误报（事后扫描，只用于比较模型的区分力）。

| 模型（参数量） | 链路 v6：误报 / 检出 | 扫描：检出 ≥80% / ≥85% 时最低误报 | 原始尺度 v6：误报 / 检出 | 理想尺度扫描 ≥85% |
|---|---|---|---|---|
| DAV2-S（25M，现用） | 5.93% / 80.6% | 5.3% / 达不到 | — | 3.6% |
| DAV2-L 公制 Hypersim（335M） | 7.45% / 85.5% | 4.6% / 6.9% | 5.55% / 37.2% | 3.9% |
| MoGe-2-L（~330M） | 6.61% / 87.0% | 4.3% / 4.9% | 11.3% / 88.5% | 4.0% |
| UniDepth-V2-L（~350M，已知内参） | 6.32% / 88.3% | 4.0% / 4.7% | 4.91% / 82.9% | 3.8% |

判定（误报 ≤0.5 倍 DAV2-S 且检出不降超过 2 个点）：**都不达标**。大模型的主要好处是检出高 5–8 个点；同检出下误报低 13–25%，最好的是 UniDepth-V2-L。理想尺度下四种模型差不多（3.6–4.0%），说明盒内读出的上限主要受尺度/锚定限制，模型形状精度的差别是次要的。公制自带尺度：UniDepth 不锚定也有 4.91% / 82.9%（已知内参，比 DAV2-S 链路好），DAV2-L 检出只有 37%，MoGe 误报 11%。

大模型约慢 4–15 倍（RTX 5060 单帧：DAV2-L 约 0.2 s，MoGe-2-L 约 0.45 s），手机上更不现实。

## 2. 世界一致性规则：不成立

思路：人在走时，真实障碍在世界坐标里不动，深度估错的“幽灵”会跟着人走。规则：走路时（GT 水平速度 ≥0.3 m/s），当前帧计数的像素团用 GT 位姿搬到 1 s 前那一帧，若那一帧的预测点云在同一高度带、半径 0.2+0.1z m 内少于 3 个点，就不计。

| DAV2-S 链路 | 误报率 | 检出率 | 走路时近处（≤0.7 m）检出 |
|---|---|---|---|
| v6 | 5.93%（168/2831） | 80.6%（5482/6804） | 67.3% |
| v6 + 世界一致性（GT 位姿） | 5.30% | 78.4% | 61.5% |
| 再加“站着时只认 ≤1.0 m” | 4.38% | 73.4% | 61.2% |

判定要求误报降 ≥25% 且检出降 ≤2 个点，**不达标**。用当前头朝向 + GT 速度或固定 1 m/s 代替 GT 位移，结果更差。

原因：坐标变换没问题（真值盒内占据格有 96% 能在 1 s 前的真值里找到）。但模型预测的盒内占据也有 94% 能找到，因为估错是“稳定地估错同一处结构”，墙面、地面这种大面在前一帧也会落在附近。误报像素团到同高度带最近真实结构的中位距离是 1.27 m，它们不是贴着真实物体的小偏差，却同样前后一致。

自录 23 段（已用数据，仅诊断）用 IMU 估运动（陀螺积分转向，加速度幅值步频 × 0.65 m 估速度；自录步伐很轻，2 s 窗口幅值标准差只有 0.015–0.04 g，阈值看过数据后从 0.04 降到 0.015）：走廊误报段 054159 0.37 → 0.37、054301 0.41 → 0.40，基本没动；反而迎面走近扫把的 054437 头部末段 1.00 → 0.33。真目标被否决、误报没被否决，与 ADT 一致。**关闭。**

## 3. ToF + 地面联合锚定：不成立

同一套 DAV2-S，ToF 区和地面 RANSAC 内点各占一半权重拟合一个仿射。

| 锚定 | 误报率 | 检出率 | 检出率 ≥80% 时的最低误报 |
|---|---|---|---|
| v6 链路（ToF 优先） | 5.93% | 80.6% | 5.3% |
| ToF + 地面联合 | 4.56% | 63.6% | 达不到 |
| 仅地面 | 4.87% | 39.5% | 达不到 |
| 理想尺度（GT 全图仿射，诊断） | 6.68% | 92.7% | 3.25%（检出 84%） |

ADT 公寓家具多，地面拟合不稳，拉低了尺度。**不达标，关闭。**理想尺度一行说明尺度仍有约 12 个点的检出空间，但地面不是可靠来源。

这也修正了 [ADT 评测](ADT_EVAL_RESULT_20261013.md)里“误报来自形状而非尺度”的说法：在固定门槛下，理想尺度的误报确实不更低（6.68% 对 5.93%）；但按相同检出率比较，理想尺度的误报低得多（检出 ≥80% 时 3.25% 对 5.3%），检出还高 12 个点。尺度的作用是存在的，只是在固定门槛下体现为工作点的移动。

## 4. ToF 朝向（真值几何 + 系统模拟）

**覆盖率**（只用 GT，不涉及模型）：GT 正例 query 帧中，ToF 视场内盒内像素 ≥150 的比例。

| ToF 再下倾 | 盒内障碍像素被覆盖 | HEAD query 帧 | BODY query 帧 |
|---|---|---|---|
| 0°（现在） | 17% | 63% | 57% |
| 15° | 44% | 79% | 84% |
| 25° | 68% | 86% | 96% |
| 35° | 76% | 82% | 99% |
| 45° | 66% | 72% | 97% |
| 现有 + 第二颗下倾 35° | 85% | 92% | 99% |

同样的统计换成 60°×60° 视场（±30°，VL53L7 系列的视场；本项目用的是 45° 的 VL53L8CH）：不倾 35%（HEAD 80%、BODY 76%），再下倾 15° 74%（93%、95%），20° 88%（96%、99%），25° 94%（96%、100%）。一颗宽视场 ToF 下倾 20–25° 的覆盖超过“现有 + 第二颗 L8”。代价是每区约 7.5°、更粗；是否有带 CNH 直方图输出的宽视场型号、能否直接替换，需要另查器件资料，这里只给几何上限。

**系统模拟**：ToF 由 GT 深度按我们的区射线和外参模拟（无噪声、无串扰、无暗面丢失，偏乐观）；ToF 报警 = 某区 ≥30% 采样点落在盒内；ToF 否决 = RGB 像素团中心落在某区锥内（4° 内），且该区采样距离只有 <10% 在像素团距离 ±0.4 m 内（直方图上那里没有回波）。RGB 仍是 DAV2-S v6 链路，锚定用的是现有 ToF。

| ToF 再下倾 | 仅 ToF：误报 / 检出 | 融合：误报 / 检出 | 融合 + 否决：误报 / 检出（HEAD / BODY） |
|---|---|---|---|
| 0° | 1.4% / 51.8% | 6.7% / 85.1% | 6.5% / 84.9%（73% / 92%） |
| 10° | 1.9% / 70.0% | — | 6.7% / 89.3% |
| 20° | 2.4% / 81.1% | — | 6.5% / 91.7% |
| 25° | 2.4% / 85.3% | 7.2% / 93.3% | 6.1% / 92.7%（87% / 97%） |
| 30° | 2.8% / 86.8% | — | 6.2% / 93.6%（88% / 97%） |
| 35° | 2.5% / 84.5% | 7.3% / 93.3% | 5.9% / 92.7% |
| 40° | 2.3% / 83.0% | — | 5.9% / 92.5% |

模拟 ToF 的“误报”全部来自 2/3 确认的滞后（物体刚离开盒子），真实 ToF 还会有自己的噪声误报。下倾 25° 时否决掉误报像素团的 42%，只误伤真目标像素的 4%。

**判定**：预先规则是“融合检出 ≥ 现在 +5 个点且误报不升”。只看融合，下倾 25°/35° 检出 +8.2 个点，但误报高 0.5 个点，**严格说不满足**；加上下倾后才有意义的否决，检出 +7.5 个点、误报 6.7% → 6.1%，**满足**。否决本身要求误报 ≤0.75 倍，实际 0.84 倍，不满足。

**真机侧的旁证**：第一批 quiet 走廊段 032738 设备实际朝下约 31°（中位 −31.5°），边走 74 帧 ToF 强报警 0 次；054058、054111 站着低头（−31°、−35°）也都是 0 次。下倾的 ToF 没有把地面当障碍，但只有 3 段 172 帧，也没有覆盖下倾时迎面障碍的检出。

**RGB 也改用下倾 25° 的 ToF 锚定**（重跑 DAV2-S，锚定链不变，只是区射线换成下倾后的）：

| | RGB 支路：误报 / 检出 | 检出 ≥80% / ≥85% 时最低误报 | 融合：误报 / 检出（HEAD / BODY） | 融合 + 否决 |
|---|---|---|---|---|
| 现在的朝向 | 5.93% / 80.6% | 5.3% / 达不到 | 6.71% / 85.1%（73% / 93%） | 6.46% / 84.9% |
| 下倾 25°，锚定不变 | 同上 | 同上 | 7.21% / 93.3%（87% / 97%） | 6.08% / 92.7% |
| 下倾 25°，重新锚定 | 5.69% / 88.3% | 3.1% / 3.9% | **6.57% / 93.7%（88% / 97%）** | 5.93% / 93.1% |
| 理想尺度（诊断） | 6.68% / 92.7% | 3.25% / 3.6% | — | — |

重新锚定后，不加否决的融合也满足预先规则（检出 +8.5 个点，误报不升）。锚定点落在障碍真正出现的位置，RGB 的尺度接近理想尺度，这就是收益来源。否决这时只去掉 14% 的误报像素（真目标 2%），作用变小。

## 边界

- ADT 只有一套公寓，人在做家务，头常低着（相机光轴中位在水平线下 18°）；ToF 模拟是理想化的，真实的串扰、多径、强光和暗面会让 ToF 的检出变低、误报变高。所以数字只用来比较朝向的相对好坏，不代表实际性能。
- 下倾后，ToF 看到的地面更多，现有强档算法和姿态门控是按现在的安装角调的，需要实测确认。头部高度 HEAD 盒的上沿在眼睛上方 0.2 m，下倾后近处头顶以上的障碍更依赖 RGB。
- 世界一致性和联合锚定的负结论只针对这里的规则形式和 DAV2-S。
