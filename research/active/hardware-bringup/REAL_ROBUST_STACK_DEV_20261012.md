# 稳健 ToF 栈：M3/ordinary/S 全部加入干扰与俯角随机化

2026-10-12 · EXPLORE · 执行者 Claude（用户授权）。接续 [俯角敏感性](REAL_PITCH_ROBUSTNESS_DEV_20261012.md)。

## 结论

**在“真实式干扰 + 俯角误差”的部署条件下，稳健栈的提醒质量接近原默认栈在干净模拟上的水平；原默认栈在同条件下几乎处处报警。** 代价是在完全干净的模拟输入上误报更高，因为阈值按“部署时总有干扰”校准，而真机串扰始终存在。

模拟留出（已消费，1536 scene × K2，contact 1024 事件；基线为原 old5）。格式：及时检出 / far+clear 有通知片段率：

| 条件 | 当前默认栈 | 稳健栈 |
|---|---|---|
| 干净 | 86.5% / 9.9% | 82.5% / 15.1% |
| 干扰，俯角误差 −10° | 97.8% / 95.4% | 84.2% / 7.7% |
| 干扰，−5° | 97.8% / 95.4% | 85.2% / 10.0% |
| 干扰，0° | 97.2% / 94.4% | 84.9% / 8.9% |
| 干扰，+5° | 95.1% / 94.1% | 82.8% / 7.0% |
| 干扰，+10° | 84.2% / 94.1% | 77.1% / 5.3% |

其中稳健栈强档（只用 M3）在干扰下为 38–45% / 1.4–3.8%，其余检出由 S 轻提醒补足。

## 做法

- **M3**：沿用俯角+干扰随机化模型（5 seed）。
- **ordinary**：同一批去 bin0 DR 训练直方图，逐行加入相同族的干扰（25% 干净，拖尾 t1~U(0,3)、逐 zone U(0.5,1.5)、直流 U(−0.3,0.8)）和假设俯角误差（80% 行 U(±12°)，作用于特征几何），原配方 3 seed、32 epoch、7488 步，bf16。
- **打分**：cal、S 训练集、6 个负例池在“部署条件”下打分（每个场景一组干扰，俯角误差从 {−10,−5,0,5,10}° 中抽取，25% 干净）；留出集另按干净、各固定俯角误差下全干扰分别打分；默认栈在同样条件下也重新打分作对照。
- **校准**：强档只用 M3、关闭 LOCAL，raised 阈值在部署条件 cal 上匹配原 old5 的 clear 时间格数（80/80）；ordinary single 阈值同条件标定；S 在部署条件 S 训练分数上重拟合；S 阈值在部署条件负例池上取 far+clear ≤ 原 old5 + 3pp 的最低阈值（445+161 → 选中 606/5376）。
- 共用训练数据与评价数据的干扰族相同，属乐观条件。
