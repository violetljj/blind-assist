# ToF 提示的深度补全网络（不达标）

2026-10-14，EXPLORE，执行者 Claude。数据为 Aria Digital Twin Dataset（Meta Reality Labs Research）与 Aria Synthetic Environments Dataset（Meta Reality Labs-R），非商用研究许可；训练出的权重属于派生作品，只放在被忽略的 `artifacts.local`，不分发。判定规则在训练前写入 `artifacts.local/work/adt-eval-20261013/PLAN_TOFPROMPT.md`。

## 问题

ToF 暂时不能改装。在**现有安装角**下，能否训练一个网络，用 RGB、DAV2-S 相对深度、8×8 ToF 读数（按每区 25 条采样射线画进图像）和地面先验（头高 + 重力，设备上有）直接输出米制深度，从而胜过 v6 的“全局仿射锚定链”？

## 做法

- 网络：小 U-Net（约 1M 参数），在 320×240 上运行；以“ToF 读数对 DAV2 视差的逐图最小二乘仿射”得到的深度为基线，网络只学对数深度的修正量（在 160×120 上计算后放大）。损失为 GT 0.3–10 m 的对数深度 L1，3 m 内加权 ×2。
- 训练：ADT 5 个家族 11 段 + ASE 场景 0–15，每隔一帧取一帧（4983 帧，全部放在显存中）；ToF 提示在每个 batch 实时模拟，倾角在 0–35° 中随机取，一半样本用打折 ToF（25% 丢区、3 m 量程、4% 测距误差）。25 个 epoch，GPU 6.5 min。
- 评测：ADT multiuser 2 段（926 帧）和 ASE 场景 16–19（1478 帧）。ToF 模拟和打折随机种子与角度扫描逐帧一致；网络深度放大到 640×480 后，用不变的 v6 读出（像素团 ≥10 px、中位深度 ≤1.8 m、≥150 px、2/3 确认）。基线是同一批帧上 DAV2-S 锚定链的扫描结果。
- 判定：现安装角的理想（i0）和打折（d0）两种条件下，检出 ≥80% 时的最低误报都要 ≤0.75 倍基线，且 v6 规则下检出不降超过 2 个点。

## 结果（RGB 支路，query 帧）

| 留出集 / 条件 | 基线 v6 误报 / 检出 | 网络 v6 误报 / 检出 | 检出 ≥80% / ≥85% 时最低误报：基线 → 网络 |
|---|---|---|---|
| ADT 现安装角 理想 | 10.0% / 83.0% | 16.9% / 87.7% | 6.4% → 5.2% / 达不到 → 11.4% |
| ADT 现安装角 打折 | 12.4% / 85.0% | 22.9% / 89.5% | 7.1% → 8.3% / 12.4% → 12.4% |
| ADT 下倾 30° 理想 | 7.6% / 85.1% | 10.5% / 91.0% | 3.6% → 3.1% / 7.4% → 4.3% |
| ADT 下倾 30° 打折 | 7.6% / 86.2% | 10.5% / 89.9% | 3.3% → 3.3% / 5.7% → 4.8% |
| ASE 现安装角 理想 | 16.2% / 89.7% | 15.7% / 87.5% | 13.1% → 12.0% / 15.2% → 13.8% |
| ASE 现安装角 打折 | 16.7% / 89.2% | 17.6% / 88.4% | 12.5% → 12.8% / 15.5% → 14.0% |

ADT 负例 420 个 query 帧，ASE 1242 个。

**判定：不达标。** 现安装角理想条件是 0.81 倍、打折条件是 1.17 倍，都没到 0.75 倍。网络的主要作用是让读出“更敏感”：固定门槛下检出 +4–6 个点，误报大幅上升。这和之前用 ADT 微调 DAV2 的结果是同一种模式：工作点移动了，区分能力并没有提高。

事后看到、不作为结论的线索：在下倾 30° 时，检出 ≥85% 处网络的误报更低（理想 7.4% → 4.3%，打折 5.7% → 4.8%）。也就是说，ToF 正好照到障碍区域时，学习方法才有一点额外空间。

## 解读与边界

- 真实训练数据只有一套公寓。网络在 ASE 合成场景上与锚定链持平，在 ADT 留出段上没有稳定优势。在这种数据条件下，学习方法赢不了“ToF 仿射 + 读出规则”这套几何做法。
- 留出集很小（ADT 2 段、420 个负例 query 帧），0.8 倍左右的差异在噪声范围内。
- 没有调参重跑：在留出集上看过结果之后再换损失或训练轮数，就不再是干净的检验了。
- 训练缓存（约 8 GB）保留在 `artifacts.local/work/adt-eval-20261013/tofprompt_cache`，以后若有新的真实数据，可以直接复用。
