# M13 续攻：S24 Ultra 逐层量化根因定位与零干扰混合精度帕累托前沿

## 三个根因与逐层干预验证

M13 首轮纯 PTQ（`W8A8` 误差 `19.14% / 11.57%`，补焦距端点后 `11.84% / 9.00%`，无 ToF 零干扰偏差 `1.275 m`）卡在三处可独立消除的芯片误差：
1. **逐张量权重量化 + 末端视差反演 INT8 截断**：加入 `--use_per_channel_quantization --use_per_row_quantization` 并把末端 `disp_head -> stable_softplus -> host_focal -> 1/disp` 切回 FP16，纯 RGB 误差由 `20.12%` 降至 `7.95%`（`aria 32.10% → 5.07%`），再把整个 FPN/输出头切至 FP16（`pc_fp16dec_a8`）进一步压至 `4.93%`（`day 2.06%`, `coda 2.73%`, `aria 3.92%`）。
2. **暗光 `0.18×` 在 `enc.stem + enc.stages_0` 的 INT8 有效位宽崩塌**：`pc_fp16dec_a8` 上唯独 `dark` 高达 `11.01%`。仅把 `rgb + enc.stem + enc.stages_0` 升为 INT16，其余主干 `stages_1..3` 保持 W8A8（`pc_stem16_tailfp16_a8`），`dark` 立即降 **4.6×**（`11.01% → 2.37%`），Pure-RGB 跑出 **`9.16 ms`（109.1 FPS）**。
3. **无 ToF 零干扰退化的结构成因**：当 `p1_use = p1_ctx + dp1` 之后的 `smooth0` 位于 INT8 时，Omni 因校准含 `has_tof=1` 而与 Pure-RGB 产生不同缩放步长（导致 `0.39–1.80 m` 差异）。将唯一的 INT→FP16 切点干净地放在编码器四层输出 `(f1, f2, f3, f4)`（整个 FPN + ToF 分支 + 输出头运行于 FP16），**实片严格恢复 `0.000000 m` 零干扰**！
