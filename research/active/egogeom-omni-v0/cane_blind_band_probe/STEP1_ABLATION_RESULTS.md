# Step 1：盲杖中性区三分区重算与零训练读出消融报告

- **阶段与口径**：`EXPLORE`（严格零训练 / `0 CCU` / 零改动冻结 `egogeom_omni_v41_pure_rgb_best.pt` 与 `:app`），本地耗时 `137.63 s`；配套前序五域基线报告见 [RESULTS.md](RESULTS.md)，执行脚本见 [eval_cane_neutral_and_ablation.py](eval_cane_neutral_and_ablation.py)。
- **结论先行（效果 + 成本 + 决定性判别）**：
  1. **三分区中性区把“评测口径冤假错案”与“真实模型短板”彻底分开了**：把 `[0.15, 0.65) m` 仅盲杖覆盖的低障碍设为**盲杖中性区 (`cane_neutral`)**（漏报不罚、报警不算清路误报，仅全高 `>4 m` 才是 `strict_clear`）后：
     - **确证了部分冤假错案**：4 域 `midup_ground_matched`（`276` 事件）的 `2-fold` 源留出交叉拟合从 `2-zone` 全军覆没（`0/276`）恢复到 **`bev_midup_ground` `CF=34/276` / `DCF=56/276` (`4.139 cw/km`)**、**`m6_head_anchored_85_pg` `DCF=80/276` (`2.069 cw/km`)**；ARKit Day/Dark `bev_midup` 的单帧 `AUROC_3z` 跃升至 **`0.9436 / 0.9304`**（`bev_ha85_geom` 达 **`0.9545 / 0.9430`**）。且透明审计指标 **`cane_neutral_alert_rate` 仅 `0.00%–0.57%`**（对比 `bev_full_ground` 固定 `d<=2m` 为 `57.8%–72.8%`），证明中高读出并没有靠乱报低障“作弊”。
     - **也证伪了“纯阈值稀释假说”**：将 Stage-2 占用阈值按高度带厚度下调至 `0.55×`（`bev_midup_cal_thr`：`0.0308`）后，阳性有限预测率 (`finPos`) 仅微增 **`1.5–3.8` 个百分点**（Aria `centered_full` `0.3030 -> 0.3182`，CODa `0.3125 -> 0.3438`，Aria `strict_past` `0.6464 -> 0.6844`）。**失去脚底接近线索后的阳性覆盖塌陷，根子在冻结 Pure-RGB 主干深度估计本身，不在 Stage-2 阈值偏严。**
  2. **消融阶梯结果：无地面 `dh + 竖直法线` BEV 彻底清零头锚定路面误报；`m6_ha70_nopg` 与 `m6_ha_adapt` 各自跑出关键突破与清晰边界**：
     - **`bev_ha85_geom`**（在无地面 `HeadAnchoredBEV` 中直接引入 `dh_s4` 与 `1-n_down^2` 竖直权重）一举把头锚定固定距离 `d<=2m` 清路占率从 `9.15%–11.74%` 压到 **`0.45%`（4 域合并 `0.40%`、`CODa 0.04%`、`ARKit 0.00%`）**，`full_ground_centered` 精确前沿从 `6/365` 升至 **`30/365` (`1.035 cw/km`)**，4 域 `CF` 从 `0/365` 升至 **`63/365`（Aria `12/143`）**。
     - **`m6_ha70_nopg`**（去掉误伤正样本的 `+10°` 门控并收紧下界至 `-0.70 m`）在 **不损坏单域排序性能**（ARKit `AUROC_3z=0.8604`，CODa `0.7405`，Aria `strict_past 0.6887`）的前提下，将 `full_ground_centered` 精确前沿拉升至 **`86/365` (`4.139 cw/km`)**，并将共享 `CF=45/365`（含 Aria `12/143`）的测试清路复警从 `5.173/km` 压回预算内的 **`3.104/km`**，分设备 `DCF=100/365`。
     - **`m6_ha_adapt / v2`**（全因果高/俯仰自适应 `H_ema + floor_dh_ema + z_rel_lo`）在 4 域合并指标上冲到全场最高：**`full_ground_centered` `P5=89/365`、`CF=75/365 @ 3.104 cw/km`、`DCF=104/365 @ 2.069 cw/km`**，同时成为 `midup_3zone_centered`（**`P5=52/276`、`CF=36/276 @ 3.104 cw/km`**）和 `midup_3zone_strict_past_aria`（**`P5=45/380`、`CF=37/380 @ 4.123 cw/km`**）中唯一让共享 2-折不掉零的 M6 读出；**但它也暴露出单域退化副作用**：`pitch_guard` 与按 `H_ema` 收紧 `z_rel_lo` 把 Aria/CODa 有效点数砍掉太多（Aria `finPos` 从 `0.2893` 跌至 `0.1804`，`AUROC_3z` 从 `0.6599` 跌至 `0.5897`；CODa `AUROC_3z` 从 `0.7555` 跌至 `0.5306`），导致共享阈值几乎只在 ARKit 得分（Aria 为 `0/143` / `0/84`）。

- **成本与校验**：Colab **`0 CCU`**；`FastClipEval3Zone` (`neutral=0`) 对 `score_episode` 200 次随机检验逐比特一致（`atol=1e-12`）；`midup_2zone_matched`（8 臂）与 `full_ground_centered/m6_head_anchored_85_pg`（`51/365`, `CF=45/365`, `DCF=117/365`）与首轮报告完全一致；全量 `haz / cane_neutral / strict_clear` 严格两两互斥；`cane_neutral_ablation_report.json`（`2,675,495 B`）已备份至 `gdrive:BlindAssist/runs/egogeom_cane_blind_band_probe/`，零 `NaN/Inf`。
- **下一步决策建议**：Stage-2 纯推理读出在**已知底座**上的潜力已基本探明——**接下来最值得做的是“真·盲杖盲区”悬空/透明障碍微基准实测（30–50 段头戴采集）**，验证冻结 Pure-RGB 主干对真正不接地悬空物与玻璃门是否发生深度塌陷，从而决定 Stage-1 下一轮是只做中高数据对齐微调，还是必须补两帧视差 / 硬件深度分支。

## 3. 诚实边界

1. **Part 2 覆盖范围限制**：7 条新因果读出运行在本地已缓存 stride-4 张量的 4 域 103 片段（Aria / ARKit Day / ARKit Dark / CODa）上，未对 SANPO 40 片段重跑前向推理（SANPO 仅用于 Part 1 的 8 臂 3-zone 重算）。
2. **证据边界与场景分布缺口**：仍属于 `EXPLORE` 离线基准回放（Development），不构成真机安全证明；公开数据集仍极度缺乏**纯悬空头障（树枝、悬挑广告牌、货车尾板）与透明玻璃门**样本，无法从本实验推断主干面对非接地悬空细结构的深度可靠性。
