# 固定模型稳定性与共同校准

2026-10-07；EXPLORE。承接[高度迁移检查](CNH_HEIGHT_TRANSFER_DEV_20261007.md)，检验其净收益集中于第三折的原因。这里的 fold 0/1/2 指原来训练的三套固定模型，不是将新评价数据再分三份；所有模型评价完全相同的观测。

**结论：原始观测＋HB训练覆盖的候选值得保留，但尚不能替代M3。** 共同校准后，原高度三套候选主要窗及时数均提高且误报不增加；HB仍以少报对2–7件事件换取少68–93个误报间隔。原先第三折的相对优势含有明显基线阈值差异，不能当作普遍稳健收益；排序观察支持原始信息有价值，标量校准本身没有增加信息。

## 新单位稳定性检查

固定 48 个新模拟 unit `410004..410051`，每个原有 40 个配置，另生成对应 HB 物理高度，共 3840 条记录。沿用 none/corner 背景分布、三个运动模式、镜像规则；mode×mirror 六格各 8 unit。模型与原校准阈值全部冻结，不拟合、不按分数选场景。

原高度有 140 接触事件、371 严格畅通控制；HB 有 140 事件、357 控制。各有 150/200 条目标与背景相交记录；其余接近边界、未到评价交点且非全程 clear 的记录保留但不当负例。实际新渲染 1008 个可评价序列。全部 48 unit 同时输入三套模型；不把三套固定拟合或两种高度当作独立样本。

头部方向误差从旧 144×40 个 16 帧轨迹中整窗抽样，记录来源，不改符号或幅度。因而是新模拟几何/噪声种子，不是新受试者或新运动类型。读出只接收 pair2，或 pair2＋当前观测摘要136；真实轨迹、盒体与标签只供物理渲染及评价。

### 原阈值下的结果

主指标排除首两输出的启动红利，接触事件在原 0.9 m 几何交点之前报警；主要误报窗为输出 `[2:12]`。及时数分母均为 140，原高度/HB 的误报间隔分母分别为 3710/3570。表内为“及时数 / 误报间隔数”，使用旧 2.5% 校准目标对应的阈值，实际误报并不相等。

| 原模型编号 | 原高度 M3 max | 原高度 raw+HB | HB M3 max | HB raw+HB |
| --- | ---: | ---: | ---: | ---: |
| 0 | 96 / 70 | 111 / 78 | 111 / 114 | 100 / 59 |
| 1 | 82 / 48 | 109 / 77 | 105 / 75 | 103 / 49 |
| 2 | 56 / 10 | 111 / 54 | 83 / 28 | 109 / 39 |

**原定的六格都提高及时数且误报不增加，未满足。** 原高度及时都提高但误报也增加；HB 模型0/1较保守，模型2及时提高同时误报增加。

三份 M3 max 分数逐值相同，其旧阈值却为 5.6327 / 7.3263 / 10.8085。因此 max 的 96→82→56 和 HB 的 111→105→83 差异，在本轮可以明确归因于阈值切换；这解释了先前第三折相对收益的一部分。不能由此把学习模型之间的差异全部归因于校准，因为三棵树的训练也不同。

候选相对 max 的原高度净及时差为 +15 [5,26]、+27 [17,37]、+55 [41,70]；HB 为 −11 [−21,−3]、−2 [−9,4]、+26 [16,36]。括号为 1000 次按 mode×mirror 分层的 unit bootstrap，固定模型和阈值的条件区间；各项伴随表中的误报变化，不能解释为同误报收益。

5% 旧校准目标下，原高度候选及时120/121/120 vs max116/109/100，FA163/115/122 vs158/127/76；HB 候选118/112/115 vs127/119/111，FA137/101/110 vs230/182/125。启动期单独保存：2.5% 候选原高度1/2/1 of742帧，HB3/0/0 of714帧；max均为0。

### 排序与报警阈值

辅助排序量取每个事件 `max(score[2:deadline+1])` 与每个畅通控制的 `[2:12]` 分数比较。按完整同分组计算 0–5% 误报预算内的可达阶梯面积，再除以0.05。它是事件峰值与控制时间间隔的描述性权衡，不是逐帧分类 AUC，不声称时间间隔独立，也不从曲线选择部署阈值。

| 读出 | 原高度归一阶梯面积 | HB 归一阶梯面积 |
| --- | ---: | ---: |
| M3 max（相同分数） | 0.6844 | 0.7189 |
| raw+HB 模型0 | 0.7473 | 0.7370 |
| raw+HB 模型1 | 0.7566 | 0.7584 |
| raw+HB 模型2 | 0.7759 | 0.7764 |

候选三套的面积均更高，说明观察到的排序增益不只在第三折；HB 模型0的增益较小，这些面积本身没有提供训练/校准不确定性的置信区间。模型2仍有更好的排序，不能说所有差异都由旧阈值造成。

图：`artifacts.local/work/cnh-model-stability-dev-20261007/model_stability_operating_points.png`（另有 PDF）。实线是完整同分组阶梯，圆点/空心菱形是旧2.5%/5%校准目标对应的实际评价点；阴影标示0–5%排序诊断区间。图已目视检查。

## 共同原高度校准诊断

使用另48个unit `410052..410099`，与训练和上述评价单位不交叠；保留全部1920条原高度几何，368个严格畅通控制进入渲染与校准，共3680间隔。153条目标背景相交记录及接触、pass、非全程clear的删失记录均不进入负例池。全程clear的控制即使没有0.9m交点仍可用于校准。

所有模型采用完全相同的控制序列和 `[2:12]` 窗，整组同分值不拆分；报警比较为 `>=`，阈值取预算边界值的下一浮点数。没有加入HB校准，也没有重新训练。上述评价结果已看过，因此这是事后诊断，不是独立确认。额外48个校准unit保留了原140个评价事件，不再将既有评价集拆小。

2.5%校准目标下，共同M3阈值为3.9146044，三套结果完全一致；raw+HB三套阈值分别0.5392117/0.5310457/0.5139543。这四种读出的校准报警均为92/3680。共享的是校准数据与规则，不是要求不同模型使用同一数值阈值。

| 0 | 108 / 118 | 114 / 115 | 117 / 175 | 111 / 89 |

分母同上：及时140，主要窗误报原高度3710、HB3570。原高度净及时差为+6 [−3,17]、+7 [−2,17]、+11 [2,22]；HB为−6 [−13,1]、−7 [−15,0]、−2 [−10,5]。这些是固定新阈值的评价unit条件bootstrap，没有重新抽样校准集，不能称所有模型均显著改善或统计非劣。评价实际FA：M3原高度3.18%、HB4.90%；候选原高度2.70–3.18%、HB2.30–3.00%。**校准2.5%没有保证评价2.5%，也没有形成统一实际误报率。**

## 下一步

保留原始信息与训练覆盖候选，M3继续保留。下一项有判别力的检查是：在共同校准单位上补充物理HB控制，预先固定“两种高度分别满足误报预算”的单一阈值规则，而非只约束混合平均误报；再用同一已消费评价集检查两种高度的及时与误报。它不要求推理时知道真实高度，仍是校准覆盖诊断，不是新的确认。需另行冻结范围及预算，当前尚未运行，不按现有评价结果挑高度比例或最好的模型。
