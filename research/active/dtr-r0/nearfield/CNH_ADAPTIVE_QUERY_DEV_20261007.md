# 方向不确定性自适应查询与身体参照（2026-10-07，EXPLORE）

**结论：预设标准（相同误报下收回一半以上方向损失）未达到。按步速与转向自适应放宽报警查询，在相同误报下反而使及时报警更少；躯干朝向虽然对未来路径的误差更小，代入报警后并不比头部位移更好。唯一有效的是只用于“判畅通”的自适应宽度：静默漏报几乎消失，代价是无法判断时间增加。行进意图估计应在论文中作为开放问题。**

## 设置

- **真值**：骨盆沿路径前方1.5 m的方向（报警关注的0.9–2.1 m内身体实际去向）。
- **方向来源**（BlindWays，10位视障/低视力步行者）：头部1 s位移（现用方法）；躯干朝向（两肩连线法向，相当于胸前佩戴的身体参照）。CPU对比（[脚本](cnh_blindways_body_reference.py)）：相对未来路径，头部位移RMS 17.6°/中位6.7°，骨盆位移17.1°/5.8°，躯干14.1°/4.8°；慢速（<0.6 m/s）时躯干20.8°/7.3°，头部26.5°/13.1°。
- **自适应宽度**：每帧按因果代理（1 s头部位移速度、估计方向0.5 s变化率）分6档，取该档|误差|的75分位作为±k；宽度表只用奇数编号参与者拟合，代入的误差窗口只来自偶数编号参与者（32,929个窗口）。头部：慢/中/快约25/12–13/6–7°；躯干约14–16/9–11/5–7°。固定宽度为总体75分位（头部12.6°，躯干8.7°）。
- **代入**：开发批98000/99000（369事件、1255对照），冻结M3/阈值/r3门/事件定义（[脚本](cnh_adaptive_query_dev.py)，GPU约15 min）。相同误报阈值为批内扫描（描述性）。

## 解读

1. **扇形报警不可取。** 与[合成误差下的结论](CNH_HEADING_UNCERTAINTY_DEV_20261007.md)一致：放宽查询会把走廊旁的物体纳入，为守住相同误报只能抬高阈值，净效果为负；按步速自适应也不改变这一点。
2. **对未来路径更准的方向不一定带来更多及时报警。** 躯干误差RMS更低，但偏差更持续（身体朝向与实际路径之间有慢变偏移）；此前也观察到持续偏差比快速抖动更伤报警。
3. **三态可以守住“不说畅通”。** 自适应宽度判畅通把静默压到单路1、双路4（/369），略优于固定宽度，代价是无法判断时间约+7和+20个百分点。
4. **判断：** 在本批数据上，简单的几何补救（扇形、身体参照）都不能收回方向损失。对慢速、路径曲折的视障步行者，“接下来往哪走”需要更好的意图估计（例如结合盲杖、环境或导航信息），这超出本章范围。

## 局限

开发数据批内评估；BlindWays为惯性动捕位置，躯干朝向由肩线推算；评估参与者以P06为主；真值为骨盆前方1.5 m路径方向，是“去向”的一种定义；相同误报阈值为批内扫描；误差窗口与模拟运动不同步。
