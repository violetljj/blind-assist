# MZ109: interval geometry conditional on observable error envelopes

EXPLORE,2026-09-13. Continue one RGB+ToF+Radar+IMU. Fixed MZ108 stable regions and
reciprocal association; change only associated-region corridor geometry. No
threshold tuning, source-dependent parameters, training or sensor substitution.

MZ108 correctly associates some boundary objects but noisily projects their
extent across the corridor. Earlier MZ88 scalar uncertainty association did not
establish task gain; that negative result is not permission to treat uncertainty
as hazard probability. This study instead bounds an actual RGB-region projection
and explicitly keeps independent support when geometry is ambiguous.

Fixed working envelopes: Radar horizontal range +/-0.15m, integrated yaw
+/-(0.5+0.2*time_s)deg, mount pitch +/-0.5deg, each image box edge +/-2px.
These are disclosed nominal tolerances, not calibrated confidence intervals or
guaranteed physical bounds. Use conservative interval arithmetic for pinhole
projection and trigonometric extrema, not unanimous predictions at sampled
parameter vertices. Corridor unchanged: forward0.2--3.6m,lateral+/-0.3m,
height0.4--2.05m, in the initial walking reference.

Use a filled image-box / horizontal radial-shell representation. OUT requires
the entire outer envelope to be disjoint from the corridor. IN requires one of
nine fixed image witnesses in the intersection of all perturbed boxes to have
its entire projected envelope inside the corridor. Witness pixel is fixed;
edge uncertainty is not added twice. Invalid or too-thin box, non-forward ray,
nonpositive range bound or undecidable overlap is AMBIGUOUS. A true object need
not fill its bounding box: results are conditional on this proxy, identity and
working envelopes, never proven real-world clearance.

OUT removes only that associated Radar support; IN adds it. AMBIGUOUS restores
that return's original three-sensor support, not the previous refined decision.
Unassociated Radar and independently valid ToF support remain unchanged.
Overall absent support stays UNKNOWN; no CLEAR state or hysteresis is added.

Inputs:192 consumed MZ107/MZ108 frames plus one new96-frame12-scene panel,
seed109013, all frames retained. It adds mirrored boundary objects with inner
edges at0.29m (actually intruding1cm) and0.41m (outside11cm), plusHEAD,poles,
multitarget and clear scenes. New panel is constructed Development, not an
independent confirmation set. Reuse authenticated MZ108 RGB-derived caches for
old panels; compute the same module on new RGB. Seal all predictions before
evaluator access. No true pose, native geometry or target identity enters inference.

Compare three-sensor baseline, nominal MZ108 and interval output per panel.
Report TP/FP/FN, retained baseline and nominal TP, HEAD/pole/boundary strata,
association geometry IN/OUT/AMBIGUOUS, no-support UNKNOWN and extra latency.
Trace any changed decision to geometry state and evaluator-only source identity.
Task-gain criterion: fewer FP on at least one panel, no more FP on any, and no
baseline TP lost on any panel. A geometry-stability improvement that merely
undoes nominal regressions is not better-than-baseline task gain. Stop after
this fixed study; retain useful diagnostics and report any limitations honestly.
