# LOCAL native support diagnostic: scope before execution

2026-09-22, authorized EXPLORE continuation. One existing-data diagnostic,
not a new deployable readout. Preserve the completed LOCAL transfer, its old
model/thresholds and the original spatial trial's failed system cost gate.

Question: do LOCAL's transferred rescues have native observed-return support
in the same centre query that supplies their highest score, and do its added
false alerts lack that support? The representation copies each regional range
interval to every RGB pixel in its footprint. Actual pixel depth and winning-bin
sample locations can diagnose how much of this hypothetical support belongs in
the query. Neither public region geometry nor high HGB confidence establishes
pixel ownership.

The decision is whether this particular correspondence has enough measured
information opportunity to justify a separately evaluated public association
mechanism. It is not whether native depth can be installed as a runtime gate.
The weakest premise is that a useful correspondence, if present, can later be
estimated from public RGB/ToF; this diagnostic does not test that premise.

## Scope and overlap

Use all 576 consumed LOCAL-transfer frames, 48 clips, eight base geometries,
both background appearances and six fixed queries. Baseline counts are A
192TP/4FP/64FN, A OR LOCAL 228/6/28, with 36 rescued TP and two added FP.
Include the 28 remaining FN, all A alerts, all negatives and all appearance
pairs; error-defined subsets are descriptive, not fresh evaluation groups.

Old MZ183 reconstructed-mask ownership and earlier full-face/return ceilings
retain their own source, body-coordinate, readout and negative dispositions.
The present contrast concerns the newly retained query-local HGB's specific
pixel-band/return-location correspondence and borrowed BODY/HEAD attribution.
It neither retries those masks nor claims a new general ownership ceiling.
The preceding multireturn trial added hypothetical observations; this trial
reconstructs only the original already observed strongest-bin return stream.
MZ130's earlier image-mask rule had unchanged alerts while excluding a native
point beyond RGB FoV. This audit therefore retains complete contributor indices
and records sample coverage; it introduces no image-clipped runtime mask.

## Frozen measurement

Read saved probabilities, features and decisions; never load a model pickle,
train, change a threshold, re-extract an alternative learned representation or
capture additional frames. Inputs include evaluator-only native optical Z,
rendered geometry, original source specifications and public RGB/ToF. These
roles remain separate. Native/evaluator information must not enter a claimed
public model, and diagnostic outputs are evaluator-derived.

Reconstruct the original simulator with the original identity/noise key and
check all 576 public ToF arrays exactly. Retain only contributors to actually
observed winning bins; dropped returns and other latent modes are not observed.
Project native sample centres with the original camera. For every query count
actual winning-bin contributors in its 3D prism and separately all visible
native points in it. No ray or contributor means absent support, not free space.

Recreate the unchanged three public LOCAL interval bands at 320x180 RGB pixel
centres. Match saved per-band footprint fractions. Each resized RGB pixel has
four native 640x360 subpixels: assess them separately, never interpolate depth.
For every band retain subpixel counts for actual query occupancy, agreement
with the unchanged regional depth interval, validity, and rendered AABB
compatibility with target/background. The existing 2 cm association tolerance
is descriptive; overlapping associations remain ambiguous, unmatched points
remain unassigned. AABB compatibility is not captured semantic segmentation,
surface identity or physical return ownership.

Report four exhaustive frame strata, especially for the 36 rescued TP: observed
support in the winning centre; no winner support but observed support in the
other centre; no observed centre support but visible native corridor points;
and neither observed nor visible centre support. HGB has no unique causal
winning zone, so no such zone is invented. These distinguish attribution from
information lost by the single-return export and from absent visible surfaces.

## Two declared diagnostic readouts

Primary: A OR (saved LOCAL standalone alert AND at least one observed winning-bin
native point inside the winning centre query). The winning query is argmax over
indices 1 and 4, with index 1 on ties. Control: the same rule with at least one
such point in either centre query. The control distinguishes lack of any observed
corridor support from lack of support in the score-winning BODY/HEAD query.
Any zone may supply this information-availability witness; no claim is made that
it caused the HGB decision. Both are PRIVILEGED_OPPORTUNITY_NOT_DEPLOYABLE, not
strict information-theoretic ceilings. A's flags and UNKNOWN are preserved.

Report full TP/FP/FN, precision/recall/FPR, false segments, inclusive sampled
durations, events, onset gains/losses and retained/lost rescued identities;
compare with both A and original LOCAL, including lost early alerts, within-event
alert gaps and sampled coverage. A preservation is guaranteed by OR construction,
not an additional learned capability. Separate appearance, layer, relation and
base group. Do not select between the two rules or hide the control. No frame
exclusion or cutoff sweep.

The primary information opportunity is supported only if it removes both added
LOCAL FP, retains at least 32 of the 36 rescued TP, and preserves all A true
frames/events/onsets. This permits at most four rescued-frame losses for removing
two false frames; it is a diagnostic cost choice, not the prior lossless system
criterion. A native point in the query is privileged occupancy evidence, so
removing FP is largely guaranteed by geometry and is a sanity check. Rescue
retention and loss of LOCAL timing gains supply the actual opportunity evidence;
none of this establishes learnability from public RGB/ToF.
Failure rejects this exact support condition for the proposed role,
not all spatial learning or the retained LOCAL component. If only the control
meets these costs, record an attribution gap; do not promote it automatically.
Missing parity, source alignment or evidence makes the contrast NOT_EVALUABLE.
