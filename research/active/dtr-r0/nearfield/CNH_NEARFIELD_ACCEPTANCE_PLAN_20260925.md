## 2. 头戴坐标与姿态（G0）

定义右手查询坐标Q：原点为头戴组件参考点，X向右、Y沿重力向下、Z为头向在水平面的投影。Q只补偿俯仰/横滚，**偏航随头转动，不是躯干朝向或未来行走通道**。主算法没有躯干偏航输入；仿真的身体朝向及头–身偏角仅供生成/分层审计，不得泄漏给模型。无有效重力/姿态时标为坐标UNKNOWN，不假设水平。

保留六盒的尺寸，仅改变其参考坐标并明确为新任务版本：X中心为−0.30/0/+0.30m、半宽0.30m，Z=[0.30,3.00]m；HEAD的Y=[−0.20,0.42]m，BODY的Y=[0.42,0.90]m。因此HEAD世界高度是[h−0.42,h+0.20]，BODY为[h−0.90,h−0.42]；它们是冻结的头参考几何区域，不是不同身材的精确解剖学分界。低于BODY的物体仍可为六查询全负，不能按“低矮障碍”名称强造正例。

用显式刚体变换 `T_Q_camera` / `T_Q_tof` 投影与求交。物理标签在Q中计算，两个安装条件共用同一Q和标签。只改变ToF下倾不能旋转盒或改变标签；相机随头动，ToF另叠加固定安装角。针孔相机名义640×360、HFOV100°作为受控仿真假设保留，不能称真实镜头标定。

以下范围标记 `ASSUMED_STRESS`，不是用户身高、头动概率或实测分布。高度每布局采一次；头姿态按配置内8个分层样本抽取，每个因素覆盖上下半区，固定seed独立打散，不能按标签决定姿态。

| 变量 | 冻结分布/配置 | 解释 |
| --- | --- | --- |
| 头戴参考点离地高度h | U[1.45,1.75]m | 下次实测与范围不符需另版，不偷改 |
| 头俯仰 | U[−15°, +10°] | 向下负，角度相对重力水平 |
| 头横滚 | U[−10°, +10°] | 轴与旋转顺序写入元数据 |

| 名义相机–ToF平移 | 0m | 几何隔离假设，实机适用前必须替换为测量外参并另版 |

G0门槛：所有帧保存轴定义/单位/旋转顺序、Q/C/ToF变换与生成姿态，覆盖率100%；旋转正交误差≤1e−6，往返回投误差≤1e−6m。固定世界几何和Q，仅变相机/ToF俯仰横滚时六标签逐位一致；变头偏航允许按Q重算标签。使用理想重力是特权姿态假设，必须披露；IMU误差尚未被本版验证。真实使用的重力估计、同步和外参不合格时不推广。

## 3. 生成器、边界带与布局独立性（G1）

一个独立单位是**独立生成的近场物理几何、对象集合和摆放配置族**。同一场地只换路径、种子噪声、材质、背景、安装角或SNR不能多算一个单位；同一物理场地若有多个布局，后续统计须合并为一个cluster。若12个候选不能提供12个这样的单位，报告实际数并停止，不用帧数补足。所有场地均是仿真独立单位，跨真实场地泛化另无证据。

预定12单位按生成前ID和seed固定6 train / 6 audit-development，每个划分各有直/L/T两单位；每种形状各2 train、2 audit，跨单位的近场配置独立生成，形状名称本身不证明独立。既有test场地、资产保留池和City不得读取或挪用。沿用障碍物及同类干扰物资产族跨划分隔离、背景共享披露约束；一旦侵入查询区即不能享受背景豁免。

每单位主集20个独立对象配置×8个位姿=160帧，边界集5配置×8位姿=40帧，共200帧；总2400场景位姿、两安装条件共4800组ToF观测，三个SNR均为同观测几何的响应派生，**不增加独立样本数**。这是拟议试采上限，不是当前已批准的采集量。所有主/边界配置及随机seed在渲染前固定；每配置最多32次几何候选，不满足则整个试采报告生成FAIL，不扩大候选次数。

每配置独立变化横向位置、前后距离、对象数量和类型。候选区域Q中X∈[−0.90,0.90]m、Z∈[0.20,4.00]m；每配置0–4个查询相关对象，另允许盒外干扰物。必须含：悬空物（下沿世界高度1.2–1.8m、其下无支撑侵入对应查询）、低矮物（高度0.10–0.70m，按真实盒求标签）、细杆（横截宽0.01–0.05m，单列尺寸）、宽物体及贴边干扰物。类型不是标签；姿态与高度变化后必须重新几何验算。

边界margin固定 **0.05m**，它不是“物体厚度至少5cm”。令三角面集合S到盒B的有符号内侧余量为 `m(S,B)=max_{p∈S} min_i(p_i−lo_i, hi_i−p_i)`：正值表示至少有表面点深入盒内，负值表示分离，0为接触。用精确三角形–盒几何求值/认证界，不用屏幕像素面积、AABB近似或稀疏顶点替代。细杆只要位于盒内部也可有较大的m。

- 物理标签保持闭合接触定义，不以margin重写：有三角面接触为1；已证明完整几何覆盖且无接触为0；缺覆盖无见证为UNKNOWN。所有正例保留对象ID与见证。
- 主集要求对六查询及每个相关对象均避开 `|m|<0.05m`；主集判定不依赖观测/模型。边界集在选定查询上 `|m|≤0.05m`，正负侧各20帧/单位，接触标签仍按几何定义，记录选定面、对象和m。
- 主指标**排除整个边界子集**，边界集单独报告；另给包含边界的全量结果，不把被排除的40帧藏掉。边界集不是负例集，也不是UNKNOWN集。几何数值容差1e−4m，容差内难定符号保留边界不确定标记并报告，不通过强制舍入造标签。
- margin控制生成难度，不构成EXR或硬件误差容许值。已有几何导出门槛不因margin而放宽。

G1门槛：所有布局、对象配置、帧的身份/来源/分区/三角面覆盖/对象ID和坐标绑定100%完整；主集UNKNOWN=0，否则该候选不能作为完备受控验收数据，保留失败和缺失原因。边界UNKNOWN单列，不强转负例。每个划分内不得重复整个近场配置序列；对非空配置在标准Q姿态下以1cm体素化的查询相关几何做指纹（忽略纹理、名字及远景），完全重复的正例配置数必须为0。额外计算布局间近重复：若任一布局≥90%的非空配置在另布局能找到Jaccard≥0.98的对应近场几何，则FAIL；扰动名字或毫米级位移不能绕过此门槛。透明/反光等不受现代理支持的材料另列，不混入此版主集。

## 4. 标签多样性硬门槛（G2）

以下按每单位160帧主集检查，并在train/audit分开汇总；边界40帧不参与凑数。生成器可按预先声明的几何覆盖配额拒绝候选，这形成**受控、配额平衡数据**，不得冒称自然障碍发生率。

| 验收项 | 固定门槛 |
| --- | --- |
| 每查询阳性率 | 每布局、每划分均为15%–85%；每布局即每位至少24正、24负 |
| 同方向HEAD/BODY不一致 | 每方向至少20%的主帧不一致；两种方向H1B0、H0B1各≥8帧且来自≥2配置 |
| HEAD-only / BODY-only | “至少一HEAD正且全部BODY负”及相反情形，每布局各≥16帧、≥2配置 |
| 左右不对称 | 至少一个高度段left≠right，每布局≥32帧、≥4配置；左侧独有/右侧独有各≥8帧 |
| 多障碍 | ≥2个不同对象ID实际贡献六查询中的正例，每布局≥32帧、≥4配置；不能按场景摆了两个远处物体计数 |
| 标签组合 | 每布局≥12种六位已知组合；每划分≥20种，每种计入下限的组合须在≥2配置出现 |
| 相关性 | 每布局及每划分：三组同向H/B、两个高度段各自L/C及R/C，共7对，二元Pearson(phi)的绝对值≤0.80；方差为0直接FAIL |
| 全空及距离覆盖 | 每布局主集全0≥16帧、来自≥2配置；正查询见证最近前向距离[0.3,1)、[1,2)、[2,3]m三段各≥24个正查询且来自≥3配置，允许跨查询相关但不计独立功效 |

上述类别可重叠，不把计数相加冒充200个独立样本。相关阈值是去退化的工程门槛，不要求真正统计独立。盒之间存在集合关系：同一高度段 `centre⊂left∪right`，因此 `(L,C,R)=(0,1,0)` 不可能；已知标签出现它即FAIL。每高度段最多7种可行组合，六位最多49种，不要求64种。多对象可产生101，HEAD/BODY跨边界同时为正也合法。

回执必须逐布局给六位阳性数、完整组合频数、7对相关矩阵、H/B不一致率、五类配置/帧数量、对象类别和尺寸覆盖及UNKNOWN原因；不能只报“PASS”。任何一项FAIL不开展模型收益比较；保留全部失败候选/拒绝理由，修改须新版本而非只删困难帧。

官方支持Closest/Strongest，默认Strongest；最多4目标是输出能力，约600mm同区分离约束须披露，不等于任何波形次峰都可当目标。CNH缓冲5468bytes只核算CNH块，标准四目标输出、RAM、链路开销另算。不得为跑通而静默退成单目标、4×4或另一帧率。[ST UM3183 §4.9–4.11、§5–6](https://www.st.com/resource/en/user_manual/um3183-a-guide-for-using-the-artificial-intelligence-enabler-vl53l7ch-and-vl53l8ch-multizone-timeofflight-tof-sensors-stmicroelectronics.pdf)。

旧代理已经称2%为补偿后残余，但它是`ASSUMED_STRESS`，与实际盖板/单位量级没有已建立的换算。CNH有符号归一化单位不能直接当光子counts，也不能把`signal_counts×0.02`与手册kcps/SPAD直接比较。本版要求记录单位/缩放/scaler、曝光、盖板、校准版本，并在桌面匹配后才称“硬件锚定”。无绝对标定时仅比较归一化早峰/目标峰比及误报概率；不得编造厂商通用的“残余2%正常”结论。

模拟必须从**同一原始响应/曝光**产生目标候选、质量量、最多4个有序距离和H3，再分别交付波形与标量臂；标准距离可在未压缩响应上估计，不能强迫真实固件距离等于H3粗bin中心。禁止为标量臂单独调用无噪声深度，或为CNH臂偷偷使用不同噪声/有效性。公开资料不足以复现固件私有目标检测时，使用独立命名的`proxy_quality`，不得把简单SNR门槛硬写成真实ST status5；状态映射和实际输出的符合性仍需桌面检查。

SNR冻结三档为**参考目标SNR=3/6/12**。定义为参考目标响应积分均值相对同设置无目标背景均值的增量，除以有目标重复观测积分的标准差；参考为2m、覆盖一个完整zone、ρ=0.5、入射余弦1的漫反射单平面。积分窗口为冻结响应核在真目标位置的±3个原始bin；此真值窗口仅用于离线标定/设档，绝不参与在线目标选择。各档用固定200次独立噪声抽样核验SNR在目标值±10%内，只调整预声明的公共信号增益，不根据标签或AP挑参数。200次仅为未来传感单元校验，不是本次执行。

三档ambient参考均值固定4个代理单位/raw-bin，噪声倍率1；脉冲/尾部/串扰/邻区泄漏继承的每个数值单独标为假设，不能据此声称模拟真实照度。一次桌面会话估计出的残余若要替换旧2%，须在新试采之前写入另版参数表、锁定并再次交审，不能在本版中待看结果再填。当前v1因此只冻结校验方法和门槛，不宣称已冻结硬件标定数值。

代理有效性至少同时包含：候选信号/噪声≥5、由观测估算的距离sigma≤0.10m、有限ambient和距离、当前帧候选一致性及最多4目标限制；ambient必须进入噪声方差，不能只检查“peak>0”。设档增益求解采用期望响应和方差方程，在[1e-3,1e7]代理增益内最多40次二分，之后仅做一次200次噪声核验；核验未达±10%即FAIL，不继续试seed或调增益。二分只解参考SNR，不读标签。

这两个数值为代理工程门槛，**不是ST内部阈值**。无法计算任何一项则质量UNKNOWN，不凭几何真值补有效目标。原始status/代理原因分别保存；失败不能靠放松sigma、SNR或清除早bin补救。

| 误差定义 | 对单平面用该区射线/立体角权重定义的真实径向距离中位数；另报真实最小/最大范围，禁止拿轴向距离冒充径向真值 |
| 多目标 | 同区两表面间隔≥0.60m、各覆盖该区≥30%、SNR12：两目标均检出率≥90%，一对一匹配误差各≤0.10m；小于0.60m单列混合/合并，不强求分开 |
| 近零假目标 | 在所有真表面径向距离≥0.35m的区，输出有效距离<0.30m的比例≤1%；同时以全部区帧及有效区帧作分母，防止全UNKNOWN掩盖问题 |
| 低/中SNR | 分别报告覆盖、误差、sigma、近零率与目标漏检；不要求SNR3达到SNR12覆盖，但不得删掉该档或只报有效样本误差 |
| 全数据逐区检查 | 每布局、安装、SNR保存64区的误差分布/覆盖/假目标率、匹配或未匹配目标数；复杂遮挡/合并的距离真值使用可见目标集合匹配，与最近射线标量分开 |

单平面及双表面为传感单元校验，不计12个独立布局。G3门槛同时检查模拟和可用桌面参考的相应单元；未能实现硬件对应时最多称模拟工程通过。若实物在同设置也稳定超出1%近零率，记录`HARDWARE_MATCHED_DEGRADED`，必须保留校准/独立复位重测证据；这不是“正常基线PASS”，不进入主收益比较，先将真实故障或局限交用户决定。不能凭一次波形早峰较高就证明距离输出应为近零。

## 6. 公平对照与拟合烟测（G4、G5）

**G4：输入匹配硬门槛。** 所有臂的帧/布局/曝光身份、标签、分区、安装和SNR配对率100%，无真值进入观测。一次曝光内CNH和标准距离共用响应、固件配置与有效性；未检测目标不能变成“确定无障碍”。所有模型在全部已知查询上输出分数，不通过删UNKNOWN输入样本提高AP；另报输入有效覆盖与告警UNKNOWN行为。

后续拟议矩阵为H3几何规则、ToF-only、RGB-only、CNH+RGB、标量+RGB，逐一给出M0/M1×SNR3/6/12六条件结果。本版的“标量+RGB”指**同一四目标配置的最多4个距离标量/有效位及公共质量元数据**，而非人为只留一个距离；CNH+RGB获取完全相同元数据再多一份直方图。另列第一个有效最近距离的单距离消融，不以它代替公平主对照。RGB-only不拿传感质量量或模拟身体真值作捷径。

增加两项特权几何**参考**，不进训练、不称数学上限：(a)逐zone无噪声真实最近可见径向距离，在完整zone射线内取min、保留可见性/无返回，不给出造成最小值的子区方向；按预定义区锥与查询盒径向区间读出。(b)完整可见射线/像素回投查询盒的直接规则，用于区分zone聚合与视场外/遮挡。另报告物理正例中ToF视场内首表面见证比例。参考(a)弱仍不能证明ToF信息不足：最近距离会丢较远返回和角位置；只有(b)及可见性分析才能说明当前采样观测缺口。阈值若非纯几何固定，全部只在train选择；不在dev找“完美阈值”。

模型结构仅冻结原则，当前不实现：ToF用`query_weights`查询×区×bin交集先验，并随公开姿态/外参重算；RGB从查询盒在**完整图像**上的保守投影取特征，空投影有显式无观测标记，不限ToF视锥。使用冻结预训练图像编码器、max或查询attention池化；确切checkpoint/许可/hash、二者选定及训练优化配置需在批准实施时锁定，不能看audit AP选。既有相机坐标静态query_weights不能直接复用为下倾后的正确权重。

**G5：烟测只考train拟合。** 使用预先选定的32个train帧，覆盖6个train单位，每单位按seed取5帧、前两个单位各多1帧；以几何标签覆盖规则补足每位至少4正/4负，若不满足固定候选则FAIL，不改成挑易样本。六查询共192项。先检查该模态量化/浮点输入完全相同却标签不同的观测冲突；若存在，记MODALITY_NOT_IDENTIFIABLE，不归咎训练、不换选帧规避；此时该模态不适用近满分门槛。没有精确冲突也不证明信息充分。seed=20260925，batch=16；固定最多2000次更新或15分钟/臂，任一先到即停；每100步检查一次。分别对无噪声H3-only及直接深度查询分支检查，非部署参考而是管线测试。通过要求 pooled train AP≥0.99、每查询AP≥0.98、全部已知查询BCE≤0.05（无类别权重的评估损失）；出现非有限值、断梯度或输入退化立即FAIL。达到全部门槛即停止，不追audit AP0.85。失败须先报告具体检查，不增加步数、换seed、无限“训到平台”或启动完整模型矩阵。

G5只证明该子集可拟合，不证明自然泛化、模态增益或充分训练。完整训练阶段若以后批准，须另冻结学习率、最长预算、仅用train/独立校准集的plateau停止规则；不把本文烟测2000步当完整训练预算。所有数据G0–G4未过，G5不得作为救数据的理由。

## 7. 独立布局精度估算与统计报告

12单位是工程试采上限，只有6个audit单位，不给融合收益显著性结论，也不把12或6个单位的bootstrap当可靠泛化证明。连续帧、六查询、20个摆放、两个安装、三个SNR和训练seed都不是新增独立布局。若底层物理场地共享，则按场地合并，报告有效独立单位下降。

后续估计主量为每独立布局计算AP后得到的**布局宏平均AP**；五臂比较用同布局配对ΔAP。每布局固定相同主样本量和生成配额，同时报告每查询AP及阳性基率；合并所有帧的micro AP仅作次指标。所有正式CI都在独立布局/场地层面重采，整单位保留全部帧、查询、条件与配对模型，bootstrap固定10000次；不得按帧重采恢复所谓大样本。点wise 95%区间不自动控制全部臂/六条件的多重比较，跨条件“稳定收益”需要另冻结同时推断规则。

以下只是规划假设：独立布局配对差值标准差s未知，目标95%均值区间半宽h≤0.05 AP；用 `h≈t(0.975,n−1)×s/√n` 计算。s不能从旧重复三布局估计。公式是近似精度规划，不是AP bootstrap精度保证或统计功效计算。

| 独立评价单位n | s=0.10的半宽 | s=0.20的半宽 |
| ---: | ---: | ---: |
| 12 | 0.0635 | 0.1271 |
| 24 | 0.0422 | 0.0845 |
| 48 | 0.0290 | 0.0581 |
| 64 | 0.0250 | 0.0500 |
| 96 | 0.0203 | 0.0405 |

按s=0.20的规划，达到±0.05需**至少64个独立评价布局/场地**，不包括训练集；这就是后续评价规模的建议依据，不按帧数定。64不是保证：s=0.30时半宽约0.075，不得仍声称±0.05。未来若批准，建议固定64单位并以实际区间报告；未达精度则报告不精确，不追加至显著。训练布局数量应依据单独学习曲线预算确定，不能拿评价精度公式确定训练量。本版不授权64单位，不改原384布局主考场或164受保护test计划。

边界带、距离段及姿态段必须报告独立单位数；子集单位不足或无正/负导致AP不可算时记NOT_EVALUABLE，不能用总体n代替。按布局bootstrap也不能修复相同几何换背景的伪重复。

## 8. 一次桌面实测步骤（仅列计划）

已有实物证据，但未检查现在是否连接；不扫描串口、不发控制命令。日后批准这次会话后执行：

1. 记录板卡/芯片身份、ULD和固件hash、盖板/遮光结构、现有xtalk校准及所有原配置；保存可恢复配置。读回Closest、4目标、8×8、H3窗口、积分/频率及质量输出。若组合不支持，停止报告，不换成H2冒充通过。校准/刷机如需要，须纳入用户批准的这次实施范围。
2. 用固定支架、卷尺/标尺（距离记录到5mm）、漫反射面，禁止把传感器读数当真值。测相机/ToF安装高度和固定俯仰，记录坐标轴及目标径向/轴向换算。记录ambient原单位；lux只能辅助描述，不能直接换算940nm背景光子率。
3. 按当前盖板执行或加载厂商xtalk校准，保留校准前后文件；厂商校准目标条件须按锁定UM3183/ULD执行，不用障碍数据的AP拟合串扰。CNH早峰原值始终保留。
4. 固定10个条件：无近物且远背景≥4m；大平面0.15/0.30/0.60/1.0/2.0/3.0m六条件；同一细杆在1.35/2.0m、后方背景≥3.8m两条件；同区各覆盖至少30%的前后两宽面1.0/2.0m一个条件。近距离0.15/0.30m是合法早目标对照，不能从中要求零早峰；后三项中同区多目标间隔及覆盖须实际记录，细杆不冒充满足30%覆盖，<0.60m不作为分离通过证据。
5. 每条件独立重新摆放3次；每次稳定5秒后记录20秒，计划5Hz约100帧，共30段/约3000帧、正式记录10分钟。整次会话墙钟上限60分钟，发生无法恢复的配置/传输错误即停止；部分完成如实记账，不无限补录。摆放重复不是30台独立设备。
6. 同步保存全部目标距离/status/nb_target/signal/sigma、CNH raw/scaler/ambient、帧号和设备/主机时间、真实布置距离与照片、原始字节及解析错误。对同帧比较“bin0较高”和“固件报告近零”，不要把两者混为一谈。
7. 前两次摆放只作标定/解释，第三次作桌面复核，不用第三次调参数。按G3报告每区覆盖、假近零率、误差与早峰/目标峰比。远平面时若CNH早峰高但固件距离正常，判定旧argmax代理缺少固件处理，不能继续用旧标量作论文基线。若硬件也近零，先查盖板/校准/配置和原始status，保留退化证据；不通过“删bin0”掩盖。
8. 保存manifest/hash、参数对照表、所有失败段及结论，关闭采集进程并恢复事先记录的原配置；不自动覆盖当前App固件。实测发现导致任何拟议参数变化，先交新版本审阅，再决定是否允许12单位试采。

## 9. 决策、停止与待审项目

验收顺序为配置/坐标G0 → 生成独立性G1 → 标签G2 → 传感响应G3 → 公平输入G4 → train拟合G5。G0–G2可在渲染前用生成器元数据和三角面检查；任何FAIL尽早停止下游成本。传感桌面校验优先于大规模仿真，但没有硬件时可保留纯模拟方案，不能自行把硬件符合性改成PASS。

最终回执需列 `planned/completed/rejected` 布局和帧数、每门槛实际值、每个seed/配置/hash、UNKNOWN与排除分母、拒绝候选原因、处理后端/时间和保留资源。未执行项统一NOT_RUN；仅“worker已接单”不是完成。该次试采不产生任何“RGB有收益”结论，最多允许提出后续固定模型矩阵。

**交用户审阅的具体选择已写定：头参考重力水平坐标；5cm生成边界带但不改物理标签；12独立单位工程试采；Closest/四目标/严格status5；三档SNR3/6/12与两安装角；主集15%–85%阳性率及phi≤0.80；近零假目标≤1%；32帧有界拟合；后续±0.05精度对应64评价单位的条件性规划。** 高度/俯仰/外参仍是声明的仿真假设；实际标定数值尚无资格冻结为硬件真值。本版供审阅，等待用户批准，不自动启动桌面会话或采集。随后单独授权的QG-1仅复用旧数据作结构/响应诊断，不等于批准本方案执行，也不恢复旧数据的泛化证据资格。
