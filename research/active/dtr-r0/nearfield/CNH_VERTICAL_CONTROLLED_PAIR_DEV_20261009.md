## 配对采样与算法输入契约

原边际为histᵢ=Pois(Eᵢ+8A)−Pois(8A)。对每个条件组与K，固定独立role／arm seed流，令λᵢ=Eᵢ+8A、μ=minᵢλᵢ：

```
B ~ Poisson(8A)
C ~ Poisson(μ)
Rᵢ ~ Poisson(λᵢ−μ)
histᵢ = C + Rᵢ − B
```

B、C及各Rᵢ的流独立；B与C跨臂共享。各臂C+Rᵢ严格保持Pois(λᵢ)边际，且与减项B独立。共有C包含条件最小强度，**这是人工统计耦合，不是共享物理光子或独立实测重复**。跨臂Cov(histᵢ,histⱼ)=μ+8A；不能把192序列当192个独立样本。9组×K4、角度、两高度、窗口也有共享结构，不作推断统计。

原FP32规范化→输入FP16→原FP32投影→特征FP16、past8、last5、五模型与阈值不变。f3–13的last5前缀与原13窗公式一致，原M3θ=.8557642486787612。本轮没有新局部读出、融合校准或门控；原5格候选未改变。评价侧别／几何只选配对，不进观测特征。

公共内外mask及四个统计与上轮相同。当前缩放支持量=sum(current)/累计count，是有符号量，**不是单帧密度或L1绝对量**；内部正量份额用max(current,0)。历史占比由FP16 tot−current残差计算。另保存条件线性均值参考：原E−bias除以冻结den，经公共当前曝光投影系数，除累计coverage；它在输入／特征FP16舍入前，**不是实际FP16统计或非线性份额的期望**，也不是信息上界。

执行前预期为contact−clear：缩放支持量正、内部正量份额负。报告全部条件／帧／K差和均值／中位数，没有数值成功门槛、N64借用阈值或d′。镜像一致只增强线索，非必要或充分条件。完成固定队列与核验即停止，不追加seed或新配方。
