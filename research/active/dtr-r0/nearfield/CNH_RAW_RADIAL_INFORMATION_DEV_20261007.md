# 原始径向信息与历史内容检查（2026-10-07）

**当前距离摘要有增益迹象，过去径向内容的独立增益未得到支持；本轮不替换M3。** 369个原域事件中，原校准2.5%目标下，无启动期及时发现从旧pair的253增至当前距离模型的271，同时实际误报由246增至297/12550。评价控制重新定阈值的描述性前沿为265→274，增益9 [0,18]；加入历史后280，但相对同可见性元数据对照只多4 [-5,12.025]。这些是复用Development的条件描述，不是新的确认。

## 问题与固定对照

前轮[两固定阈值诊断](CNH_QUERYWISE_CALIBRATION_DEV_20261007.md)显示旧两分数重标度余量有限，但未限制原始观测的信息。本轮保持144个完整unit、5760段序列的三折训练/校准/评价划分、浅树容量与种子，检查新增原始输入是否有用。没有重新训练M3、重新渲染或扩大来源。

新特征仅从单传感器分支0的signed `z1`、环境光和带噪旋转提取。保留8×8区域、16个径向bin的含义，不把电子残差当表面概率，也不截掉负值。当前摘要为2行×4列共8个扇区，每扇区4×2个zone，对16个bin分别取均值，并附8个`log1p(ambient)`均值，共136维。

历史取原生帧滞后1/3/5，即0.2/0.6/1.0秒。用`R_past.T @ R_current`将当前zone中心射线投到过去视角，双线性回采同径向bin；在共同有效zone内计算当前减过去的均值。保留每扇区可插值支持比例；无历史或无共同支持时差分为NaN、支持为0。支持范围是zone中心网格[0,7]，不是完整物理视野的覆盖率。没有真实平移补偿，也没有travel、未来路径或精确方向特征。

|方法|输入维数|作用|
|---|---:|---|
|原max|2取最大|冻结M3实际基线|
|旧pair_only|2|同配方旧浅树参照|
|current|138|旧两分数加当前原始摘要|
|current_support|162|再加历史可插值支持元数据|
|temporal|546|再加过去径向差分|

`current`对`pair_only`检查当前原始信息，`temporal`对`current_support`才检查过去内容。后者即使有收益，也可能来自去噪或记忆，不能直接归因为接近运动。旧M3分数本身已含上游历史及原查询条件，因此不是“完全无历史”基线。

三个新臂均使用150轮、深度3、最多7叶的HistGradientBoostingClassifier，学习率0.05、叶最小20、L2=5，无早停和超参搜索，种子沿用`I.SEED+fold`。正例仅用截止前最后一个因果输出；严格双高度全程畅通的控制按正例截止时刻配权，正负总质量相等，其余不作负例。训练分数不是部署碰撞概率。各新阈值仅由原calibration控制选定；原max/旧pair完整继承旧模型和阈值。

## 原域结果

以下及时数均排除前两个输出的启动期；事件分母369，误报间隔分母12550，来自1255条控制。评价控制重新定阈值只用于描述前沿，不是独立阈值验证。

|方法|原校准2.5%：及时|实际误报间隔（比例）|评价控制2.5%上限：及时|实际误报间隔|
|---|---:|---:|---:|---:|
|原max|202|330（2.629%）|195|312|
|旧pair_only|253|246（1.960%）|265|310|
|current|271|297（2.367%）|274|312|
|current_support|272|287（2.287%）|276|312|
|temporal|269|255（2.032%）|280|312|

当前摘要的原校准增益为18 [8,29]个，同时多51个误报间隔，不能写成同误报增益。描述性前沿增益为9 [0,18]，各fold为+5/−1/+5；两臂实际误报仍差2个间隔。5%描述前沿为current305、旧pair295，增益10 [2,17.025]，误报627 vs605。当前信息值得保留研究，但两工作点及实际误报必须一起解释。

历史相对支持元数据对照：原校准−3 [-14,7]个及时，同时少32个误报间隔；描述性2.5%前沿+4 [-5,12.025]，误报均312；5%前沿+6 [-2,14]，误报均627。当前配方未证明独立历史内容增益，不把少量正差判成接近估计成功，也不据此断言全部时序方法无效。

区间来自1000次按batch/mode/turn分层的完整unit配对bootstrap，模型及阈值固定，没有重新拟合或多轮选择校正。其用途是描述本次已消费Development比较。代码、分母、逐fold差及误报差见[条件对照](../../../../artifacts.local/work/cnh-raw-radial-information-dev-20261007/contrasts.json)。

## 双高度结构检查

沿用已消费的72个物理anchor，每个H/B/HB三种变体，共216段、39个不同unit。每种结构36接触事件和36控制；所有新模型及阈值来自对应原evaluation fold，未用这些变体训练或校准。

|方法|H/B/HB无启动期及时，各/36|H/B/HB误报间隔，各/360|
|---|---|---|
|原max|24 / 15 / 25|7 / 4 / 8|
|旧pair_only|25 / 22 / 11|5 / 11 / 1|
|current|25 / 25 / 21|6 / 10 / 1|
|current_support|25 / 24 / 21|6 / 11 / 1|
|temporal|27 / 25 / 18|3 / 7 / 1|

原始输入缓解了旧pair的HB检出不足，但没有在原工作点恢复原max的及时数。实际误报1 vs8/360，不能将4或7个事件差全部称为等误报下的能力损失。5%原校准工作点HB为current28、temporal28、原max30；实际误报11/7/16，也不同。

同一模型内，单高度H或B能及时报警、扩展为连续HB后却漏掉的anchor仍有current9、temporal12，旧pair15、原max0；这些是成对物理结构检查，不是独立新确认。原两分数共同不降并不代表新增原始特征也共同不降，所以不能把新模型的下降直接套用为旧两输入的单调性违规。该[事后诊断](../../../../artifacts.local/work/cnh-raw-radial-information-dev-20261007/hb_structure_diagnostic.json)不参与重训或阈值调整。

## 决定与后续

保留当前原始距离摘要作为候选输入；本轮不优先扩大历史窗口或模型容量。当前反复出现的问题是原单高度训练分布上的提高不能直接迁移到组合高度。下一步优先检验**训练是否缺少组合结构支持**：在原完整unit划分下，仅将train角色的已有物理变体用于新增训练，并以同anchor、同新增权重的单高度重复为对照。先用旧两分数模型定位训练支持的贡献，原calibration控制仍单独定阈值；HB评估只使用其原OOF fold。此后HB属于明确参与方法开发的结构分布，绝不能称新鲜验证。该后续实验尚未冻结或运行。
