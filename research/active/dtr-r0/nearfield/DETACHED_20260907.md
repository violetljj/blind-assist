# NF-G11: detached spatial gate

Completed 2026-09-08; protocol and capture identifier 20260907. EXPLORE,
controlled Willow Development only. Base: [G10](DIVERSITY_20260907.md).

**Retain G10 as the near-field baseline.** Detaching the predicted support gate
recovers localization, but fails the predeclared requirement to preserve decisions
at the original operating point. Validation calibration creates a useful ensemble
tradeoff, not a uniform improvement: joint correctness improves while bar recall
falls. Keep the detached checkpoints as a disclosed challenger; stop this fixed
experiment without sweeping weights, choosing a TEST seed, or promoting App/video.

## Fixed comparison

Original gate reuses all three G10 expanded/region checkpoints with zero refits.
Detached gate starts from the same original G8 ordinary checkpoints, seeds
17/29/43, using the same 800 TRAIN images, 96 common VAL images, 600 steps per
seed, batch 32 with eight per geometric variant, AdamW 1e-4 / weight decay 1e-4,
near BCE + 0.25 support BCE. Minimum VAL near BCE selects every 50 steps;
all three selected step 600. Architecture remains 45,646 parameters.

The sole training change is `gate = support.sigmoid().detach()` before multiplying
spatial features. Support supervision remains attached; the shared spatial
backbone still receives near-loss gradients. This does not isolate the tasks.
Reconstructed batch-sequence hashes match the executed new sequences using G10's
original helper, RNG and full dataset offsets. G10 did not save an independent
executed batch trace, so this is not a comparison against such a historical trace.
The retained executed G10 trainer and delivered formatting revision have equal ASTs.

Fresh TEST uses g5000..g5031, seed 11080907: 16 narrow and 16 diverse groups, each
with both / bar-only / box-only / neither. All 128 images pass unchanged native
visibility, intended BODY/HEAD query and floor verification. Parameter ranges
match G10 TEST; no new TRAIN material was created. Same Willow map throughout.
The protocol was written before these outcomes. TEST is now consumed.

Primary uses frozen G8 ordinary ensemble thresholds BODY 0.1558650881 and
HEAD 0.3789404432. Secondary selects each arm's thresholds only on the existing
G10 VAL set at the existing <=5% validation-FPR rule. TEST never selects thresholds.

## Localization and predeclared decision

| Positive support localization, ensemble | Original | Detached |
| --- | ---: | ---: |
| BODY IoU at 0.5 | 0.160 | 0.252 |
| HEAD IoU at 0.5 | 0.113 | 0.230 |
| BODY peak hit | 35/64 | 52/64 |
| HEAD peak hit | 36/64 | 50/64 |
| BODY IoU at VAL-selected mask threshold | 0.316 (@0.90) | 0.404 (@0.85) |
| HEAD IoU at VAL-selected mask threshold | 0.269 (@0.95) | 0.461 (@0.85) |

Mask thresholds use only positive G10 VAL queries, grid 0.05..0.95 by 0.05,
maximum mean IoU with smallest-threshold tie break. Both heads improve fixed IoU
and peak hit in all three paired seeds. The gain is therefore not solely a 0.5
binarization artifact. These are native query-support regions, not complete object
segmentations. At VAL mask thresholds, any negative-image activation remains
BODY 64/64 for both arms and HEAD 57/64 versus 55/64; average active pixel fractions
are BODY 0.02007 versus 0.01508 and HEAD 0.00393 versus 0.00288. Sparse activation
is not the same metric as a near false alarm, nor evidence of a clean mask.

Predeclared ensemble retention required both fixed-IoU gains >=0.05, peak-hit
drop <=2/64 per head, near-FP increase <=2/64 per head, joint drop <=1/32,
diverse-joint drop <=1/16, and bar-recall drop <=1/32. Localization and primary
bar recall pass; both FP budgets, total joint and diverse joint fail. These are
practical descriptive tolerances, not statistical noninferiority claims.

## Spatial intervention on consumed G10 TEST

No training: replace each predicted map with its per-image/head mean, or preserve
its values while shuffling positions with fixed seeds 101/103/107. Evaluate all
three models and ensemble; only the 128 consumed G10 TEST images are scored.

| Ensemble intervention | Joint /32 | BODY FP /64 | HEAD FP /64 |
| --- | ---: | ---: | ---: |
| Original | 21 | 9 | 4 |
| Same-mean constant | 0 | 60 | 50 |
| Shuffle 101 | 0 | 58 | 46 |
| Shuffle 103 | 0 | 53 | 46 |
| Shuffle 107 | 0 | 58 | 43 |

This argues against a mean-strength-only switch: spatial arrangement matters.
It does not establish correct obstacle localization. These interventions also
break learned feature/map alignment and are out-of-distribution diagnostics.
Detach's localization improvement supports a direct-gradient tradeoff on this
training setup, not a universal cause or complete separation of the tasks.

Initial strict reproduction failed under TEST-only batching and different input
normalization/backend settings (retained failure: max score difference 0.0003593,
zero alert flips). Restoring the original full 864-image batch layout and in-place
normalization reproduces all three original seed scores exactly. The diagnostic
ensemble differs by at most 7.95e-8 with zero alert flips. Both layout and input
handling changed, so their individual numerical contributions are not isolated.
Failure logs/source are retained; this repair did not train or tune a model.

The training pipeline independently reproduces original scores for all 864 G10
images and stored float16 TEST support maps bit-exactly for all seeds. Separate
consumed G10 regression gives primary joint 21 -> 15 and secondary 22 -> 26;
secondary bar recall 31 -> 29. Regression is not fresh confirmation.
