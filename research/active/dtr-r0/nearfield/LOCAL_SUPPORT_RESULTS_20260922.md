# LOCAL 原生支持诊断：空间对应值得研究，硬门控会损失早检

2026-09-22。按[冻结协议](LOCAL_SUPPORT_PROTOCOL_20260922.md)完成一次既有数据
诊断和一次独立审计。**36 个 LOCAL 救回帧中，32 个在最高分中心查询内
确实有已输出单回波的原生贡献点；另 4 个原生可见，但单回波没有输出
对应走廊支持。** 两个新增误报均没有中心走廊原生支持。

固定特权支持条件保住 32/36，恰好达到门槛，并去掉两个新增误报；
但四个真例首报比原 LOCAL 晚 0.2–0.4 s。任一中心查询的对照与主条件
完全相同，没有通过切换 BODY/HEAD 归属找回这四帧的机会。
保留的是**已输出回波中的细粒度位置具有诊断价值**，尚未证明公开 RGB/ToF
能学出此对应关系。原 LOCAL 继续作为 COMPONENT，不安装这两个特权过滤器。

## 输入和证据身份

使用[上一轮迁移](LOCAL_TRANSFER_RESULTS_20260922.md)的全部 576 已消费帧：
48 clips、8 个基础几何、两种背景、6 个查询，共 3,456 query、10,368 band。
没有新增采集、模型加载/预测、训练、阈值选择、删帧或重新选择外观。
原 A/LOCAL 决策、UNKNOWN、原生深度、渲染 bounds 与公开观测分别封存。

原模拟器、原 noise key 重建 ToF，576/576 数组逐值一致；10,368 个
band 像素占比在固定 1e-6 容差内复现，零 mismatch、零无效 query 标签。
只取真正输出的 winning-bin 贡献点，未输出模式、掉帧或原生可见表面
不会被补成传感器已经观察到的返回。native 是 optical Z，不是硬件量测。

这不是重跑 MZ183 的重建 actor-mask 角支持，也不是旧 A* 的六维 full-face
表示替换。那些负结果保留原责任范围。MZ130 提醒帧级指标可能掩盖原生点
排除，本次因此保留完整贡献索引；multireturn 的额外槽位也未在此生成。
这里检查的是已保留 LOCAL 的区域距离广播、原生位置与 query 对应。

## 两个新增误报到底混入了什么

两帧是 `local_transfer_body_suspended_solid_g00_base_outside_06/07`，
最高分均来自 HEAD 中心 query 4。其 definite band 为空；possible-only
band 却分别包含 735、326 个 RGB 像素。每个像素对应四个独立 native
子像素，未做深度平均或插值。

| query 4 的 possible-only band | 06 帧 | 07 帧 |
| --- | ---: | ---: |
| 原生子像素总数 / 有效数 | 2,940 / 2,940 | 1,304 / 1,304 |
| 真正落入该 query | 0 | 0 |
| 仅与 target bounds 兼容 | 1,325 | 224 |
| 仅与 background bounds 兼容 | 1,064 | 560 |
| 未归属到声明 bounds | 551 | 520 |
| 同时兼容两者 | 0 | 0 |
| 深度落在该区域公开区间内 | 1,097 | 224 |

深度相容的子像素全部与走廊外 target 兼容，而没有一个实际落入查询。
因此问题不能简化为“只看错了背景”：**区域区间被广播到多个像素，
走廊外目标、背景和未归属表面共同进入了假设性的 possible 支持带。**
深度相容本身不能解决横向位置；同样，仅剔除背景不能保证消除这些误报。

所有归属名均指渲染 AABB ±0.02 m 的几何兼容，不是 captured segmentation
或真实返回身份。未归属的 1,071 个子像素保持未归属，没有强行叫作背景。
真实救回帧也混有背景：其 HEAD 中心 possible band 合计 11,716 个子像素，
仅 1,957 个实际在 query 内，5,325 个只与背景 bounds 兼容。
这些是描述性累计数，不能从两个 FP 再选“纯度阈值”或证明整个特征空间可分。
上一轮换背景导致分数变化与本次混合支持事实相容，仍不是具体树分支的因果证明。

## 决策与交付

主机会门槛 PASS：保留 32/36，去掉 2/2 新增 FP，并按构造保留 A。
32 恰好是允许损失四帧的下限，不是无损方案；此成本选择只适用于本诊断。
保留原生支持分解为诊断 COMPONENT，不能把 224/4/32 作为公开算法成绩。
它支持下一步关注**可公开估计的像素与区域回波对应**，并独立评估早检代价；
没有证明可学习性，也没有启动后继模型。14 个已有支持的剩余漏检和 14 个
尚未输出支持的漏检分别保留，不合并成单一“再训练就能解决”的任务。

旧 LOCAL 迁移的 228/6/28、原始批次误报段失败、A/UNKNOWN、RAW 负对照
及 CNH 暂停状态都不改变。没有容差、点数、查询或阈值扫描，也没有部署。

8 项合成测试通过；独立审计的 16 项合成断言通过。科学诊断与审计各执行
一次，没有重跑。独立审计检查 596 个输入文件，重算全部 576 帧、48 clips、
3,456 native query 和每个已输出 bin 的成员/权重，并重新计数所有读出、
分层、事件、首报及 gap。独立 band 几何重建覆盖确定性的 192/576 帧、
3,456 bands，包括全部 38 个新增告警帧及其背景配对，再加各 clip 固定
0/5/11 帧；其余 band 只核对保存成员/特征占比，不冒充全量独立重建。
合计 873,123 个审计断言通过，stage PASS 与研究机会 PASS 分别记录。

审计不导入主诊断、模型、模拟器或原指标计算；不重复 RNG/noisy range
重建，而核验主阶段的逐值一致性回执和封存数组。哈希认证不能证明原生
深度等同真实设备或真实分割，这些边界随结果保留。

CPU / NumPy 2.4.4，TASK_NOT_GPU_SUITABLE；诊断 48.45 s、审计 42.18 s，
包含读取/归属计数/封存，不是运行时预测延迟。没有模型、UE、远端 worker
或付费进程被创建；两个 governed journal 均 succeeded。

两个 RunSpec 与 console；同名前缀 `-run` 保存完整诊断、lineage、指标及
input/output seals，`-audit` 保存独立复核及覆盖身份。journal 位于
