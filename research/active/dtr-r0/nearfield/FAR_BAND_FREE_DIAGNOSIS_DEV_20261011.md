# 远带 FREE 误支持诊断（EXPLORE，2026-10-11）

**未发现“远带严格 FREE 参考错标”是多个方法失败的共同主因。参考质量需要在未来版本中显式约束，但本轮更直接的下一步是检查融合器如何在局部深度没有侵入证据时仍给出支持，再检查 RGB 远带深度误差。** 所有数字是已消费 Development 上的诊断标记，不是新的方法成绩；旧 v2 远带失败、v1/v1.1 结果与阈值继续保留。

诊断共 528 个 query，三组各 176：全取误支持 (a)，随机未支持严格 FREE (b)，随机 POS 对照 (c)。每个 (a) 已生成 RGB 裁剪、query 投影与 native 有效/缺测、confidence 掩码，以及 LiDAR/FARO/DAV2/UniDepth 深度剖面，共 176 张 PNG 和本地 HTML。官方 confidence 补齐 239/239 个所需帧，无 GPU 重推理。

## 样本与固定规则

[PLAN](FAR_BAND_FREE_DIAGNOSIS_PLAN_DEV_20261011.json) 在选样和原因计数前写定；seed=20261011。v2 仅读已消费 eval12 的不可变 native_perturbed 逐 query 决策：逻辑回归 96 个与 RGB 39 个 FREE 支持的并集为 111，交集 24。v1.1 全部 split 共 3,456 个远带 query，以原 DAV raw 切点 0.24403834342956543m 定义 RGB 支持，另合并旧融合 v1 已消费 eval4 的不可变 logit 决策；得到 65 个误支持，含原 RGB 55 个及 logit-only 10 个。train/cal 没有已有 logit 决策，不新增模型前向。两个数据集工作点各按自己的历史合同解释，不能池化为统一 FPR。

全部候选 inventory 为 6,912 个远带 query。v2 FREE/POS/UNKNOWN 为 270/2,108/1,078，v1.1 为 203/1,833/1,420；UNKNOWN 不进入三组。K2 与 native/FARO 来源副本均不增加样本数。v2 (a/b/c) 各 111、v1.1 各 65；(a) 共 15 个贡献 visit，未把 query 当独立场景。

先匹配 dataset/visit 的 (a) 数量、无放回抽样。六个 visit 的 (b) 不足：v1.1 的 421254/421259/421260 缺 20/19/5，v2 的 422011/422134/422535 缺 14/7/16；按事先写定的剩余容量规则在同数据集补足。**总数相等，但 (b) 并非完整逐 visit 匹配**；selection 保留缺额，per_visit 与共同 visit 差值一起交付。(c) 完整匹配所有 (a) visit 的数量。

三类允许重叠，均为固定诊断条件，不修改评价阈值：

- 标签可疑：native 有效 query 像素射线少于 64，或 confidence=2 占比低于 90%，或严格 FREE 的 FARO 区间内表面至少 16 像素。FARO 冲突也可能来自配准/重建，不能自动认定 native 标签错误。
- 读出几何风险：射线域触及图像外侧 5% 边缘，或域像素少于 64，或 DAV margin 前 16 条射线中超过一半物理相交长度小于 0.10m。边缘是位置代理，短相交是结构风险，均不构成已证实的原因。
- 深度模型误差强证据：native 所有域射线均有 query 出口之后的深度，confidence=2 至少 90%，FARO 至少 90% 的域像素有出口后的表面且区间内为零，DAV 区间内至少 16 像素。其余 native/RGB 不一致单列“独立空参考尚未确认”。

另列 fusion-only（logit 支持而冻结 RGB 不支持）及三主类均未命中的 unresolved。一次实现语义错误曾把 POS 的 FARO 内表面也算作标签矛盾；已修正为**只有 FREE 才有 FARO 标签矛盾，POS 内表面单列相容证据**。原 PLAN、抽样、(a)/(b) 数字与条件均未变，初稿表保留于 `attempt0_pos_control_semantic_bug/`，修复理由见 `rule_clarification.json`。

“DAV 区间内至少16像素”是 margin≥0 的局部几何诊断，和各数据集冻结 RGB 支持切点不同（v1.1为0.24403834342956543m，v2远带为0.12002337635498161m）。因此 (b) 也可有少量模型侵入标记而未达到原支持条件，9/176 的强证据与16/176的未确认不一致不构成冻结决策矛盾。

## 参考与深度测量

native 深度是 Apple 发布的 256×192 深度图，计数是落入投影射线域的**像素采样射线**，不是硬件原始 LiDAR beam 或独立回波数。逐 query 已分开记录 inside/before/after/invalid、confidence 0/1/2，以及光轴 Z、欧氏射线距离和出口后的间隙分布。严格 FREE 本来要求全部域像素有效且 depth>exit，因此 (a)/(b) native 缺测率全部为零、域内占据为零，不能作为独立准确性证据；真实原始回波稀疏性在现有数据中不可直接测。

以每 query 中位再取组中位，(a/b) 出口后回波 optical-Z 为 3.482/4.011m，沿射线距离 3.647/4.225m，超过各自出口的 Z 间隙 1.270/1.841m。不是把 3m 一刀切当所有射线出口。confidence=2 比例组中位 (a/b/c) 为 85.4%/71.2%/93.8%；FARO 覆盖为 95.4%/92.6%/89.6%。每 query 的完整 confidence 数量和缺测/FARO 分位数在诊断表。

FARO 使用固定 fused_surface 渲染缓存，在 **grid pose → RGB pose** 后以 nearest-pixel z-buffer 对齐，native 未填洞。缺 pose 或孔洞保持 UNKNOWN，没有用过去的 CNH ≥52 zone 方法门筛掉诊断样本。FARO 非 native 同值源，但官方 high/low 筛选相关性、静态重建与米级配准长尾仍在；“两路确认为空”只指本报告的可见采样参考条件。

DAV/Uni 对 native 的域内逐像素绝对差中位，再取组中位分别为 (a)0.709/0.231m、(b)0.611/0.326m、(c)0.316/0.166m。这不是有独立真值的模型 MAE，且远带冻结 RGB 使用 DAV；Uni 只作未改变工作点的深度对照，不据此选择替换模型。query 位置的 top/bottom 仅为图像位置，没有自动把它解释为地面/天花板。

## 建议与未来参考草案

**不因本轮标签风险占比高而回溯修订远带结论，也不优先启动读出修补。** 先检查融合器的局部支持合同与几何/缺测特征依赖：为什么 DAV 没有任何足够侵入、甚至 native/FARO 均在后时仍输出支持。可在新的授权诊断中只读已有模型系数和特征贡献，区分公共位置先验、缺测编码和两路不一致；之后才用新建立的评价判断是否需要改变融合输入或训练。RGB 的 33 个双源空参考冲突提示第二优先级应是 DAV 远带局部 metric-depth/边界误差。本任务没有执行这些改变。

**建议未来新建远带参考 v2 时增加质量合同，而非宣布现有标签已错。** 草案仅用于未来、在采集/模型输出前冻结，不能把本轮筛后子集变成过去 eval 的“修正版成绩”：

1. 保留全部公开 query 与逐射线穿越定义；缺深度、遮挡在入口前、低 confidence 或缺位姿一律 UNKNOWN，不把删去低置信像素后的剩余集合宣称整 query FREE。
2. FREE 见证要求实际使用的 native 射线 confidence=2、有效采样数下限（草案64像素），并预声明域覆盖与空间分布；如果只有已插值的深度图，明确 count 为采样像素，不能借像素数声称硬件 beam 密度。
3. native 必须有超出每条 query 出口的回波，并在新数据前约定边界余量及量化误差处理；边界不足的样本保持 UNKNOWN，不用已消费支持结果选余量。
4. 有独立 FARO 时，要求预声明配准检查、足够的 query 域覆盖（草案90%）、出口后支持和无区间内表面；FARO 缺覆盖或冲突则进入 UNKNOWN/人工复核，不把稀疏或可疑注册的 FARO 当绝对真值。无 FARO 的 native-only 标签需独立身份，不与双源参考混称。
5. 单列玻璃/镜面/细物体人工审查及可见/不可见身份，保留拒绝率和每visit各带覆盖。先确认可形成有效的未来分母，再冻结新评价；本轮不报告草案筛选后的方法指标。
