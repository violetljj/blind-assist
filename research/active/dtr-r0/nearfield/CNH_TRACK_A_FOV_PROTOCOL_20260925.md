# Track A 阶段1：视场选择协议

冻结于计算前，2026-09-25。用户本轮明确授权 Python Track A、v1.1 与最多12独立单位工程试采；取消旧 HEAD 诊断前置。旧结果不改，City/test/UE/硬件均不运行。

纯几何积分，不生成场景或传感器结果。Q 六盒继承 v1.0，X 中心 -0.3/0/0.3、半宽0.3；HEAD Y[-0.2,0.42]、BODY Y[0.42,0.9]。Z 三段 [0.3,1)、[1,2)、[2,3]；另报 HEAD Y<0。方锥 HFOV=VFOV=45°，相机640×360/HFOV100°，平移0。

旋转：列向量，ToF→Q 为 Rx(head_pitch) Rz(head_roll) Rx(mount_pitch)，X右/Y下/Z前，负俯仰向下。Q偏航随头，因此头身偏航对无障碍盒覆盖积分消去；高度随Q平移亦消去，不伪造其影响。纯体积不计遮挡。

姿态采用 seed=20260925 的 scrambled Sobol 256 点，pitch U[-15,10]°、roll U[-10,10]°；每盒每距离段16³等体积中点，固定计算而不根据结果加点。报告各盒覆盖在姿态上的median/p10/p90，HEAD-above亦然。数值为离散积分近似，不是解析精确解。CPU NumPy 足够，小型几何积分不启动GPU。

选择：对 p=0,-5,-10,-15,-20,-25,-30°，先对三个横向盒等体积合并，再取姿态中位数，得 [1,2) 上 cH/cB；score=min(cH,cB)。最大score相同时先距-15最近，再取较小绝对角度；若最大score减score(-15)<0.05，保留-15，否则选最大者。M0=0。此规则不得看结果后改。选择是模拟对照配置，不是产品安装决定。

阶段1输出JSON、全部盒表和覆盖-距离图，记录源码hash。随后把选择值写入v1.1并提交，才实现生成器。任一冻结验收失败停止下游、保留回执；12单位是上限，不是允许绕过失败完成配额。
