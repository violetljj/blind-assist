## 查询级校准探针

沿用此前固定 27 格、全部位置和标签。三条 ARKit capture 各 16 帧／432 查询，共 1296；POS 609、严格采样 FREE 572、UNKNOWN 115。原 cal16 仅 2 个严格采样 FREE 查询，本轮并未新增真实参考。

每查询取有效域内第 16 大射线分数，`score >= cutoff` 等价于至少 16 条射线支持。点读出分数为米制 interval margin，CDF 为区间分数；不足 16 条有效射线为不可用，保存 JSON 使用字符串 `-Infinity`，不视为零。正见证要求至少 16 条参考正射线获得支持，不能用 UNKNOWN 区的支持补足。

三折留一 capture：仅另两条 capture 的严格采样 FREE 分数选最接近且不超过 5% 的经验支持比例，全部并列分数保留。正例与留出 capture 不参与选值；各折先保存实际 cutoff，再评价留出 capture。5% 是探索设计选择，不是已认证 FPR，也不是旧射线目标 .14190356448。

## 决定、核验与资源

保持 affine 几何强对照、上一轮 3RScan 局部增量和全部负结果。当前配方不继续通过移动评价阈值争取升级。下一优先检验“以度量几何为主干、学习受约束距离残差”的不同机制，减少直接重新生成绝对距离时对几何关系的改变；残差定义和幅度需在新 run 中先确定，再按相同 train/cal 条件比较。它是待执行提议，不能由本诊断保证收益。同步补跨环境固定网格的查询级负校准参考和新相机／完整身体、细结构与步行事件参考；真实评价仍为硬目标。

核验覆盖：208 份实际 mask、原 train 配对身份、6 个真实帧的完整分母与原 DP 重采样、6168 次独立标量误差；1296 查询参考计数、6480 第 16 大值排序、19440 支持／见证阈值等价、15 折臂 cal 最优性、12960 条保存决定重读（含 3435 个不可用见证 sentinel）。父 plan 与执行 source SHA 对应。没有重跑无关 Android 或旧臂核验。

两次执行故障保留：点分析在 CSV 写出接口处失败，修正后完成；首失败没有完成计时，记 null 并保守占 120s，未补造实测。查询分析首次遇 −∞ 严格 JSON 保存失败，改为显式 sentinel 后完成并核查重读。它们未改变科学判据。

资源预算 CPU 1200s（点 600、查询 300、整合 300），GPU 0、下载 0。点支线实测最终诊断 16.937s＋作图 2.597s、含首失败与收尾保守记 160s；查询含失败及收尾实测 12.721s、保守记 30s；整合／文档／交付保守记 300s，总计 490/1200s。任务计算资源释放，模型、原阈值及旧 payload 未覆盖；新的三折校准值独立保存。全部持久工件 owner 为本 run，路径 `artifacts.local/work/rgb-body-query-migration-diagnostic-dev-20261010/`。

这些 capture 均已消费且同相机家族，帧／格／点相关，三折不是独立确认或第三硬件。严格采样 FREE 不证明整盒／身体空间无障碍；UNKNOWN 不是负例；未形成完整身体误报、细障碍或真实步行提前量。不同距离误差、输入差异和工作点取舍共同缩小假设范围，仍不能定位单一原因。CNH 范围／预算、旧停止配方与原确认身份保留。
