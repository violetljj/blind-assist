# V2 融合臂 RGB 使用诊断（Development）

结论：现有三颗 seed 的融合 checkpoint 在这三个巷道 dev 布局上几乎不依赖 RGB。将 RGB 在每个布局的 160 帧内部打乱或全置零，查询级 AUPRC 最多只变动 0.0006；这说明本模型当前没有学到可观的 RGB 增量，不说明 RGB 本身无信息。V2 原冻结结论不变，测试集与 City 均未触及。

输入是 V2 的六个既有巷道 Development overlay、冻结划分和三个融合 checkpoint。只对 480 帧 dev 做重推理；每帧六查询。每个布局用 NumPy `default_rng(20260925)` 随机排列 160 帧，再让排列中的每帧取其后继帧 RGB，形成无固定点、布局内的一条环；三 seed 使用同一映射。ToF、ambient、标量、有效位、age、视锥支持和 checkpoint 均保持原值。置零臂把 RGB 精确置零。原图重推理与 V2 原保存 logits 的最大绝对差为 `0.0`，三 seed 均通过。
