# MZ108: visual-region gain retained; spatial alert gain not achieved

2026-09-13, EXPLORE. Same single RGB+ToF+Radar+IMU architecture. Retain the
stable-region extractor as a controlled Development component. Reciprocal
association is a useful ambiguity diagnostic, not reliable identity proof.
Do not promote the combined spatial-alert candidate.

## What improved

Replace reliance on one global brightness threshold with fixed MSER intensity
regions, retaining Otsu regions and removing nested duplicates. No learned depth,
semantic labels or native geometry enters the extractor. Require reciprocal
uniqueness before committing a Radar--region--ToF association: two eligible Radar
returns competing for a region make that region's association UNKNOWN.

All four fixed arms were sealed on both96-frame panels before evaluator reads.
The legacy implementation and RGB-off baseline reproduce exactly. Twelve focused
tests pass; independently valid ToF support survives every arm.

The combined candidate removes1 real boundary FP (`boundary_2_03`) but adds2

associations; the failure is subsequent spatial extent estimation, not identity.
The negative-side object's true inner edge is -0.310m, outside the -0.300m corridor
boundary. Image extent projected using one noisy Radar range puts it at -0.294m
and -0.262m, producing false overlap. A correctly identified object is not yet a
precisely localized obstacle. This is a concrete uncertainty/extent issue for a
future separately scoped study, not authorization to tune a corridor margin now.

No-support UNKNOWN counts are27 unchanged on old data and40 baseline/39 candidate
on new data; UNKNOWN is never CLEAR. These are instantaneous spatial-support
metrics, not final alarm timing or predicted future collision. Full system
breakthrough has not been demonstrated.
