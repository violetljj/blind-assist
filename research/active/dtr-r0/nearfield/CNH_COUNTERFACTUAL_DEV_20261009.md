# CNH 新背景与生成覆盖三臂匹配实验（Development，2026-10-09）

本轮支持新增场景训练的任务收益，但不支持 target×background 全交叉（CF）比等量 ordinary 扩充具有稳定额外优势；优先保留普通扩充作为后续数据机制参照。两种扩充仍有 pass 报警成本，query +3° 对所有分支（包括冻结 M3/旧融合）的 clear 成本冲击明显，因此本轮不作全面替换或部署升级。

较实用的 ordinary＋旧5格 OR 在 validation ideal 相对旧融合的及时增量：HEAD [17, 15, 25]、BODY [23, 13, 38]，clear slots [58, 58, 58]（旧融合 58/6656），但 pass clips [89, 103, 115]/256（旧融合 60/256）；固定阈值 +3° clear slots 增量为 [52, 16, 107]。下一优先核实 publicquery/pose 输入合同；这与重调已停止旧实验是不同问题。

本轮比较相同 bin-token 读出器的 Base、等量普通新增场景与 target×background 全交叉新增场景。主要判断是固定校准后，CF 相对 ordinary 在两个本次新增训练外背景结构族上的任务收益和报警成本。三个训练 seed 保留全部结果；不按验证结果挑选 seed、checkpoint 或阈值。

按 seed 顺序 [2026100955, 2026100956, 2026100957]，standalone：CF−ordinary 的 HEAD 净事件 [-2, 13, 0]、BODY [0, -4, -7]；ideal clear slots 差 [18, -2, -1]，+3° clear slots 差 [172, 115, -1]。 旧5格 OR：CF−ordinary 的 HEAD 净事件 [-7, 0, 2]、BODY [-10, -2, -10]；ideal clear slots 差 [0, 1, 0]，+3° clear slots 差 [-26, -2, -10]。

这些是匹配运行的描述性结果；不以“所有 seed 必赢”作新增门槛，也不从平均收益跳过个别 seed 的完整损失与报警成本。

## 机制与公平控制

各 seed 同初始化，BoundaryTokenReadout 8833 参数，center 读出、signed-face 六通道置零，相同 batch=256、固定 7488 optimizer steps、最终 checkpoint。Base 用旧训练行重复填满相同 slot；两个扩充臂均有 768 scenes×K2×13=19968 新行，新增占训练 slot 的 1/3。三臂均只用普通 masked weighted BCE，不消费 pair 身份。

Ordinary 与 CF 的 target、presence、背景 instance 等边际量一致。target×background×presence 联合覆盖为 501→768，实际唯一物理世界为 268→392。若有改善，也只能归于这套生成分布的覆盖/多样性变化，不能单独归因于配对身份、反事实损失或因果学习。

删除物体独立重渲染剩余背景；所有 boxes 重算标签，不从旧 hist 扣除。相同物理世界+occurrence draw+replica 共用 photon seed，重复 occurrence 独立采样。pass 的监督 mask/weight 为 0，contact=1、clear=0；far 权重沿用旧规则，每个扩充训练集总权重归一为行数，未额外类平衡。类别、placement、family 不输入模型。

此次新增数据的背景 family 整体分区，相关增删版本保持同一区。每个 cal/validation 有两 family、各两 instance；固定 96 个 target fixtures×4 backgrounds=384 scenes，K4。cal/validation 的 target ID 不同但形状与摆位模板相同，覆盖四 shape、两高度、左右侧、侵入 1/4/12cm、pass、clear、absence。这是此次新增训练外的几何背景模板/实例、固定 shape-grid 迁移。该 disjointness 不追溯保证继承的 39936 旧训练行或 M3 历史预训练从未见相似几何；旧数据包含通用背景。因此不宣称全历史结构独立，也不是新形状、真实材质、环境或独立用户迁移。

每个评估分支 HEAD/BODY 各 384 接触事件；joint-clear 6656 slots、512 clips；pass 256 clips；physical contact 任一高度分母 768。一个及时事件是 scene×replica×height，replica 是噪声重复；同一 target 跨背景和三个训练 seed 有相关性。每个 split 的 384 scenes 实际对应 324/324 个唯一物理世界（cal/validation；absence 名义 target 重复共享相同背景世界）。不能把这些分母或三 seed 扩大解释为 iid 世界样本数。

bin_summary 与 main Base 同 seed 初始化、8833 参数、7488 steps、旧监督和 slot 顺序。它在原生 normalized_z 中保存首个局部峰位置、幅度和 signed total：峰要求 z≥3、z>左邻、z≥右邻；固定 decoder 在首峰 bin 放峰幅，其余十五 bin 均分剩余 total；无峰时十六 bin 均分 total。随后用同一模型训练与推理，并非仅把若干输入通道清零。

这只能比较该三标量摘要/固定 decoder 与完整 bin 历史在本模型下的结果。摘要退步不能证明所有压缩法无效，也不能单独建立“保留原生 bin”论文机制；完整表同时保留与 Base、Ordinary、M3 和旧融合的配对损失。
