# ToF 引导双目：几何组件改善，联合告警未改善

2026-09-23，EXPLORE；576 对 MZ101/MZ102 已消费渲染 Development。

固定原版 FoundationStereo Large，使用理想 64 射线 ToF 做 VPP 匹配阶段引导后，
正确查询区内且轴向深度误差不超过 5cm 的比例从 **87.62% 升至 94.75%**。
但相同 ToF 联合和告警保持下，最终 TP/FP/FN 从 **377/22/69 变成 375/24/71**。
保留为 **COMPONENT_OR_CHALLENGER / COMPONENT**，不替换告警基线。
这次结果支持“距离提示能改善空间估计”，尚不支持“避障任务已经升级”。

## 固定配置与证据边界

- 主对照是同一原版 Large 的有引导/无引导输出，各自派生纯深度和深度+ToF 四组。
  SGBM+ToF 是同场历史参照；当前 A 没有参与这次回放。
- 原版 `23-51-11 / ViT-Large`，源码 `6e8806816b533e4d13ddbb95ffa907b797060a62`，
  checkpoint SHA256 `60e79bde9c6a00acea551625ff814fe06e5a6806e2c0c9829baee248de87c5f1`。
  输入 640×360，padding 至 384×640 后还原，32 iterations、max_disp 416、mixed precision、low_memory 0。
  延用前次完整权重加载与运行兼容配置，没有更换模型或权重。
- 使用 [官方 VPP 实现](https://github.com/bartn8/vppstereo)，revision
  `ecf12d40a816286d541c96c46746f43401836cfa`，`vpp_standalone.py` SHA256
  `247861d3b38675dce34d3be85df43182e94839057934efa3693cc9443046fd12`。
  固定 rnd、3×3、blending 0.4、非统一随机颜色、亚像素插值、左至右遍历；
  每帧种子由 panel/id 确定。没有参数、随机种子或检查点竞赛。
- 理想中心射线的径向距离先转换为左相机坐标及轴向 Z，再按 fB/Z 投影视差；
  ToF 与左相机同原点，右相机基线 0.1m。仅使用有效 0.5–4m 返回。
  不用原生真值补点、删点、选择遮挡提示；无返回不等于自由空间。
- 3×3 投影隐含局部近似等视差，可能跨越边界，未使用右图真值遮挡掩码。
  这里是精确登记点提示，**不是实际 8×8 区域 ToF 的验证**。
- 下游 FOV、姿态、空间查询、ToF union、two-on/two-off 保持全部固定。
  模型推理只读取公共 RGB、ToF 与标定；两面板支持/告警封存后才进入真值核算。

配置 hash 为 `2b70c1b1a32ab7c892739535101d0e9e4cd0f46e113473db948651ba8dee3dcd`。
3 帧接口检查后完成一次完整 576 对推理。实际后端 CUDA / RTX 5060 Laptop；
推理均值 0.925s/对、含投影与写出均值 1.002s/对，总耗时 589.7s。
这是离线回放耗时，不是实时设备能力。

## 同场任务结果

TP/FP/FN 是 BODY/HEAD 查询帧计数，不是独立事件数；表格为两面板描述性合并。

| 配置 | 当前空间支持 TP/FP/FN | 最终告警 TP/FP/FN | 最终检出事件 |
| --- | ---: | ---: | ---: |
| SGBM+ToF | 435/62/11 | 402/40/44 | 56/56 |
| 无引导 Large | 405/16/41 | 359/22/87 | 52/56 |
| 无引导 Large+ToF | 423/16/23 | 377/22/69 | 55/56 |
| VPP Large | 422/16/24 | 374/24/72 | 55/56 |
| VPP Large+ToF | 423/16/23 | 375/24/71 | 55/56 |

纯深度原始支持新增 18 个 TP、丢失 1 个 TP；联合后只新增 1 个、丢失 1 个。
这说明多数纯深度检出收益与原来 ToF 已覆盖的查询重合，不能把它们全算作联合系统增益。
具体而言，18 个新增原始 TP 中 17 个原本已被 ToF 覆盖，15 个新增最终 TP
全部已被原无引导 union 覆盖。
最终纯深度新增 15 个 TP，同时新增 2 个 FP；主对照联合告警则丢失 2 个 TP，
新增 2 个 FP，没有新增 TP 或消除 FP。

主对照没有新增整段漏检，但原有 `small_head_flat` HEAD 漏检仍在；MZ101 最大额外首报
延迟为 0.25s，MZ102 为 0。联合误报段仍为 18 段，误报查询帧增加 2 个。
因此该配置既没有优于无引导联合告警，也未完成对 SGBM 的整体升级。

四个原始 union 变化解释了最终差异：

| 查询 | 当前支持变化与最终影响 |
| --- | --- |
| MZ101 `occluded_head_flat_02` HEAD | 删除出现前 FP，使 `_03` 真实起点不能立即满足 two-on，首报晚 0.25s、损失 1 个最终 TP |
| MZ101 `occluded_head_flat_11` BODY | 新增原始 TP；原 union 已保持告警，没有最终收益 |
| MZ102 `head_bar_flat_11` HEAD | 丢失原始 TP，与 `_10` 连续缺失，损失 1 个最终 TP |
| MZ102 `receding_flat_09` BODY | 新增原始 FP 并保持至 `_10`，新增 2 个最终 FP |

第一项尤其说明：单个几何修正可能与固定时间规则产生不同方向的任务变化。

## 几何收益与残留错误

固定分母为 **1,847,852 个原生可见查询区像素**；缺失输出计为失败，不先删除难点。
正确定位同时要求预测位置仍在同一查询区、轴向 Z 误差满足阈值。

| 指标 | 无引导 | VPP 引导 |
| --- | ---: | ---: |
| 正确查询区且 Z 误差 ≤5cm | 87.620% | 94.746% |
| 正确查询区且 Z 误差 ≤10cm | 92.590% | 97.407% |
| 正确查询区且 Z 误差 ≤20cm | 93.635% | 97.726% |
| 有效深度覆盖率 | 97.266% | 98.109% |
| 缺失像素 | 50,519 | 34,935 |
| 有效输出条件下 Z MAE | 3.723cm | 1.078cm |
| 误放入查询区的真实远处像素（>4m） | 57,580 | 46,904 |
| 误放入查询区的真实近处区外像素 | 82,513 | 4,599 |

逐像素配对：**修正 138,144，退化 6,466，净增加 131,678 个正确像素**。
覆盖率同时提高，不能用“只是删掉输出”解释整体收益。
约 62.6% 的净正确像素增量来自 wall 族；按像素加权的总收益不能代表各障碍等幅改善。
不过，大量减少的错误支持原本处于已经会报警的查询，因此像素改善不必改变二元结果。

只看任务负例查询，远背景误近支持却从 **28,518 增至 33,890**，区外近物体支持
从 1,724 降至 693；纯几何 FP 查询总数仍为 16，支持全部来自远背景的 FP 查询
从 9 增至 10。这是总体几何均值不能掩盖的失败。
两种 Large 纯深度输出的原始 TP 中，“支持完全没有任何原生区内像素”的查询均为 0；
这不代表每个 TP 的全部支持都正确，也不替代逐像素定位核算。

| 难例族 | ≤5cm 正确定位率：无引导→引导 | 有效覆盖率：无引导→引导 |
| --- | ---: | ---: |
| thin_left | 89.168%→89.733% | 98.643%→98.682% |
| thin_right | 85.129%→86.015% | 98.096%→97.905% |
| occluded_thin | 81.694%→83.275% | 99.633%→99.625% |
| small_head | 47.056%→47.056% | 49.294%→49.294% |

右细杆和遮挡细杆覆盖有小幅回退，已包含在固定分母与退化计数中。
`small_head_flat` 正例的 5,452 个原生像素仍是 **0 有效深度**；其全部 12 帧没有任何
ToF 提示，不能通过这种引导凭空恢复。结构表达也不能把这里的空缺当作已知自由空间。

## 提示覆盖与作用范围

共 5,374 个有效提示；372/576 帧有提示，**204 帧整帧无提示**。
独立审计确认这 204 帧的左右图、原始视差、原始深度及过滤深度与无引导版本完全一致。

以下三个查询类别互斥；“直接提示”只指测得的 3D 点在查询盒内，不证明同物体归属。

| 查询类别 | 查询数 | 原生区内像素数 | 修正像素 | 退化像素 |
| --- | ---: | ---: | ---: | ---: |
| 查询内有直接提示 | 308 | 1,701,982 | 133,132 | 3,929 |
| 查询内无直接提示，但帧内有提示 | 436 | 40,002 | 5,012 | 2,537 |
| 整帧无提示 | 408 | 105,868 | 0 | 0 |

另有 352 个查询在盒外 0.25m 内存在附近提示，它可能与“直接提示”重叠，不能与上表相加。
该切片修正 135,038、退化 3,096；联合最终 TP/FP/FN 为 266/15/30→265/15/31。
没有直接提示的全部 844 个查询，联合最终为 105/22/33→104/24/34。
整帧无提示的 408 个查询本次原始和最终计数都不变；一般情况下保持状态仍可能受先前帧影响。

按像素离投影中心的 Chebyshev 距离，≤1px 区域修正/退化为 1,072/63，
2–16px 为 78,819/1,950，>16px 为 58,253/4,453。
这些数字表明变化不局限于盖章像素，但不能单凭距离证明正确的同物体传播机制。
注入图案后的匹配一致性没有被当作独立真值；上述收益来自封存后的原生几何核算。

## 处置

保留 VPP 输出作为后续空间结构实验的几何组件，关闭这一固定配置的直接告警替换主张。
不在本面板追加 alpha、patch、随机种子、置信度或保持阈值扫描。
本次失败也不构成 ToF 的信息上限或双目+ToF 路线整体失败。

下一项值得检验的是：在这份已保存深度上，比较直接接触与分离可见表面片/细长结构接触，
重点约束远背景误近的连通证据和真实空隙，同时保留原始细杆残余证据及显式未知。
这项结构实验尚未运行；不能预先声称它会恢复无提示的小 HEAD 障碍。
若结构有开发收益，再用新布局确认；不把重复使用的历史面板改称新鲜验证。
当前 A、LOCAL 和 UNKNOWN 的责任边界不变。
