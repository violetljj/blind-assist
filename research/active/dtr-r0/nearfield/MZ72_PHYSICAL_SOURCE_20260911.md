# MZ72 physical-size obstacle source

EXPLORE, controlled Development. MZ70 diverse exposure improves new-shape
recognition but leaves missing HEAD_NEAR unresolved; MZ71 state-only calibration
loses near-body recall and exposes high-scoring wrong-query negatives in old
scenes. MZ67 often scales objects with distance, so category count alone does
not supply ordinary physical size and range evidence. This source tests whether
credible full-size placements can add useful native head/body coverage.

Fixed budget4096 attempted frames:3072 physical-size main examples and1024
separate angular-size ambiguity controls;2048 TRAIN,1024 CAL and1024 HELD
geometry-role frames. The original T71 draft row identities, paired contexts
and64 included canary rows remain fixed. A pre-capture correction adds meaningful
pose/position combinations where draft recipes repeated across roles; actual
geometry fingerprints and remaining overlap are reported, never manufactured
from IDs. No source or model outcome chooses a replacement row.

Families: wood slats, grounded stair frames, supported compound ducts and
Birch_h tree/branch geometry. Physical-size examples retain original mesh scale.
Structural mounts, platforms and fixed occluders remain present in both paired
contexts. The old context names supported/unsupported now mean presence/absence
of optional background supports, not floating/removing structural mounts.
All fixed-object descriptors must agree within a pair. Optional context objects
remain outside the query corridor; native event masks/depth are checked for
pair invariance. Full-size objects may extend outside the image or cross both
distance bands. Their observed native surfaces, not placement AABBs, set labels.

The angular-control group uses a declared optical-center mapping for paired
near/far target geometry. Smaller raised copies require real platforms or
mounts; OFF_PATH shifts these structures outside the corridor too. It is a
separate diagnostic group, not evidence of identical RGB or sensing impossibility.
Birch material evidence currently establishes opaque single-sided bark/tree
geometry only. It does not establish transparent leaves, wind or flexible motion.

Placement focus supplies a required-positive subset of four native query bits.
HEAD_PATH/BODY_PATH/BOTH_PATH names are not exclusive class labels. Preserve
every actual additional near/far/head/body bit; OFF_PATH requires all four bits
false. Missing a required focus, an invalid render/source, or implausible support
is a source failure, not a reason to alter native truth or replace the row.

Reuse the retained MZ48 collector/runtime/plugin, native event kernels,
full-frame cell derivation and original RGB plus45-degree64-zone measured
range/valid packet. New adapter code changes source admission and metadata only.
Native depth, labels, role, pose, geometry, focus and scene identity remain
evaluator/training-only. Missing or mixed ToF is not clearance; UNKNOWN remains
explicit. This is conservative sensor-stress research, not validated VL53L8CX
failure physics or a real-device performance result.

First execute exactly64 included canary frames, split into exclusive host shards.
All64 must pass source/render/floor health, native required-focus policy and
actual RGB/native inspection including physical support; all32 pairs must retain
native event masks/depth. Any failed check stops before main4032. Retain all
attempts and failure evidence. Native count/presence novelty versus original
MZ48 fit and MZ55/MZ61/MZ67 TRAIN is descriptive coverage evidence, not a substitute
for useful visible examples or a generalization guarantee. No model scores or
thresholds enter source admission.

On canary success, execute the remaining4032 once, with fixed additional16 native
audit frames (80total) and final source/role/pair accounting. Main source failures
remain explicit; never report attempted4096 as accepted4096 without receipts.
Primary and worker collect concurrently when primary has no GPU-heavy model job.
Exact host allocations, code/spec hashes, device, durations, compact bytes and
owner-side retained raw paths are recorded before dispatch. Independent CPU
analysis may continue during capture; avoid overlapping GPU-heavy primary jobs.

Return compact RGB/packet/metadata/native counts with byte-roundtrip checks.
Retain raw native evidence on its owner and avoid duplicate raw transfers or
permanent dense features. Reserve16GiB per host; estimated source volumes and
capture times are not measurements. Release capture/Zen/helper processes and
task-owned temporary resources on all terminal paths; preserve durable evidence.
Mechanical repairs retain failed receipts and scientific identities. No repeat
of a completed frozen attempt merely because its outcome is inconvenient.

No fits or model predictions occur in this source experiment. Source success
adds an admitted component for a separately declared training comparison;
source failure identifies the placement/visibility contract to repair. Complete
scoped evidence, integration and delivery at the terminal. Existing MZ70 weights,
cuts and MZ71 negative control remain intact. No Android-default, natural-scene,
hardware or safety promotion is part of this experiment.
