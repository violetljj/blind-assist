# MZ108: stable image regions and reciprocal association

EXPLORE,2026-09-13. Architecture remains one RGB+ToF+Radar+IMU. One bounded
optimization: image regions stable across intensity levels plus reciprocal
sensor association. No depth model, additional camera, training or threshold sweep.

MZ107's global Otsu proposals lose small HEAD/multiobject regions; per-return
uniqueness also allows two Radar returns to claim the same visual target. Change
to fixed OpenCV MSER grayscale regions (delta5,min area12,max area half image,
max variation.25,min diversity.2), retain existing width/height limits and discard
95%-contained inner boxes in descending area order. Existing MZ107 Otsu boxes
are included before containment deduplication. This is a classical region proposal
method under controlled rendering, not semantic recognition or general detection.

For the competitive arm, keep the existing12deg/.35m association eligibility,
but require both a single eligible image region for a Radar return AND a single
eligible Radar return for that region. A region with competing returns stays
UNKNOWN even if one is slightly closer. No RGB/missing match veto, no ground-truth
identity use. ToF independent positives and all baseline support fallbacks survive.
Identity remains a hypothesis, not proven by reciprocal uniqueness.

Compare four fixed arms on identical packets: original MZ107, regions-only,
competition-only, and both. Three-sensor spatial baseline is unchanged; RGB-off
must reproduce it exactly. Seal every arm's predictions before evaluator reads.
Report true/false accepted associations AND retained correct association coverage,
per-family and object-projection proposal recall, TP/FP/FN, critical old TP retention,
UNKNOWN and processing cost. Object-projection recall uses IoU>=.5 against native
projected bounds, evaluator-only; it is not pixel segmentation accuracy.

Inputs:96 consumed MZ107 Development frames plus one fixed new12x8-frame panel,
seed108013. New panel has4 real boundary scenes (two narrow missing-ToF controls,
two wider objects whose extent permits a ToF central ray),2HEAD,2pole,2multitarget
with hypothetical ghosts,2clear. All frames retained; no outcome-based selection.
Source changes are prescribed geometric opportunities, not a natural test split.
New panel is also controlled Development, not independent confirmation.

Keep a visual component only if proposal recall improves without task regression;
keep competitive association only if wrong associations decrease without hiding
collapsed correct coverage. Claim task gain only with FP reduction, no lost old
TP including HEAD/pole on either panel, and no unsupported association driving a
changed decision. Report each panel separately. Stop after the fixed arms and
source complete; preserve prior failures and do not tune to new outcomes.
