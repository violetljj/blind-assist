# RGB + ToF 输入路线：两周决策计划

2026-09-24。状态：计划已编写，未启动实验、训练、采集或固件修改。
工作模式：EXPLORE；目标是选择下一阶段主线，不是论文最终确认或 App 晋级。
执行窗口从实际启动日 D1 起算，最多 10 个工作日；等待设备不自动延长窗口。

## 1. 一次检验要决定什么

在固定相机前向任务上，比较单距离、理想多层和实际配置约束下的 CNH，
回答新增距离成分是否能带来值得继续投入的告警收益。双目是系统级强参照。
先写明收益、成本和不确定性，再给出“选择 CNH / 选择双目候选 / 暂不选择”的决定。
不以组件保留代替主线决定，也不把一个模型的失败写成整个输入方向不可能。

沿用 [相机前向任务](CAMERA_FORWARD_CONTRACT_20260919.md)。本次固定：
相机 X 向右、Y 向下、Z 向前，轴向米；Z=[0.30,3.00]，中心通道 X=[-0.30,0.30]；
HEAD Y=[-0.20,0.42]、BODY Y=[0.42,0.90]，采用既有查询实验的模拟高度配置。
六个查询为 BODY/HEAD × 横向中心 {-0.30,0,+0.30}m，各宽 0.60m；主告警只读中心两查询。
输出占用分数及最近接触轴向距离；传感器 UNKNOWN 和模型预测分别记录。
这不是身体未来轨迹、隐藏场景完整重建或已标定实机走廊。

## 2. 数据：固定基准，先确认能否回答事件问题

先复用 [资产清单](SPATIAL_DATA_REUSE_INVENTORY_20260921.md) 和
[15k 复用审计](EXISTING_CORRIDOR_DATA_RESULTS_20260921.md)，不把旧标签直接改名。
BODY-query 的 15k 帧是静态训练候选，缺少当前边界难负例；不能伪造帧序或时间戳计算事件指标。
全部使用来源允许的 Development；既有保留测试和受保护材料排除。已消费数据不重新命名为盲测。

固定基准分成共享训练池、验证池和一次封存评估池；静态与事件面板分别报告：

- 训练池：允许复用的 BODY-query/native RGB-depth，统一几何适配并核验全受控场景标签。
  只有指定目标在通道外不能证明全场景为负；未解释表面、无效射线和遮挡按契约保留未知。
- 事件面板：优先已有完整 approach/dwell/retreat 序列；核验细杆、HEAD 悬挂、普通障碍、
  通道外近物、纯背景，以及贴近边界负例。Core 与 Thin-object Challenge 分开。
- 使用规范化场景/布局身份去重，跨数据源相同几何、重复视点、对应左右图和序列全部同组。
  已有合法分区优先保留；无既定分区的已消费 Development 按布局哈希 seed=20260924
  分层分配 60/20/20。分组含派生关系，不把新 site 名称当成独立原始几何。
- D2 封存可读性、标签覆盖、各族布局/事件数、复用身份和 split manifest/hash。
  关键族在验证与评估中分别至少 12 个独立布局是运行下限，不是统计功效保证。
  在看候选输出前，用实际布局数和每布局事件数模拟差值区间，报告 +10 点效应的可辨别程度。
- 缺事件、负例真值或关键布局时，先在现有允许资产中补齐；仍缺则只提出一个固定补采清单，
  总新增上限 2,000 帧、最多一次逻辑采集。它属于本检验，不新增研究分支；不得挪用保留测试。
  超过限额仍不足，则到期报告事件判定 NOT_EVALUABLE，静态诊断不能替代主指标。

既有数据适配、分组和相机参数保存成同一版本，以后方法继续使用；改版本必须保留旧结果。
右相机图像缺失时不可从左图/真值合成并称为真实双目。G5 仅在同场景真实双视图可用的
匹配子集比较；否则单列“未配对历史参照”，不得据此排名主线。

## 3. 五组输入及可比性

| 组 | 输入 | 固定用途与约束 |
| --- | --- | --- |
| G1 | RGB + 8×8 单距离 | 同一底层区域响应取最强已检测成分；保留 status/缺失，作为主对照 |
| G2 | RGB + 8×8 理想多层 | 区域内可见有效原生深度构成 0.1m bins、0.1–8m 的无噪声分布；保留所有占据层，作为理想信息参照 |
| G3 | RGB + 4×4×24 CNH | start_bin=0、sub_sample=4；以实测配置、响应与噪声描述约束代理，不能宣称已标定物理模拟器 |
| G4 | RGB + 8×8×B CNH | B 与频率由第 4 节硬件测量规则选定；设备不能支持则明确缺席，不伪造硬件配置 |
| G5 | 双目 + 8×8 单距离 | 复用现有冻结双目实现与权重，作为系统强参照；额外相机、预训练、延迟和显存单列 |

G1/G3/G4 来自同一几何、反射与噪声生成器及成对噪声种子；最强距离也由该响应导出，
避免把“另一种更理想模拟器”错算为直方图收益。旧 A/LOCAL 只作为额外历史锚点，
新代理上的 G1 不自动等于旧模型 A。G2 使用真值生成理想传感观测，不向模型泄露目标身份、
通道真值、近层存在标签或遮挡后表面；明确其未建模噪声/检测限制，不能称为严格算法上界。

CNH 代理保留环境项、有限响应宽度、幅值变化、缺失及实测波动；参数从硬件校准记录确定，
不能用评估标签拟合。可见颜色不直接当作 940nm 反射率；缺标定的参数记录假设与范围。
600mm 已检测双目标分离约束不套成原始 CNH 的硬截断；选峰限制与波形响应分别实现。
D3 封存代理配置/代码/hash。每种噪声条件对各组配对，结果全部报告，不挑最优噪声条件。
检查已知近层是否进入区域观测、峰是否合并、输出是否缺失，仅作同一运行的解释字段。

G1–G4 共用 RGB320×180、MobileNetV3-small 前缀、区域 token/几何位置编码、查询解码器，
统一占用 BCE 和有效真值条件下距离 SmoothL1（米、beta=0.1、权重各 1）。
输入适配器允许维度不同；隐藏宽度固定、总参数差异目标不超过 10%，实报参数/FLOPs/耗时。
不把 G5 称为同架构、同预训练预算的输入消融；其下游头使用相同标签和训练预算。

每个可训练组固定 seeds={20260924,20260925,20260926}，batch16、24 epochs、AdamW，
lr=3e-4、weight_decay=1e-4、RGB encoder lr=3e-5、cosine schedule；所有组同样本顺序。
每 4 epochs 在验证集选检查点及阈值，先满足误报约束，再最大化事件召回，平手取早期检查点。
无事件验证能力则主决策不可评估，不暗中改为帧指标。三次种子全部报告，不选最佳种子。
最多 15 次下游拟合、累计 12 GPU 小时；先做所有组同等短工程检查，再完成预算。
若预算不足，不降低单组难度完成比较；保留已完成结果并报告缺组/训练不足。
训练实现故障可修复留痕，修复后受影响各组同等重跑且计入预算；不因效果差追加模型或调参。

## 4. 硬件配置测量：D1–D2，最多两天

已知真实链路见 [CNH 读出](../../hardware-bringup/LOCAL_CNH_20260921.md) 和
[原始协议](../../hardware-bringup/PROTOCOL.md)：4×4×24、start_bin=0、sub_sample=4、
20ms、请求 5Hz。它不是当前演示固件；操作前核对设备、现有固件与完整 Flash/配置备份。
读本地 UM3183 和实际驱动，先确认聚合区/bin 数、缓冲内存与 integration/rate 组合是否合法，
不能把 8×8 测距支持等同于 64 个独立 CNH 区域支持。

最多测四个合法配置：4×4×24@5Hz、8×8×24@5Hz、8×8×24@10Hz，
以及上述失败时按驱动可用内存算出的最大合法 B<=24 的 8×8@5Hz。
start_bin/sub_sample 原则保持 0/4，若覆盖范围不足必须显式说明，不用减少 bins 隐藏远端盲区。
请求频率不是达成频率；非法组合只记不支持，不刷入强行尝试。
每配置预热 10s、静态记录 120s；固定背景、纯近物、混合前后景各 30s，记录实际尺量几何与光照。
需要用户摆放时集中完成一组，不假称自动获得真实场景标签；无人配合仍可测吞吐，噪声适用范围缩小。

记录 raw/scaler/ambient/header、distance/status/target_count、seq、设备时间和主机时间，
以及实际 Hz、间隔 P50/P95/P99、丢序/损坏/重启、bytes/s、每 bin 中位数/MAD/方差、峰漂移。
稳定候选要求 120s 无损坏/重启、丢序<=1%、实际频率>=请求的90%，且覆盖本任务所需距离窗口。
G4 先最大化满足条件的 B，再最大化实际频率；D2 在看模型结果前固定配置。
G4 达成则提名它为唯一主要 CNH 候选，否则提名 G3；另一组是次要探索结果，不能看分数换主角。
恢复操作前固件/配置并核验原有 8×8 流，释放串口；恢复失败立即报告，不留设备在未知状态。
不改 App，不开发新通信功能，不把 USB 实测外推为手机 Wi-Fi 性能。

## 5. 指标与预先约定的决策

告警阈值只用验证集：已知负帧 FPR<=5%，且有效事件面板每分钟假告警段<=1。
连续正预测为一段，不做额外平滑；不跨缺帧/片段边界拼接。各组同样约束，实报评估实际成本，
不得在评估集重新匹配 FPR。无满足约束且能检出事件的工作点记不可用，不用全静音宣称有效。
仿真有合法时间轴才报告“模拟分钟/提前量”；静态或 posed 数据只报采样步差，不能写真实提醒延迟。

主要收益：细杆与悬挂两族事件召回等权宏平均差（CNH减G1）；两族各自结果同时报告。
事件分母包含所有真值正事件，全部漏检不能从时机统计中删除。首次提醒相对预定入界时刻，
分别报共同检出事件的配对差和包含未检出的检出时间曲线；无速度/TTC真值不声称碰撞提前量。
补充 Core/BODY/HEAD 召回、帧混淆矩阵、误报段/持续时间、距离误差与距离覆盖率，
以及传感器 UNKNOWN、模型有输出但测量未知的比例。无距离输出保留在覆盖分母中。

使用 10,000 次按完整布局配对 bootstrap，族内分层、布局内帧/事件整体重采样；
统计量为三种子均值，另报各 seed 差值及其范围。区间不代表跨训练种子的充分不确定性估计。
唯一主候选使用 95% 差值区间，避免在 G3/G4 中挑赢家产生多重比较偏差。

| 观察结果 | 到期必须给出的决定 |
| --- | --- |
| 主 CNH 候选比 G1 主召回提高>=10个百分点，区间下界>0；评估也满足误报预算；Core召回下降<=3点；共同检出事件首报延迟恶化中位数<=一个采样间隔；三seed收益均>0 | 选择单目+CNH为下一阶段3–4周研发主线；拟定轻量化和独立真实对照的里程碑，不自动宣称迁移成功或启动新增预算 |
| G2达到相同收益/成本目标，但实际配置CNH未达到 | 理想信息值得利用，但本阶段不选CNH主线；结合已记录的分辨率、噪声、覆盖与近层保留数据，明确剩余障碍；不能直接断言4×4是原因，也不自动延长硬件测量 |
| G2不涨，且正常训练/输入检查通过 | 本方案未兑现多层信息收益，停止本轮投入；不能判定“ToF信息不是瓶颈” |
| CNH未通过，匹配的G5达到同等收益/成本目标 | 双目成为下一阶段候选；另列额外相机、算力与边缘部署成本，不把桌面大模型自动确立为最终方案 |
| 区间跨0、布局不足、关键观测/标签缺失、硬件不可用或预算到期 | 判为未能确定主线，并明确哪个已观察缺口阻止决策；不加实验分支、不自动续期 |

若 G2 不通过而真实约束组通过，保留后者的实际增益并审查比较实现；
G2 不是严格学习上界，其失败不具有否决其他组实测收益的权力。
