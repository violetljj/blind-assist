# Return correspondence: interval-readout feasibility before a student

EXPLORE, consumed same-generator Development. One fixed diagnostic, no fitting,
capture, model invocation, cutoff selection or change to A, LOCAL or UNKNOWN.

The [native support diagnostic](LOCAL_SUPPORT_RESULTS_20260922.md) retained
32/36 LOCAL rescues and removed both added false alerts using native XYZ. A
public correspondence student would know only angular association and the
original noisy regional distance interval. Test this missing premise before
training. This differs from the old query-occupancy/mask and spatial-fitting
recipes; it does not reopen them. PIXEL_QUERY already explored latent return
attention, but not direct observed-contributor supervision.

## Fixed readout and scope

Reuse all 576 saved LOCAL transfer rows and observed strongest-bin lineage from
`ba-local-support-20260922-run`. Use public ToF from the unchanged transfer
materialization. Verify source hashes and IDs before computing outcomes.

Primary `exact_interval`: every actually observed contributor's native pixel
center ray, with its zone's **unchanged public interval**, may intersect the
winning centre query at some Z. Use LOCAL's existing interval formula,
`r = 0.1 + 3*(0.01 + 0.02*Z)`, low=max(0.1,Z-r), high=Z+r, and the existing
closed ray/slab query intersection. Include definite and possible-only support.
The winning centre is argmax of frozen LOCAL probabilities at queries 1 and 4,
ties selecting 1. The readout is A OR (LOCAL standalone AND at least one
possible observed contributor in that winning query).

This is perfect **simulator contributor association**, with public range
uncertainty left intact. It is privileged and cannot be installed as a public
algorithm. It is a feasibility test for this particular possibility-preserving
filter, not a ceiling on arbitrary RGB learning or on risk-aware decisions.
The historical native interval is an assumed uncertainty model, not a proven
hard bound on all native depths.

Two fixed accounting controls: `sampled_interval` uses the same rule restricted
to 4x4 evenly spaced integer sensor points per zone (1024 rays); `native_witness`
reproduces the saved native-XYZ gate. The sampling control never replaces a
failed full-support primary. No midpoint/definite/quantile readout variants.

## Decision and stop

Primary opportunity passes only if it retains at least 32 of the original
36 rescues and removes both original added false frames, preserving A frames,
events and first-alert times. Report all FP, FN, event detection, false segments,
sampled false duration, onset losses against LOCAL, UNKNOWN and subgroups.
Also report the contributor counts on the two false frames, both controls,
and appearance-pair changes. Do not report FP removal without timing costs.

If primary fails, stop **before student training** for this filter: learning
correspondence alone has not established the promised readout opportunity.
Preserve any useful spatial evidence without shrinking intervals or tuning a
readout on these outcomes. If it passes, public learnability remains a separate
question requiring an explicitly frozen RGB versus ToF-only comparison.

One 576-frame diagnostic and one independent analytical interval audit; CPU
ragged-array/metadata work, at most 10 minutes each. Preserve logs on mechanical
failure; repair only implementation/identity defects, never outcome criteria.
The audit must independently derive ray/slab intersections rather than call
the primary query-band helper. All data consumption uses governed research-ue
RunSpecs with exact evaluator/observation roles. Outputs stay under
`artifacts.local/evidence/ba-return-correspondence-20260923*`.
