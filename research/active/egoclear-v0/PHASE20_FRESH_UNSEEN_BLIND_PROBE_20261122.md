## 2. 一句话核心结论（真底牌：哪些真强、哪些真弱）

- **结论：人眼/手持/头戴人行道与室内场景零过拟合，`v14` 的速度与开箱精度优势在全新盲考上完全站得住；同时盲考也诚实揪出了 3 个真实短板（极低机位机器人 `CODa`、户外头戴高误报段 `@350` 与 `HEAD` 偏保守、未见域动态 TTC）。**
- **硬核验证成立项**：
  1. **全新真实户外头戴（`Fresh SANPO-Real`, `n=117`）**：**冻结全局 `thr=0.50` 下 `v14 = 54.7% (64/117, FA 112.6)` 全场四模型第一**（胜 `v6.6 96.6%` **`-41.9 pp`**、胜 `v12 72.6%` **`-17.9 pp`**、胜慢两倍的 `v11 66.7%` **`-12.0 pp`**，配对 Bootstrap 对 `v11` `0` 条路线退化 `CI [-17.12, 0.0]`）；`@120 = 59.8%` 且 **暗光 `0.18×` 仍为 `59.8%`（`0.0 pp` 零衰减）**；真实行人误报 **`dyn@0.5 = 11.27% (23/204)` 全场最低**；远障 Pre-Hit `p0.5>0.5 = 0.0%`（`n=659`）。
  2. **全新室内公寓（`Fresh ARKit Val`, `n=157`）**：亮光与暗光 `0.18×` 下 `v14` 均为 **`0.0% (0/157)`**（固定 `thr=0.50` 同样 `0.0%`）；Omni 全面碾压旧代：`HEAD FPR` 比 `v11/v12` 降 **`4–4.8×`**（`51.6%/63.2% → 13.15%`）、`DROP FPR` 比 `v11` 降 **`2.9×`**（`24.55% → 8.59%`）、绕行准率 `92.43% (n=436)`。
  3. **全新合成（`Fresh SANPO-Synth`, `n=87`）**：**`v14 @120 = 2.3% (2/87)` 反超 `v11 (3.4%)` 与 `v12 (5.7%)`**，`dyn@0.5 = 0.00% (0/389)`，双融合 `ENS(v6.6+v14)` 全档 **`0.0% (0/87)`**；真深度 **`AbsRel = 0.1340, scale = 1.0083×`**（胜 `v12 0.1761`）；动态逼近 TTC **`AUROC = 0.7540`**（胜 `v11 0.6543` / `v12 0.6445` **`+10 pp`**）。
  4. **4 域无记忆光学 `UNKNOWN` 盲测大胜**：全部 4 个全新域的 `blackout / finger_red / whiteout` 上 **`v14` 达成 `12/12 = 100.0%` 满分**（`v11` 全场 **`0.0%`**, `v12` ARKit 仅 `75%`），`defocus_blur` 在 Real / ARKit / CODa 全达 `100.0%`。
- **诚实暴露的 3 个真实短板**：
  1. **极低机位机器人跨平台（`Fresh CODa`, `0.704 m` 高度, `n=82`）**：所有 `MoGe-2` 系（`v11/v12/v14`）在全新低机位路线上均出现严重过触发（压扁 `@120 = 92.7–100%`, `FA@0.5 = 672–680`；`iso_crop @120`: `v11 78.0% / v14 85.4%`），而 `v6.6 (DAV2-S)` 保持 `72.0% / @500 35.4%`；但 **双融合 `ENS(v6.6+v14) iso_crop @120 = 58.5%`** 反而同时大幅击败两者（比 `v6.6` 降 `-13.5 pp`、比 `v14` 降 `-26.9 pp`），印证双主干互补价值。
  2. **户外头戴高误报区间 (`@350`) 与 `HEAD` 阈值偏保守**：`Fresh SANPO-Real` 上 `v14` 在 `@350`（`53.0%`）不如 `v11`（`18.8%`）；`HEAD` 在该域 `AUROC` 两者几乎一样（`v14 0.850` vs `v11 0.853`），但 `v14` 在 `0.50` 处的 `F1` 仅 `0.150`（`v11 0.426`），说明户外头障头偏保守。
  3. **未见户外低机位 / 自动分割域动态 TTC**：`Fresh Synth` 上 `v14` TTC 达 `0.754`，但 `Fresh CODa`（`0.293`）与自动分割 `Fresh SANPO-Real`（`0.334`）三代模型均偏低（`0.24–0.39`），跨机位动态逼近仍待真实多帧运动标注补强。
