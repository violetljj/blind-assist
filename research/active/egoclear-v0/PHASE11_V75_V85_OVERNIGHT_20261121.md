## 1. 一句话结论（收益、代价与诚实边界）

把主干从仿射不变 `DAV2-Small (42×74)` 升级为 **冻结 `MoGe-2-ViT-S-Normal`（35M MIT，真度量深度 + 重力表面法向，84×148）+ 331M `MoGe-2-ViT-L-Normal` 清晰→暗光几何残差蒸馏 + `lags=(1,2)` + 18 通道 3D 物理走廊快捷通路 + `FreeSpaceDynamicConvGRU`** 后，**`EgoClear-v8.5`** 与 **`EgoClear-v7.5 (no-lag4)`** 在真实户外低误报、极暗室与跨城阈值收敛上实现结构性突破：

1. **真实户外 `SANPO-Real 40`（111 事件）超严误报档暴降 `-20.8 pp`**：`EgoClear-v8.5` 在 **`@fr≤80` 达 `36.9%`（`41/111, ep=18.2, fr=62.9`）**，较 `EgoClear-v6.6`（`57.7%`）狂降 **`-20.8 pp`**；在 `@fr≤120` 仅用 `62.9 fr/km`（近乎一半误报预算）即领先 `v6.6`（`48.6%`）**`-11.7 pp`**（配对路线集群 Bootstrap 中位 `-10.53 pp`；对 `v7.5(no-lag4)` 的 FA 差 95% CI 为 **`[-95.9, -2.1] fr/km`**，统计显著更低误报）。`EgoClear-v7.5 (no-lag4)` 在 `@fr≤120` 进一步触达 **`34.2% (38/111, fr=109.2)`**（胜 `v6.6` **`-14.4 pp`**）。
2. **`0.18×` 极暗户外直超 `v6.6` 亮天表现，极暗室内近乎零衰减**：`EgoClear-v8.5` 在 **`SANPO-Real 40 Dark 0.18×`** 下达 **`@80 = 47.7% (ep=9.6)` / `@120 = 44.1% (49/111, ep=16.3, dyn=14.8%)`**——**在 18% 亮度加噪暗光下反超 `v6.6` 晴天白昼成绩（`48.6%`）**；在 **`ARKitScenes 30 Dark 0.18×`** 下达 **`@80/120 = 7.7% (12/156, ep=0.0)`、`HEAD F1 = 0.501`**（亮室 `@120 = 7.1%`、`HEAD F1 = 0.520`；`v7.5(no-lag4)` 亮室更达 **`@120 = 2.6% (4/156)`**）。
3. **骁龙 8 Gen 3 Hexagon v75 NPU 单子图真机跑通（`18.8 FPS`）**：将完整 `EgoClear-v8.5` 编码器（`35.28M` 参数、`97.5 GMACs`，含 `ViT-L` 残差头、有界分块闭式 Shift 与平滑支持面估计）经 QAIRT 2.47 离线准备生成 **`Total Subnets: 1`（零 CPU 回退，HTP FP16 缓存 `92.77 MB`）**，在 Samsung Galaxy S24 Ultra 上无声实跑 12 帧：**冷启 `Init = 132.1 ms`，均帧仅 `53.23 ms`（`18.8 FPS`，较 CPU 估计快 ~`90×`）**，IEEE-754 FP16 深度最大误差 **`2.1 mm`**（`0.00209 m`），白噪兜底输出 100% 有限（`conf=0.0`），配合减负后的 `lags=(1,2)` `step`（约 `16 ms`）总计约 `70 ms/帧`，稳稳落于 5 Hz（`200 ms`）实时预算内。
4. **诚实权衡（暂不替换 `v6.6` 为唯一眼镜默认模型）**：在 **Meta Aria Gen 2 单目灰度广角眼镜零样本（193 事件）** 上，`v8.5`（`@200 = 62.7%`, `@350 = 62.2%`）与 `v7.5`（`@200 = 64.8%`）仍明显落后于 `EgoClear-v6.6`（`@200 = 41.5%`, `@350 = 35.8%`），且 `v8.5` 在亮天 `SANPO-Real` 行人误报为 `33.3% (9/27)`（`v6.6` 为 `7.4%`），`v8.5` HTP 缓存（`92.77 MB`）与延迟（`53.2 ms`）也高于 `v6.6`（`54.78 MB` / `18.0 ms`）。因此当前形成**清晰的场景互补双主力格局**：`v8.5` 为**户外强抗误报/暗光主力**，`v6.6` 保持**超快 26 FPS 通用/灰度眼镜零样本主力**。

## 3. 整夜 6 项核心科学发现（阶段 2 五门控 + 15 秒体素 X 光 + 消融证伪）

1. **Gate 1（FP16 有界分块闭式 Shift 完胜）**：我们设计的 4×4 空间分块限权闭式焦距 Shift 在 138 帧实景上达 **`AbsRel = 0.2556`**，与官方迭代 `MoGeModel.infer()`（`0.2552`）仅差 `0.0004`，原生 IEEE-754 FP16 **0 帧非有限值**（`v8.5` 编码器深度最大误差仅 `2.1 mm`）。
2. **`lag=4` 毒化实走推理（单刀直降 `-6.3 pp`）**：冻结 `v7.5` 仅遮蔽 `lag=4`（0.8 秒前，保留 `lags=(1,2)`），五域全线变好：`SANPO-Real 40 @120` 从 `40.5% → 34.2%`（`-6.3 pp`）、固定 `0.50` 误报暴降 `4.4×`（`211.0 → 48.1 fr/km`）、`ARKit @120` 从 `4.5% → 2.6%`、`Synth @120` 从 `16.1% → 14.6%`，且端侧 `step` 少 5 个输入张量、更轻量。
3. **Gate 3（331M `MoGe-2-ViT-L-Normal` 几何替换上限 `-12.6 pp`）**：`ViT-L` 在 `SANPO-Real` 全局/细边缘/暗光 `AbsRel` 分别优于 `ViT-S` `-0.0313 / -0.0423 / -0.0293`；不重新训练仅将 `ViT-L` 几何替换入冻结 `v7.5`，`SANPO-Real @120` 直接再降 `-12.6 pp`（`48.6% → 36.0%`）；在 `v8.5` 稳态 `B=16` 下，仅 +0.25M 零初始化残差头成功将 `geom` 蒸馏损失从 `0.3898 → 0.3490` 收敛。
4. **Gate 2 及时拦下 `use_ground_relative` 陷阱并挖出 `CODa` 人眼先验**：在 0.704 m 矮车 `CODa` 上，`MoGe-2` 估计地面离相机 `1.355 m`（信心 `87.5%`，系统高估 `1.92×`），Gate 2 自动关闭了地面相对采样；同时验证五域可走地面法向 `n_up` 全部精准落在 `+0.992 ~ +1.000`。
5. **15 秒体素 X 光揭开 `Aria`/`CODa` 物理与训练分离**：`MoGe-2` 原生 3D 垂直面命中在 `Aria`（`0.059 / 0.006 = 10×`）与 `CODa`（`0.058 / 0.001 = 58×`）上具有极高信噪比，证明瓶颈不在 `MoGe-2` 几何本身，而在单目灰度广角特征分布与旧 `v7.5` `delta=0.30` 死区抬高了清空走廊底噪（`0.21–0.26` vs `v6.6 0.016–0.070`）。
6. **`B=1` Proxy-Lagrangian 与 `BatchNorm` 负对照教训**：在 `v7.5 ep1..8` 发现 `B=1` 事件/误报循环在 `.train()` 模式下覆盖了 `BatchNorm` 统计量（纯多域 BN 重校准零改权重即让 `Synth @120` 降 `-23.3 pp`、`CODa @120` 降 `-16.7 pp`）；`v8` 负对照进一步证明无教师锚定时激进 `B=1` Proxy-Lagrangian 会引发 `fa` 震荡（`2.18`）与梯度裁剪饥饿，而 `v8.5` 回归纯 `B=16` 稳态联合优化（Smooth Tail-OHEM + 动态铰链 + 互补双教师 + `ViT-L` 几何残差蒸馏）立刻全面收敛。
