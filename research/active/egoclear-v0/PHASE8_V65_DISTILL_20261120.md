## 1. 方法设计：特权跨架构知识蒸馏 + 动态防泄漏门控

为将旗舰教师 **`EgoClear-v6-Base`（`DAV2-Base 97.5M` + 3-Lag `(1,2,4)`，`202.82 MB` FP16）** 在真实户外学到的强三维几何表示压缩回移动端 **`57.22 MB`（`DAV2-Small 25M` + 2-Lag `(1,2)`）**，同时避免继承教师在无语义 `camera_head` 上残留的行人误报（`66.7%`）与 `lag=4` VIO 漂移敏感（`16.8%`）：

1. **非对称特权输入（Privileged Teacher → Hardened Student）**：
   - 冻结教师 `V6-Base` 始终接收干净 RGB 与干净位姿，并使用 3-Lag `(1,2,4)` 长基线（0.8 s）视差提取几何软目标；
   - 从 `EgoClear-v5` 暖启动的 2-Lag 学生同时接受 30% 单通道灰度化、45% 针孔虚拟俯仰/偏航（Virtual Pan-Tilt）与 50% 真实 VIO 漂移扰动，在强域随机化下对齐教师的 BEV 空间占位与单调走廊生存风险。
2. **动态安全蒸馏门控（Dynamic-Safe Distillation Gate）**：
   - 有动态分割真值帧严格按 `(1 - is_dyn)` 屏蔽动态目标区域蒸馏；
   - 无动态分割真值的 100 条 `camera_head` 场景额外引入学生自有动态头置信度门控（`p_dyn < 0.25`），阻断教师行人误报向学生迁移。
3. **训练数据池（1,194 条多域场景，18 ep，384 帧/步）**：`synth=627 (36%)`、`real_seg=167 (36%)`、`real_head=100 (10%)`、`arkit=300 (18%)`；总损失由 `0.5109` 稳定收敛至 `0.3939`（`co: 0.0683 → 0.0364`，`flk: 0.0212 → 0.0160`）。

## 3. 诚实边界与机制复盘

1. **为什么 `V6.5` 在胸挂/高召回/VIO/室内全面创纪录，甚至反超 203 MB 教师？**
   - 冻结 `DAV2-Base (97.5M)` + `lag=4` 教师在 1,194 场景上提供的密集 BEV 与走廊软目标，把丰富的远距三维几何先验成功蒸馏进了 `57.22 MB` 的 `2-lag` 学生头，同时 `2-lag` 架构天然避免了 `lag=4` 的长基线 VIO 漂移累积，动态门控把教师 `66.7%` 的行人误报砍掉 2/3 至 `22.2%`。
2. **为什么在 `SANPO-Real camera_head @120`（`80.0%` vs `V5 65.7%`）与 `Aria Gen 2 @120`（`70.5%` vs `V5 53.9%`）低误报区间未能完全追回 `V5`？**
   - 根本原因在于教师 `V6-Base` 本身在 100 条无语义 `camera_head`（`has_dyn_gt=0`）与彩色 ZED 域上存在偏锐化的 logits 分布（教师在 Aria `@120` 仅 `82.9%`）；即使做了 `p_dyn < 0.25` 门控与学生灰度增强，教师在 `camera_head` 帧上的软目标仍将部分高分偏置注入了学生头，导致极低误报阈值区被压缩。
3. **三模型清晰帕累托前沿（均 `mono_viol=0.0%`，零 ToF/零地板拟合/零眼高假设）**：
   - **`EgoClear-v6.5`（`57.22 MB` FP16，误差 `3e-6`）**：**胸挂/手持手机默认主力模型**——真实胸挂 `@120 = 29.3%`、真实高召回 `@350 = 17.1%` / `@500 = 16.2%`、VIO 1× `@80 = 5.1%` / `2of3 @120 = 1.5%`、室内 `HEAD F1 = 0.535`、`cov70 = 1.52%` 全线创纪录。
   - **`EgoClear-v5`（`57.22 MB` FP16，误差 `1.8e-5`）**：**头戴眼镜 / 极低误报专精模型**——Aria Gen 2 零样本 `@120 = 53.9%` / `@200 = 47.2%`（首超双目参考）、真实户外 `@120 = 55.0%`（`4.4m 50.5%`）与最低行人误报 `11.11%`。
   - **`EgoClear-v6-Base`（`202.82 MB` FP16，误差 `2.2e-5`）**：**旗舰高算力参考教师**——真实户外中段 `@200 = 29.7%` 与户外 `HEAD F1 = 0.140` 最高。
