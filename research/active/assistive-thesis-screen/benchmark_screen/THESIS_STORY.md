# 毕设故事线：视障用户的免标注个人物体识别（ORBIT）

所属：**毕设线**。数字均来自 [RESULTS](RESULTS.md)（测试集 = ORBIT 官方测试划分 17 位视障用户、297 段杂乱视频、
官方 50 任务协议；参数只在训练/验证用户上选，测试集每轮先在 [PLAN](PLAN.md) 登记并推送，再只跑一次；共使用两次）。

## 一句话

视障用户用手机拍几段短视频，"教"系统认识自己的东西；之后在杂乱的家里，系统要认出镜头里是哪一件。本文的方法
**不需要用户做任何标注、骨干冻结**：先记住每件物体"与众不同的局部"，再学会"往哪看"，只对拿不准的画面放大再看一眼。
在真实视障用户数据 ORBIT 上，**单帧 76.84%，超过官方元训练模型的 75.38%**，骨干参数约为其 1/4，平均每帧只多 0.42 次前向。

题目候选：《面向视障用户的免标注个性化物体识别：判别式局部记忆与按需放大》；
或《先找再看：视障用户可教物体识别的轻量方法》。

## 难点（每条都有数据）

| 难点 | 证据 |
| --- | --- |
| 教学视频没有标注：盲人无法画框或掩码 | 依赖参考掩码的方法改成免标注后退化：Swiss DINO 61.6%、PerSAM 20.6%（测试集单帧） |
| 目标小、背景杂 | 测试集约 22% 的有效帧目标面积不到画面 5%；按真值框放大可从 72.5% 到 84.8% |
| 不知道往哪看 | 开发集：真值中心+固定放大 86.1%，自己的证据峰值放大只有 83.0%；位置对了大小才有用 |
| 同一用户的物体很像 | 训练用户的错误平均 61% 被同一个"枢纽物体"吸收；最差用户有 5 支只差颜色的马克笔 |
| 手机算力有限 | 整图放大到 448 每帧 31.7 GMACs（224 的 5.2 倍），不能靠堆分辨率 |

## 方法与创新点

1. **免标注判别式局部记忆**。用户其他物体的教学帧就是天然负样本：每件物体只保留"像自己其他帧、不像该用户其他物体"
   的 15% 图块，聚成 32 个局部原型。不训练、不要框。
   证据：整帧 66.3 → 72.5（单帧）；"剔除共享图块"这一步单独贡献约 16 点（不剔除 55.5）。
2. **学会往哪看 + 按需放大（先找再看）**。一个 2.5 万参数的定位头（用公开训练划分自带的框训练，测试时不读框）指出
   "用户正在拍的东西"在哪；只对前两名差距小的帧，在那里裁出半幅放大重看，与整图得分融合。
   证据：主结果 76.84（+2.24 相对池化版 74.60）；同样门控下学到的定位比证据峰值高 1.34；门控比每帧都放大更准
   （76.84 对 76.31）且省 29% 计算；小物件用户 P455 从 50.4 到 69.7。
3. **轻量跨用户学习**。52 参数的池化头（学温度与整帧权重）+ 定位头，都在 44 位训练用户上学，骨干与记忆不动。
   负结果同样写进论文：4.9 万参数的匹配投影在交叉验证 +4.9，但测试只 +1.1（物体多的用户退化）；框监督用于匹配反而 −3。
4. **因果时序累积**。只用当前及之前的帧：1 秒窗口 79.55，从首帧累积 81.82（后者部分来自 ORBIT"先近后远"的拍法）。
5. **高效、安全的实验系统（工程亮点）**。按需从 figshare 取帧（三个划分约 9 GB，原估 5 小时的测试集 18 分钟）；
   一次前向同时得整帧与图块；放大裁剪直接在 GPU 已解码帧上做；nvJPEG + 混合精度（−21% 耗时、精度不变）；
   显存上限、低内存暂停、断点续跑，以及一次 336 显存溢出后把上下文改为切片视图（峰值 5.3 → 3.5 GB，结果逐位不变）。

## 消融与分析（论文第 5 章）

- 局部记忆：剔除比例（keep 1.0 / 0.3 / 0.15 → 55.5 / 70.4 / 72.0）、融合整帧、上下文减半（个性化计算减半只降 0.45）。
- 往哪看：真值诊断拆分（位置 vs 大小）；证据峰值 / 画面中心 / 学到的定位的命中率（72.3 / 56.7 / 75.4%）。
- 放大：门控阈值与比例、固定尺寸 0.5 / 0.65、每帧都放大、候选验证（82.4，无效）；与整图 336（开发 +1.75，计算 2.5 倍）对比。
- 负结果：匹配投影的开发–测试落差、框监督用于匹配、颜色感知、背景集规整、register 版、多尺度记忆。
- 失败分析：枢纽物体（P753 马克笔不变：放大不解决颜色差异）；物体多的用户。
