日期：2026-10-15；状态：EXPLORE / 文献与源代码合同；模型实验 NOT_RUN。

**结论：最值得补充的机制是“按可观测性校准负证据，再用有限次复查消除冲突”，但目前应列备选。** 它能连接视障寻物、物品状态确认与熟路记忆：物体没被看到时，区分“已移走”和“当前看不到”，然后选择最有用的复查。已有工作已覆盖主动拍摄、记忆压缩、跨视图冲突和旧记忆核验；这些名词本身不能构成两个创新点。本轮还发现最贴近的数据源无法匿名下载，因此其可执行性暂时低于已有可用数据的方向。

## 建议加入的两章机制

拟题仅为工作标题：**面向视觉辅助的观测证据有效性判断与预算约束复查方法**。

**研究点一：观测条件校准的负证据。** 对每条“目标没检测到”估计“若目标仍在，这个视角本应多容易看见它”。用可视区域、目标历史尺度、遮挡、拍摄角度与历史可靠性估计检测机会；低可观测性下的未检出只更新 UNKNOWN，高可观测性下的未检出才支持状态改变。可实现为小型校准器 + 因果序列更新，不需要重训大 VLM。与最近邻的区分在于显式估计负证据强度，并校准错误消失判断；不是让另一个提示词替系统做判断。

关键薄弱假设是：能获得或构造可观测性监督，且预测器不能看到当前反事实真值。由相同位姿的“物体保留/移除”配对得到的差异可用于训练与 evaluator，但不能成为部署输入。多视图往往相关，不能把重复帧当独立证据相乘。

**研究点二：以错误消失风险下降为价值的复查。** 在相同观察预算下，选择回到旧视角、换互补视角或停止；优化每一次观察对“仍在/移走/未知”歧义的预期消除，而非只选与问题最相关的图。学生只能用当前信息预测动作价值；未来视图仅作训练监督和 evaluator。若数据只能提供已录好的多视图，先研究有限视图库检索，明确不等价于真实人类相机动作。

这两点有统一状态估计问题，且能分开消融：仅研究点一、仅研究点二、联合。仅设计一张场景图再接一个规划器不足以区分于 ObjChangeVR、DIVRR、IVAM-Nav。

**最小判别试验（尚未运行）：** 若能获取合法可用的少量配对数据，以 2 个场景的约 60 个对象事件作 Development 筛查，覆盖真实移除、仍在但遮挡、仍在且视点变化、从未出现；来源对象/轨迹成组拆分。基线为最近可见记忆、作者修复后的 ObjChangeVR、直接 VLM 多图比较、相同预算的均匀/位姿最近取帧。先看给定错误消失次数下的正确状态覆盖，再看 1/2/3 次观察预算的收益。若只在可观测性 oracle 下有增益，说明只是数据上界，不足以选题；若校准单独无增益，不用大规划器掩盖。

## ObjChangeVR 实际接入结果

作者仓库树 SHA：`c5329c50761ad2485a42ea1e2db1b9f407703c6d`。11 个 tree entry 中有 **8 个文件**、0 个 CSV。此前消息曾把文件数口头写为 7，本处以机器输出 8 为准。

README 声称数据包含 5 类场景、逐轨迹截图/位姿与 QA，并说明同轨迹反事实保留/消失渲染。但本轮唯一数据下载入口跳转到 `login.microsoftonline.com`，取得的是 59,975 B 登录 HTML，而非数据包。没有登录、没有绕过授权。公开 Task.jpg 只展示 1 个模拟花瓶消失案例，不能计算数据集错误率。

| 项目 | 实际结果 |
| --- | --- |
| 取得作者源码 | QA 生成、Unity 捕获、方法与评价，共 4 文件 |
| 取得原生 QA/results 行数 | **0 行** |
| 取得可运行原始成对图像 | **0 对** |
| 作者配图检查 | **1 个模拟案例**，含历史帧 43/110/126 和当前帧 143 |
| 当前模型/错误分组统计 | **NOT_RUN / 不可计算** |
| 可复现代码合同反例 | 3/3 个 toy 索引不匹配，见下；不是性能分数 |

源码核查得到的合同：

1. 生成器按 `Index` 匹配 screenshot 与 groundtruth，两者文件名可不同。应按索引并核验位姿，不应按截图时间戳文件名配对。
2. `CameraPathPlayer.cs` 输出的 `IsDisappear` 由全局 `isAfterPhase` 计算，只在 groundtruth CSV 中输出；**它不是每个对象的可见性标签**。已检查字段没有对象级遮挡/可见性。
3. QA 类别为 disappeared / always / never，生成提示要求 4/3/3 配比。这是生成目标，不是已验证的数据分布。
4. “第一图中未出现”在生成提示中会触发 never；未检查原始 QA 前不能声称所有标签错误，但这是必须检查的负证据监督假设。
5. 作者方法有可复现的索引合同错误：`RetrievedIndices` 经 `chosen_rel = final_idx[order_rel]` 得到，而实际发给 VLM 的图像用 `subset_paths[i] for i in order_rel`。缺少 `final_idx` 映射会导致记录帧与图像不一致。固定候选 `[7,4,9,6]` 的前三个时间排序记录 `[4,6,7]`，实际取图却是 `[1,3,0]`，**3/3 不匹配**。这证明代码路径缺陷，不证明论文结果用了该错误版本，也不估计其准确率影响。原作者代码未修改。

因此，第 5 方向本轮结论为：**机制值得保留；数据匿名接入失败；可观测性标签与基线代码均需修复/核查；尚无模型收益。** 不应因这条新方向听起来更完整就替换当前已能跑小试的路线。
