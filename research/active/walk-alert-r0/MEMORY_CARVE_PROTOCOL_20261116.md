# 多帧记忆 + 自由空间清除（“试多帧地图”授权范围内，冻结于运行前，2026-11-16，EXPLORE）

背景：[记忆结果](MEMORY_RESULT_20261116.md)显示，记忆让下限从 20.1% 降到 2.4%，但误报约翻倍。
神谕诊断表明，多出来的误报约 77% 来自过去帧中的行人拖影。本问只问一件事：
**不用语义或 RGB，只用当前帧深度做自由空间清除，能追回多少神谕去动态的效果。**
实现：`walk_alert_policy_sanpo.py prepare_mem_carve <work> v2`，然后运行 `mem_carve_eval.py <work>`。

## 不变

真值、事件、行走者、误报、B1 网格，以及“下限”和“工作点”的定义，都与 [记忆协议](MEMORY_PROTOCOL_20261116.md) 相同；共 287 个会话。

## 感知臂（新缓存 `policy/cache_mem_carve`）

- 0：单帧。1：记忆（与记忆协议的臂 1 相同）。
- **2：记忆 + 自由空间清除（主）**。过去帧 j < i 的每个点，用当前帧的 GT 位姿和内参投影到当前图像。
  当它在当前相机前方超过 0.3 m 且落在图像内时，查当前帧在最近采样像素上的深度 d：
  若 d 无效（无穷、≤ 0.1 m 或 ≥ 30 m，例如天空），或 d > z + 0.10 + 0.03·z，说明此处已被看穿，删除该点。
  其余点保留，包括被遮挡的点（d < z）和落在视野外的点。不用任何类别信息。
- 3：记忆 + 神谕去动态（参考臂，与诊断臂相同，只用于计算追回比例）。

## 判据（盲人行走者，B1）

- **主判据：追回比例** R = (FA₁ − FA₂) / (FA₁ − FA₃)，FA 取 τ=5 时的误报/km，按会话 bootstrap 2000 次（种子 20261116）。
  - R ≥ 0.6 且臂 2 的下限 ≤ 10%：几何清除可用，下一步改用真实感（带噪深度和位姿）的记忆来检验。
  - R < 0.3：几何清除不够，需要语义检测（RGB）。
  - 其余情况：不确定。
- 次要报告（不决定方向）：记忆协议的原判据，即臂 2 对臂 0 下限降低 ≥ 5 个百分点、CI 下界 > 0，
  且工作点误报 ≤ 1.2 倍。神谕臂本身是 1.25 倍，所以这一条预期很难满足，事先说明。
- 明眼人行走者只做描述。
