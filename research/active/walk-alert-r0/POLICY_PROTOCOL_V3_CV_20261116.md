# 提醒策略对照协议 v3：按会话 5 折交叉验证（用户 2026-11-16 授权，冻结于运行前）

继承 [v2 协议](POLICY_PROTOCOL_V2_20261116.md) 的真值、事件、感知、行走者、策略、网格和匹配迟报率规则，
直接复用 v2 缓存（`policy/cache_v2`），不重建、不下载。v2 因固定划分的评估集分母不足（22 < 30）
判为 NOT_EVALUABLE，原样保留。实现：`walk_alert_policy_sanpo.py cv <work> v2`。

## 披露

v1 在旧固定划分的 110 个评估会话上运行过一次（明眼人行走者的 P1 数字在日志中可见）。
这些会话在 v3 中也会进入各折的留出集，所以 v3 的结论只算 EXPLORE 开发证据，不能当独立确认。

## 相对 v2 只改划分与汇总

1. **折分配**：`sha256('walk-alert-r0-cv:'+id)` 的前 8 位十六进制转为 [0,1)，乘 5 取整得到折号 0–4。全部 287 个会话参与。
2. **每一折**：用其余 4 折的会话训练 P1（同一 HGB 配置），计算 v2 的匹配迟报率 cap
   （B1/B2/B3 训练集最低迟报率的最小值 + 5 个百分点），并在训练折上为每个策略选
   “迟报率 ≤ cap 时误报/km 最低”的阈值（并列取网格中第一个），训练折误报/km 最低的规则记为该折的最好规则。
   然后在留出折上只跑一次所选阈值。
3. **汇总**：把 5 个留出折按会话拼起来。每个策略的汇总迟报率和误报/km 用各折自己选出的阈值计算；
   “最好规则”一栏在每个会话上取该会话所在折的最好规则。
4. **bootstrap**：对 287 个会话有放回重采样 2000 次（种子 20261116），统计 P1 相对最好规则的误报/km 减少量。

## 分母核对（只看标签，先于任何策略运行）

全部会话上每个盲人行走者平均的可避免事件 < 30 → NOT_EVALUABLE，停止。
任一折中 P1 或三条规则全部选不出阈值 → 该感知臂 × 行走者组合 NOT_EVALUABLE。

## 判据（与 v1/v2 相同，作用于汇总结果）

- 主臂 × 盲人行走者：P1 相对最好规则，汇总误报/km 减少 ≥ 30%，且 bootstrap 95% CI 下界 > 0，
  同时 P1 的汇总迟报次数不比最好规则多 2 次以上 → 继续 G4。
- 减少量 < 10% → 放弃 G4；介于两者之间 → 不确定。
- G6 附带检验：主臂下把行走者换成明眼人，若四个策略的汇总误报/km 排名改变，
  或 B2 各折所选 TTC 阈值的平均值变化超过 0.5 s，判为“校准行走者有影响”。
- 带噪代理臂只做描述。
