# City Sample 实验采集场 v1

已建立三个隔离区域、九条路线，覆盖人行道、原生路口和受控狭窄通道。
正式批次共 **108 帧**，另以完全相同配置复采西区 **36 帧**。
这次交付是场景与采集设施建设，没有训练或评估模型。

| 验收项 | 实测结果 |
| --- | --- |
| 场景与路线 | 九条路线均检查起点、中点、终点；正式批次全部 108 张画面已检查 |
| 街区加载 | 108/108 帧等待所需资产就绪；近处原生街区与远处 HLOD 背景保留 |
| RGB / 深度 | 108 对完整，640×360，深度为 float32 轴向米值 |
| 相机 | 每帧读取 RGB、深度相机实际变换，未发现不同步或指令偏差 |
| 障碍身份 | 36/36 个受控实例通过隔离深度与严格独立碰撞身份检查 |
| 配对条件 | 每路线包含细杆、侧向突出物、头部横杆、悬挂标牌及移除目标后的对照 |
| 对照范围 | 7/9 组对照近场 BODY/HEAD 均为 0；两条人行道仍有原生设施，不能当整幅无障碍负例 |
| 地面检查 | 103 帧在 2 cm 容差内；5 帧保留 REVIEW，无穿墙或相机埋入地面的异常 |
| 数据划分 | west/train、central/dev、east/test 各 36 帧；按区域、路线与目标实例隔离，无跨划分重复图像或相邻帧混入 |
| 原配置复采 | 36/36 帧深度文件逐字节相同，位姿、近场标签与目标可靠性一致；RGB 每通道平均绝对差约 0.689/255，不宣称逐字节复现 |
| 代码验证 | 26 项契约、装置和编译集成测试通过 |

整体数据清单状态是 **REVIEW**。108 帧的 216 个近场 BODY/HEAD 值均已知，
但像素级空间标签仍有 UNKNOWN，不能因为近场值已知就抹掉这些不确定区域。
原生设施保留在画面和空间标签中；逐实例严格验收目前覆盖新增的 36 个受控目标，
不代表已完成所有原生城市设施的实例标注。

五个地面复核位置如下。相机高度计划值来自预览插值，标签使用采集时的实测地面；
这些帧没有被静默改成恒定 1.7 m 相机高度。

| 区域 / 路线 | 区域内 sample_index | 地面偏差绝对值 |
| --- | --- | --- |
| central / intersection | 16 | 2.459 cm |
| central / intersection | 17 | 3.024 cm |
| east / intersection | 13 | 8.756 cm |
| east / intersection | 17 | 3.516 cm |
| east / narrow_passage | 26 | 2.278 cm |

每条路线是 12 m 范围内的七个静态位置采样，加中点的五种装置条件。
它们支持按配置稳定采集，不宣称连续行走视频、仿真时钟同步或整条路径无障碍。
狭窄通道的护栏与四类目标是有支撑的人工受控装置，不能冒充原生扫描物体。
原始 City Sample 地图和项目未保存修改，采集进程已释放。
三个划分共享同一城市与模型资产，且场景搭建时均被查看；`test` 是空间隔离分区，
不是封存盲测或未见城市证据。
