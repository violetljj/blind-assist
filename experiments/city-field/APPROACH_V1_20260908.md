## Reproduction and validation

The immutable [recipe](approach-v1.json) hashes the original source spec.
Run `python tools/make_city_field_approach.py --output <fresh-artifact-directory>`
to create the 21-pose preflight spec. After capturing it, run the same generator
with `--preflight <completed-preflight-capture>` to create the 105-frame final
spec from exact-XY measured floors. Use the existing native capture and strict
label verifier with these specs; preserve receipts before evaluation.

For fixed inference, use `python tools/evaluate_city_native_route.py --capture
<capture-v1> --labels <labels-v1/native-route-labels.json> --output <fresh-output>`.
For cached-only scoring, use `python tools/summarize_city_approach.py --capture
<capture-v1> --evaluation <fixed-v1> --labels <labels-v1> --output <fresh-summary>`.
Paths in angle brackets are placeholders. Keep all outputs under artifacts.local.

Five focused unit tests pass, covering label identity/hash corruption, excluded
opportunities, nonmonotonic response, paired clear alarms, and untested nearest-hit
persistence. Independent cached review matched all counts against the original
evaluator and checked joint counts and farthest distances for all 30 sequences.
Retain this route as acquisition and failure-analysis evidence. No training,
threshold search, new test partition, continuous-motion or model promotion claim.
